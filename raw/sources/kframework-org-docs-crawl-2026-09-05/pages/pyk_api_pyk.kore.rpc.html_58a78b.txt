
Abort an
execute
/
simplify
/… request running on another thread.
Sends a
cancel
so the server stops computing; the interrupted call raises a
“cancelled” error and the connection stays usable. Works on the single-socket
transport only; a no-op for HTTP (one connection per request, nothing to cancel).

before any request has been made.  Snapshot it immediately after a call
(e.g.
execute

simplify
) to key per-request data (logs, handoff
metadata) to that exact request.  Each proof worker drives its own
KoreClient
(see
