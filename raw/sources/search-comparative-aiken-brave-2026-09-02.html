Aiken | Cardano Docs
Aiken does not include higher-kinded types or type classes because it aims for simplicity. On-chain scripts are typically small in size and scope compared to other kinds of applications being developed today. Consequently, they do not necessitate as many features as general-purpose languages that must tackle far more complex issues.
