# Cardano developer documentation: reading route

The full local prose archive is indexed in [cardano-developer-docs/INDEX.md](cardano-developer-docs/INDEX.md). The generated Plutus public-library API archive has its own [index](cardano-plutus-api/INDEX.md). All921 HTML targets from its root index were retained;126 additional cross-reference URLs returned404. [Root coverage](cardano-plutus-api/ROOT-INDEX-COVERAGE.json) and [failures](cardano-plutus-api/FAILURES.md) preserve that distinction. Raw HTML and separately scoped text extracts have per-page SHA256 receipts. Those archives are reference material; they were not all substantively reviewed.

Follow this route to understand the examples in [REFERENCE-APPS.md](REFERENCE-APPS.md):

1. Read [the eUTXO model](https://developers.cardano.org/docs/developers/curriculum/fundamentals/core-concepts/eutxo), then [Plutus scripts and eUTXO](https://plutus.cardano.intersectmbo.org/docs/essential-concepts/eutxo). Separate a transaction's deterministic validation from inclusion and finality.
2. Read [datum, redeemer and ScriptContext](https://developers.cardano.org/docs/developers/curriculum/smart-contracts/datum-redeemer-context), then [transaction building](https://developers.cardano.org/docs/developers/curriculum/start-building/transaction-building). Identify what the builder supplies and what the validator must reject.
3. Read the portal's [missing UTXO authentication](https://developers.cardano.org/docs/developers/curriculum/smart-contracts/security/vulnerabilities/missing-utxo-authentication) and [parameter validation](https://developers.cardano.org/docs/developers/curriculum/smart-contracts/advanced/design-patterns/parameter-validation). Follow the full security section from the local index, especially payment attribution and unique continuations.
4. Read normative CIP31/32/33/40 and57 in the pinned `02-standards/cips/` snapshot and [standards report](02-standards/REPORT.md). Distinguish reference reads, consumed state, inline datum, script reuse, collateral and blueprint ABI.
5. Study Aiken vesting/gift-card examples, then Marlowe's evaluator/validator/runtime. Use the local API to look up V3 Contexts, TxOut/TxInInfo, ScriptInfo and signer/time/value fields. Current API landing page states Plutus1.71.0.0, updated2026-09-30 from commit`261766ad1d582bce8c86bad1af7a3b0e5355b21c`; that differs from the research master snapshot. Pin which version an actual experiment uses.
6. Study Minswap authenticated genesis and Sundae's input sorting/output allocation, then Cardano-Loans partial-payment state. Trace the off-chain construction against every validator path. SDK convenience methods do not supply contract semantics.
7. Read [Pyth integration](https://developers.cardano.org/docs/developers/curriculum/dapps/oracles/pyth), [collateral](https://docs.cardano.org/about-cardano/learn/collateral-mechanism) and the [authority report](09-authority-intents/REPORT.md). Distinguish signer trust, freshness, native conservation, liability correctness, fee sponsorship and wallet exposure.
8. Read the [ZK curriculum](https://developers.cardano.org/docs/developers/curriculum/smart-contracts/advanced/zero-knowledge) alongside [private-proof findings](08-private-proofs/REPORT.md). Example verifiers and primitive availability do not establish full Moriarty privacy or certificate soundness.
9. Read [concurrency/Hydra findings](05-concurrency/REPORT.md) before selecting sharding, batching or L2. Shared state, shared authority and exit feasibility determine the actual constraints.

The portal has obsolete linked URLs and client redirect stubs. [Failure dispositions](cardano-developer-docs/FAILURE-DISPOSITIONS.md) names related current sources. An archived changelog absent from the sitemap was downloaded separately in `doc-crawl-supplements/` after a source-route comparison. The sidechain technical specification referenced by a redirect was also downloaded as a PDF. Source reports distinguish capture, scoped inspection and actual experiments; no app or documentation code was executed.

The crawl covers current official portal/docs/Plutus documentation and latest public-library API. Historical API versions, translations, unlinked external ecosystem documentation, private material and static assets are outside that scope. This is a broad retained corpus with a declared coverage boundary, not a claim to have obtained every document ever written about Cardano.
