## Additional security condition: live recovery

The draft must not describe redeployment or a client address change as rollback of an active financial contract. Preserve outstanding duties, pending events, consumed identities and authenticated state. An old unsafe key must be demonstrably disabled on chain before claiming it revoked. Where the current client cannot remove that key, report recovery as blocked until a safe supported operation is established. A maintenance authority is optional if the chosen immutable deployment has an adequate recovery policy. Sources: ZR10/ZR15, UISEC-007/008 and `wiki/midnight-ledger-9-hardfork.md:Contradictions and gaps`.

## Additional assurance condition: deployed source provenance

Keep local reproducible source identity separate from live runtime identity. The scout records a live revision that is not fetchable from public source and a public node branch with a different runtime. This does not block local implementation. It does block claiming that the local build reproduces the deployed verifier. Source: `wiki/midnight-ledger-9-hardfork.md:Contradictions and gaps`.
