## Findings

1. **Keep complete-state independent expectations. Pairwise agreement alone is insufficient.** The existing comparator already tests this distinction. It accepts agreement between two equally altered traces while marking both as wrong against the independent literal oracle. It also catches intermediate environment changes despite equal terminal results. These are strong patterns to extend to C6 and recursion, rather than replace with final-output tests. Evidence: `models/sherlock/qa/test_paired_projection.py:70-112`, especially the `test_agreeing_pair_cannot_replace_independent_literal_expectation` test at line 95.

2. **Do not report zero actual K execution.** The maintained package re-compares retained actual F03 K/Quint outputs. The package test expects fuel 93, observed frame peak 11, 94 edges in each layer, complete projection metadata and matching layers. The same test explicitly requires `refinement = none` and `execution = not-run`, because the comparator does not execute either engine. The source design's later package section documents this historical-producer/current-comparator distinction. Evidence: `models/sherlock/qa/test_model_package.py:12-42`; `docs/sherlock/design.md:154-179`. Old model inventories and the earlier paragraph at `docs/sherlock/design.md:21` are insufficient summaries of the later F03 evidence.

3. **The Quint models have several distinct scopes.** The original `universalMachine` is a three-program algorithm abstraction with scalar maximum 15 and eight heap slots. It is not the generic K interpreter. The generic K-A counterpart uses finite AST/function tables and exact mathematical UInt128 checks, but documents a restricted finite common domain rather than totality on arbitrary machine records. The later interpreter-chunk model bounds fuel at 28, frames at 8, events at 29 and cuts at 3, and samples five named programs. Evidence: `models/sherlock/quint/universalMachine.qnt:1-25`; `models/sherlock/quint/K-PROFILE-README.md:82-126`; `models/sherlock/quint/interpreter-chunks/interpreterChunks.qnt:18-28,65-87`.

4. **A sampled invariant pass is expressly weaker than semantic correctness.** The chunk model's bookkeeping invariant checks chain continuity, program/fuel preservation, charges, bounds and preserved cuts. Its test deliberately changes a coherent literal/publication result from 7 to 0. The altered execution still satisfies that invariant and fails the independent full trace expectation. This is a useful anti-vacuity control and a concrete reason to retain independent semantic oracles. Evidence: `models/sherlock/quint/interpreter-chunks/interpreterChunks.qnt:57-63`; `models/sherlock/quint/interpreter-chunks/interpreterChunks_test.qnt:113-120`.

5. **The recorded finite Quint result is real but bounded.** Its result record reports 44 selected tests, five directed/sampled runs, and 38 reached witnesses. It distinguishes 100 sampled traces per random run from the subset of emitted example traces. It expressly did not run exhaustive verification. Do not turn these counts into full39/full96, field, compiler, circuit or native coverage. Evidence: `docs/results/sherlock-quint-design-20261017/README.md:3-11` and its linked command/source/result records. This audit read those summary facts, not every historical raw log.

6. **Do not silently equate A and B fuel.** K publishes completed return and error at zero charge, ahead of zero-fuel exhaustion. Its structural helper rewrites have no separate semantic-fuel decrement. The current design states that completed B intervals erase to A events only on their common domain, with `W_B = W_A + H_B` under named no-capacity-failure premises. Incomplete B prefixes erase to a saved A origin. Evidence: `models/sherlock/k/main.k:73-107,229-235,288-297`; `docs/sherlock/design.md:85,101`. Acceptance must distinguish equal semantic observations from equal microstep counts.

9. **Raw mutation tests already address an important false-rejection trap.** Scalar arithmetic tests mutate raw field statements and recompute communications commitments from the mutated statement and post-state, except for a separately identified stale-commitment case. The law file's cases cover changed program/shared-state lanes, wrong child context, rule-tag/charge errors, reversed ordering, malformed lengths and height bounds. ## Proposed assurance obligations

These are recommendations, grounded in the distinctions above.

- Freeze each supported profile and its concrete domain, representation relation, outcome precedence, cost clock and target tuple. Map every changed rule to the exact source semantics and circuit relation. A profile change requires requalification of affected edges.
- State semantic soundness separately from witness completeness. For each admitted encoded pre-state and *arbitrary* witness, circuit acceptance must imply a valid semantic successor under the representation relation. Separately show that each supported valid transition has a witness accepted by the circuit. Positive host-generated witnesses alone address neither quantifier completely.
- Establish initialization and preservation of the shared state invariant. A per-rule proof with an assumed invariant cannot justify genesis or an unchecked cross-rule boundary. Dispatch exclusivity, disabled-row semantics, inactive cells, bounds and canonical encodings belong in the composition argument.
- Keep independent normal fixtures and full intermediate-state comparisons. Add generated valid programs with recursion, lexical scope, sharing, nominal types and financial boundaries. Record seeds and shrinking traces. Compare K/Quint/host only on a declared common domain, and classify out-of-domain results explicitly.
- Add adversarial witness tests below admission and witness builders. Mutate each statement field and hidden lane, preserve unrelated bindings, and recompute derived commitments. Record the rejecting layer. A builder refusal is not a circuit rejection.
- Require a deliberate wrong-successor control for every new differential oracle and a missing-constraint control for each critical circuit invariant. A test harness that cannot detect an injected defect cannot close that obligation.
- Verify recursion separately: authenticated genesis, authorized relation/VK identity, exact ordered parent-child statement linkage, complete decider obligations, nonduplicated work/budget and bound rollover. Connect model commitments to real encodings and hash domains.
- Separate local semantic/circuit gates from real proof/decider and target settlement gates. Target acceptance must bind the actual network/version, code/VK, transaction and observed effects. Mainnet deployment needs evidence for the actual post-fork tuple, not an inherited stagenet label.
- In each receipt, record source and oracle hashes, tool versions, command, profile/domain, seeds/bounds, expected observation, actual output, pass/fail/timeout status and unproved premises. Preserve timeouts as operational evidence without converting them into semantic rejection.
