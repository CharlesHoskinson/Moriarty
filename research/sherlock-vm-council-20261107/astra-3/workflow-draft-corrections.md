# Draft workflow corrections

Read against the in-progress draft at 2026-11-07 21:14 UTC, before its formal announcement. These are proposed changes, not implementation evidence.

1. **SWF-005 asks for a commit the existing command cannot make.** `models/doctorwatson/factory/evalloop.py:39-46` runs `git commit --only -- <STATE_FILES>`; the files are `qa/sherlock/status.json` and `qa/sherlock/runs.jsonl`. A deployment receipt cannot be in that same `state-commit` commit. Require the receipt/artifact to be committed and hash-bound to the check, followed by the normal state commit, or name an exact command extension. Prefer the existing two-step path. Add a check that an uncommitted receipt is ineligible and a committed receipt plus its subsequent state commit is eligible.

2. **Strict current-HEAD equality makes recording evidence invalidate it.** E7 marks any run at a prior HEAD stale, while the exit rule requires current-HEAD passes and SWF-005 requires a later commit. The `state-commit` implementation above necessarily advances HEAD. Define freshness by the declared source/configuration/key/target dependency closure; a commit limited to recording the unchanged evidence and factory state must preserve eligibility. Keep the observed run HEAD for provenance. Test that a state-only commit preserves eligibility, while source, key, pins or chain-instance changes invalidate affected evidence. If HEAD-only freshness is retained as an interim conservative signal, it cannot be the final release rule without this exception. SAS-002 already names dependency fingerprints; align E7, workflow §4 and tasks with that model.

3. **Retirement must apply to bulk selection and dependencies.** The current SWF-011 and E10 specify only `next`. The agreed extension must also skip retired rows in `check --tier` and `check --set`, preserve explicit `check A8`, and reject active rows depending on retired rows unless rewired. Otherwise `qa/tiers/t3.sh` can still block on old stagenet after `next` has moved to Preview. This repeats the accepted issue response in `issues-response.md`, with tests for all three command forms.

4. **Profile before choosing S > 1.** Task 4.8 tries S=8 before task 5.3 obtains the complete-path C0 phase profile, although SRC-011 requires the profile before S/concurrency/GPU choices. Move the optional S=8 experiment after the S=1 local-chain profile and retain S=1 if no measured benefit justifies expansion. This does not delay the baseline leaf.
