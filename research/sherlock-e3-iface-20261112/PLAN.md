## 2. Decisions (LEAD unless marked; owner to confirm)

- D-5 Which `L` is under test. `L_iface` = the bench `L` (the 39 AIRs of `L_cached`, same node child, same OD-19 `L` set) plus 4 interface AIRs that carry the 12,164 public words: `StmtAir` (words 0 to 113), `LogEntryAir` (the entry table, words 114 to 625), `LogValueAir` (the value table, words 626 to 2,929) and `CallAir` (the call vector, words 2,930 to 12,163). In vk order the public values of `L_iface` are the index table of ARCHITECTURE 1.11 FP-3 word for word. The two log AIRs check the structural rules of 1.8 (op one-hot with `E = 0`, parameter bounds, `NOP` padding, running sums of values and permutation slots, totals at most `V` and `P`, value rows after `off_n` zero). They do not recompute the onion `d` and do not tie `pv` to a node statement: that is the production `L` (FP-3, M7b), not E3. `L_iface` is a stand-in for the interface, not the production `L`.
- D-6 The public-value carrier (both layers). An AIR of `H = h1 h2` rows carries `n` public words, `w` per row: selector columns `a[h1]` (cyclic one-hot) and `b[h2]` (one-hot that advances when `a` wraps, and is 0 after row `H - 1`), and per value column `c` the degree-3 constraint `v_c = sum_(i,j) a_i b_j pv[(j h1 + i) w + c]` (indices at or above `n` dropped, so those cells are 0). First-row and transition constraints make `a` and `b` unique, and the last-row constraint `a_(h1-1) b_(h2-1) = 1` pins the height to `H`. Each public word is a constant times a selector cell, so the DAG grows by about `2n` nodes. Stock backend only, no preprocessed trace (the `L_Fr` table stays the only one).
- D-2' The `L_Fr` public words: the `L` vk pre-hash, then the 12,164 public words of `L` packed 8 per Fr in vk order: 1 + 1,521 = 1,522 words (D-2 of E2 at the full interface). `PublicAir` becomes the D-6 carrier. As built (2f09caf): 16 words per row (`PUBLIC_W`), 128 rows; program row `[addr_0..addr_15, active, idx]` (18 cells, `PROG_W`), with `active (idx - row) = 0`, so a program row cannot move to another trace row and permute the public blocks (review fix; the first design had `w = 48`, `H = 32` and one base-address cell per row).
- D-7 (superseded by D-10) `R` in `L_Fr`. For an ordinary call (`mode` 0 at word 74) the first 3 entries are `DIGEST` with the tags `SHK_PROGC`, `SHK_INPUT`, `SHK_OUTCOME` (tag indices 0, 2, 3); `L_Fr` asserts the mode word and these 6 entry words against key constants. A log without one of them is refused by `L_Fr`. The chunk mode is not built.
- D-8 (superseded by D-8') Placeholders for the open encodings: the `DIGEST` Fr tag of tag index `k` is `Fr(k + 1)` and the call-vector lane value of a `DIGEST` output is the output itself (ENC-1 and ENC-2 open). These enter only the native reference and the test data, never an `L_Fr` constraint.
- D-9 "The wrap's statement words equal the native ones": the E5 wrap does not exist. The check is a plain-Rust decoder of the `L_Fr` public words (the wrap's reading: unpack, recompose the call-vector lanes, apply the lane map from the `DIGEST` outputs, check each `PUB(i)` against lane `i`) compared with the native statement computed directly from the run. It is reported as that, not as a wrap gate.

## 2b. Phase 2 decisions (owner ruling 2026-11-12 22:10: all-entries accepted, gate passed; J6 only if it fits; then ENC-1/ENC-2, the FP-3 onion tie, chunk-mode `R`; recommended options, marked for confirmation)

- D-8' (replaces D-8) ENC-1 and ENC-2 as written in `research/sherlock-enc-fp3-20261112/RESULTS.md` (owner rulings P-1, P-2): `tagFr(k)` is the ASCII name of tag `k` as a little-endian `u128`; the tag list has 6 entries (`SHK_REG` 4, `SHK_SET` 5), so the `DIGEST` bound is `0 <= param <= 5`; `DIGEST` logs `(pack(d2), PoseidonFr_4(tagFr(k), pack(d2)))`; `enc(e) = [op, param] ++ limbs(v_0) ++ ...`. Still a placeholder: the `PATH` node order (`H2(l, r)` by the index bit), which no text fixes.
- D-10 (LEAD, for confirmation) `R` after FP-3, in this order: entries 0 to 2 `DIGEST(SHK_PROGC)`, `DIGEST(SHK_INPUT)`, `DIGEST(SHK_OUTCOME)`; entry 3 `SPONGE(3)` of `claim_pub` over their 3 outputs; entry 4 the `a_in` anchor `DIGEST(tag_in)`; for a chunk, entry 5 the `a_out` anchor `DIGEST(tag_out)`. So `e_in = 4`, `e_out = 4 + mode`, and an ordinary call has 5 entries, 12 values, 6 permutations, a chunk 6, 14, 7 (ARCHITECTURE 1.8 counts). The run entries come first so that their positions do not depend on `mode`. Anchor rule: `tag_in = SHK_PROGC` if ORD or `j = 1`, else `SHK_LOCK`; `tag_out = SHK_PROGC` if ORD or `j = k`, else `SHK_LOCK`; `j`, `k` as `u32` in little-endian 16-bit limbs (I-1). `L_Fr` checks it with two zero tests (advice inputs). Not checked here: the opening-proof `R` with `DIGEST(SHK_SET)`, check (i) on the operands (an `L` obligation), the `popeq` lane against `a_in` (a lane-map pair, read by the decoder only).
- D-11 (LEAD, for confirmation) J7, the part of J6 that fits: native replay of `R` only in `L_Fr` (its 6 or 7 permutations), logged values entered as `sum_i limb_i 2^(30 i)` by `Pack` and `FrAdd` doubling (257 ops per value); limb range and `Canon` stay with the reader (D-9). The full replay of every entry (J6) does not fit (section J6 of RESULTS.md).
- D-12 (LEAD, for confirmation) J8, the onion in the bench `L`: an `OnionAir` (70 columns, one row per Poseidon2 permutation) recomputes `d` over the entry and value tables for one log segment; each permutation is a lookup on the permute bus of the bench `L`'s `Poseidon2Air` (external inputs of its trace generation); the absorbed words come from `LogEntry` and `LogValue` by permutation buses 901 and 902; the final `(d, n)` must equal `log_d`, `log_n` (root statement words 57 to 65) in `Stmt` (bus 903). Not built: more than one segment (`TAG_NODE` merges) and the tie of the root statement to a verified FP-2 node (the bench node is not one). The `L_Fr` cost is gated: J4 fails if `BbAlu` or `ProgramTable` leaves 2^19.
