# Concrete Φ₀ evaluation for MIL/4

**Status:** specified-only K proposal, 2026-09-29. [`sol-formula.k`](sol-formula.k) imports the static module and exports `M4F-FORMULA`. It declares no configuration and has not been parsed or executed in K.

`m4fEvaluate(env, formula, phase, frame, fuel)` first calls `m4sStatic`. A formation rejection becomes `m4fReject(code)`. On successful formation, it checks a finite value frame and evaluates the formula to `m4fTrue()`, `m4fFalse()` or `m4fReject(code)`. The result is computed from concrete integer values; no Boolean verdict, oracle answer or arithmetic quotient is supplied by the caller.

The frame names a pre-state head and post-state head and has separate pre, post and hole value lists. Each entry carries a declared type, integer value and head. Entries must match the corresponding static binding, fit its signed or unsigned width, have no duplicate key and match the frame head. A referenced cell or hole absent from the frame rejects as `MISSING_AUTHENTICATED_READ`; a head mismatch rejects. `post` in a guard rejects during static formation. The stage relation must establish that the supplied heads and cell values really come from authenticated state. This module checks consistency with those heads but does not verify commitments, signatures, ledger roots or cryptographic proofs.

Term evaluation covers `u128` and typed quantity/price literals, concrete pre/post reads, holes, checked quantity/delta and same-clock instant/duration arithmetic, min/max and multiplication by a declared literal coefficient. Add/subtract and multiplication check the result width; subtraction of unsigned values rejects underflow. The finite formula evaluator covers equality, strict and non-strict comparison, atomic negation, conjunction, disjunction and `k_of_n`. Each threshold formula is evaluated and counted, with `1 ≤ k ≤ n ≤ 128`. Both arms of `and` and `or` are evaluated, so a reject in either arm is never hidden by the other arm's Boolean result. Fuel bounds all recursive evaluation, including the empty list case.

Oracle terms, uncertified Ω calls, variable products and unsupported formula constructors return the open or unsupported rejection from the static module. They cannot evaluate to true by providing a value in the frame. `m4fTrue()` means only that this concrete, typed Φ₀ formula holds under the supplied frame. A MIL/4 stage still needs exact signed bytes, selected program execution, authenticated reads, authority, complete effects, history and failure handling before acceptance.
