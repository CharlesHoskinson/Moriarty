## Decisions that must be frozen before implementation

1. Exact action authority: lender funding plus debtor consent at origination, explicit accrue permission, borrower funding authority at repayment/settlement, all bound to terms/cap/program/head. The existing two constructor secrets and maintenance signing key do not establish that contract by themselves. No blanket lender settlement authority is inferred.
2. Exact full state/history encoding and decoder, preserving every field, bound, ordered identity namespace and complete effects. A compiler limit cannot silently omit fields or shrink the accepted language. Use the existing ledger history; add no generic history framework.
3. Actual existing lender funding path and borrower continuation path, native asset identity and initialization reserve provenance. The current single borrower payer and fixed20-billion borrower mint fail this predicate.
4. Exact source-derived lowerer outputs and versioned generator/build/loader/SDK/comparator consumers. The current fixed recovery plan must remain historical. `run-local.mjs`, `build-proven.mjs`, `proven-assets.mjs` and `financial-comparison.mjs` are necessary consumers beyond the original draft’s shortened file list.

These are concrete LL04 contract decisions, not a new design program. Independent contract review can resolve them under existing authority before one writer changes behavior. Missing live accounting blocks dependent financial dispatch; it does not block this preparation or LL01 repair.
