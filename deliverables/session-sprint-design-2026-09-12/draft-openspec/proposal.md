# Change: Complete the preserved session through evidence-gated sprints

## Why

The preserved branch contains merged local language work and unfinished K and ledger integration. A source approval, historical test result, or recorded blocker cannot establish current execution acceptance. This change organizes the remaining work into nine sprints with explicit dependencies, complete evidence, and separate source, dispatch, process, and financial decisions.

## What Changes

- Preserve PR1–PR7 and the original requirement identities. Reconcile current evidence without resetting user work or resource history.
- Repair the retained K diagnostic, run one admitted diagnostic, and complete scoped K/evaluator agreement.
- Implement authenticated Source5-to-Compact lowering and the already specified SDK executor and prover lifetime boundary.
- Compile the actual lifecycle contract, then complete Docker and separately admitted Preview execution.
- Reconcile branch delivery against the retained native goal and wider program gates.

## Impact

Proposed capability: `session-completion-sprints`. This package is a draft under `deliverables/session-sprint-design-2026-09-12/draft-openspec/`. It does not install a change into `openspec/changes/`, modify existing specifications, admit execution, or publish source.

Implementation would affect the existing K shim and language K backend, financial custody and ledger consumer, and repository plugin executor. Exact existing and proposed paths appear in `design.md` and `tasks.md`. Proposed evidence lives under `deliverables/language-to-ledger-2026-09-12/sprints/LL01/` through `LL09/`.

## Scope and Non-goals

The terminal decision is whether the remaining session branch outcomes have current, independently reviewed acceptance evidence. Full language metatheorems, correspondence proofs, MC01–MC08, SP01–SP12, PCD, private handoff, ACTUS, and DeFi obligations remain separately qualified. No new scheduler, admission framework, standalone accounting sprint, public network, wallet identity, or resource capacity is introduced.

Four actual provider proposals inform this draft. Their agreement is not a four-member audit or consensus. `../planning-reconciliation.md` records accepted contributions, rejected alternatives, provenance, and the original obligation mapping.
