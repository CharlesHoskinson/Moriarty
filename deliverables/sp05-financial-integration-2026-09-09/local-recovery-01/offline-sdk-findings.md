# Offline SDK public recovery diagnosis

Repository observation: the failed runner discards the cause at two boundaries. `execute-once.py:137` catches the JavaScript error without binding it and emits only `RECOVERY_PUBLIC_PREFLIGHT_FAILED`. Its `run` helper at line 43 captures stdout/stderr and raises `CalledProcessError`; the outer failure record does not retain that output. Retaining Python stderr alone would still provide no underlying public-preflight cause.

Experiment observation: `offline-sdk-fixture.mjs` uses the actual pinned indexer provider, an ephemeral loopback HTTP server, the retained native deployment transaction, and its serialized native initial state. The complete synthetic GraphQL response passes `verifyExistingLoanPublic`, including the SDK transaction/state deserializers, historical observer, current full-state comparison and stable final-head check. Final artifact output is `offline-sdk-compatible-02.json`; the original compatible run remains in `offline-sdk-fixture-result.json`. This is fixture compatibility, not real chain evidence.

Experiment observation: synthetic GraphQL rejection reaches the helper as `IndexerQueryError` with its diagnostic message. See `offline-sdk-schema-reject-result.json` (expected process exit 1). It is not evidence of an actual schema rejection. Both modes were run under `timeout --signal=TERM --kill-after=1s 10s`; both exited before the bound, closed the server and had empty stderr. The script has no wallet or private-store operations.

Source observation: the pinned provider emits `TX_ID_QUERY` with `offset.identifier` and deserializes the returned hex `raw` through the protocol ledger. It maps `SUCCESS` to `SucceedEntirely`, preserves identifiers/hash/protocol/fees and maps unshielded arrays. `queryContractState` and `queryUnshieldedBalances` emit `offset.blockOffset.hash`, as supplied by the existing observer. Contract state is deserialized through the protocol Compact runtime; the fixture shows its serialization passes the ledger-native equality check. Actual query strings and variables are retained in fixture outputs. The inspected SDK entry SHA256 is `23a1883b796fbea037817ae0a7e0f5ed3c072a7d30974154a8de917893cd7f2f`.

Coverage gap: the retained actual `indexed-success-observation.json` contains hash, SUCCESS and block identity only. It cannot establish availability or encoding of raw transaction bytes, complete state, protocolVersion, fee strings, identifiers or unshielded rows under the full SDK queries. No retained indexer GraphQL schema was found in the scoped repository filename search. The fixture supplies compatible values for these fields and therefore cannot prove the actual indexer supports them. Missing contract state, a newer changed state, finality, deadline and server-schema failures remain distinct possibilities, not findings about the actual run.

No implementation sources were edited. No blockchain services, wallet, proof server or real private files were accessed. An actual failure cause remains unknown; the smallest missing evidence is a classified public error captured at the JavaScript catch boundary during a separately authorized read-only run.
