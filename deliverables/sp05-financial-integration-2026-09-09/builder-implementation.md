## Interface

Exports:

- inspectBuildSources(): read-only source manifest, schema moriarty.financial-build-sources/1, files as ordered {path,sha256}. Exact mandatory set: all custody PIN_PATHS, generator, bindings, both stored wrappers, this builder. Paths are relative to the current builder checkout; no unpinned source additions are accepted.
- sourceManifestHash(manifest): SHA256 of JSON.stringify(manifest). This is the builder sourceCandidateSha/candidateHash, not an assertion of whole-SP05 acceptance.
- async buildProven(options): one case loan or swap; no retry.

Options:

    {
      case: 'loan' | 'swap',
      outputDir: '/absolute/existing-parent/new-output',
      sourceManifest: inspectBuildSources(),
      admission: {
        id: 'actual-admission-identity', resourceId: 'actual-allocation-identity',
        candidateHash: sourceManifestHash(sourceManifest),
        case: 'loan' | 'swap', outputDir: '/same/new-output',
        allowFullBuild: true, maxCompileMs: POSITIVE_SAFE_INTEGER,
        deadlineMs: ABSOLUTE_MILLISECONDS, maxAttempts: 1,
        resourceRecord: {path: '/immutable/resource.json', sha256: EXACT_DIGEST},
        reviews: [{path: '/immutable/review-binding.json', sha256: EXACT_DIGEST}]
      },
      resourceCounters: {resourceId: SAME_ID, maxAttempts: 1, attempts: 0}
    }

Resource JSON must bind {id:resourceId,sourceCandidateSha:candidateHash,case,outputDir,maxCompileMs,deadlineMs,maxAttempts:1,attemptFile:'/existing-parent/persistent-exclusive-attempt.json'}. Its path is read/hash checked; attempts cannot reside inside disposable build output. A resource attempt file is created with wx and fsynced, including its parent directory, BEFORE any version or compile subprocess. It remains after success/failure. Resetting passed counters or deleting output does not permit reuse. The root must supply the real immutable reviewed allocation, not fabricate a new allocation to reset prior charges.

Each referenced review JSON must bind sourceCandidateSha and verdict:'APPROVED'. Builder validates actual file digests and candidate/verdict fields only. It does not authenticate auditor identities, independence, substantive scope or votes. Root must inspect actual required audits under current GPT-6/Opus routing before guarded dispatch. reviewed:true alone has no authority and is not used.

CLI: node .../ledger/build-proven.mjs --request REQUEST.json. Request holds the same serializable options. CLI disallows commandAdapter. No commands are run on module import or manifest inspection.
