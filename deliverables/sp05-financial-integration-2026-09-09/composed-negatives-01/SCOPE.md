# Composed negative controls

These seven source tests connect integrateLocalFinancialCase, runLocalFinancialCase, observeFinalizedStage and createFinancialComparator. Retained actual loan native bytes drive the installed decoder and native checks. Transport, SDK submission and reservation counters are controlled. Capability commitments are replaced with synthetic test-secret commitments in the decoded state fixture; no private evidence is read.

The control matches all four loan stages. Rejections cover a changed payer binding, wrong indexed recipient, missing wire fee fields, missing receipt fee fields, understated native debit and wrong payer in the observed native input. Each asserts the exact stop point, charged counters, cleanup and public failure record. The production retention function must reject sourceTestOnly data; separate scratch files retain explicitly labelled source-only results during the test and are removed afterwards.

These tests do not establish live Docker rejection/nonmutation or Preview settlement. They add no production behavior, operational allocation or dispatch. Source10 swap runtime and its independent resource admission remain unchanged.
