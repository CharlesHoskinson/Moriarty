Reuse existing `submitCallTx`, proof/balance guards, per-balance freshness checks, stage retention and cleanup. Bind USD_TEST_ASSET to the retained address using existing `rawTokenType` logic, never a newly prepared address.

The fresh allocation permits **three remaining submissions**, with reviewed DUST/gross-debit limits and existing outer containment. The complete financial trace contains four real stages spanning two allocations: historical deployment plus three new calls. Original deployment and earlier unsuccessful-attempt charges remain in their original records and in cumulative resource accounting. Historical observation must not charge a second deployment or refund its first charge. No old stopped reservation journal is resumed or edited. The launch validator currently hard-codes four submissions and must allow exactly three only for this verified recovery branch.

## Required tests before runtime authorization

- Offline replay of actual retained deployment bytes establishes address/identifiers and verifier/constructor/authority checks; altered raw bytes, address, role capability, network binding, key, verifier or current initialized state fails before writes.
- Existing driver with inert providers records the actual old deploy stage and exactly three calls; any deploy/prove/balance/submit during recovery setup fails the test. Old evidence is not rewritten and the comparator counts the historical deployment once.
- Synthetic copied stores: metadata-only succeeds; any private/signing value, malformed metadata, unexpected account or symlink fails. Original fixture files remain byte-identical. New-store validation and round-trip failure stop before financial operations.
- Invalid password fails before wallet restore; a valid password permits exact provider set/read in an isolated fixture. No original secret/password appears in output.
- Finality/indexer mismatch, unavailable original transaction, wrong current state, stale tip, session catch-up, deadline and remaining-budget exhaustion stop without a new transaction. Existing source tests do not replace actual three-stage settlement evidence.
