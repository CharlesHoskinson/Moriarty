# AMM primary-source notes for recommendation agents

Captured for orientation on 2026-09-29. These are comparative protocol designs, not evidence that Moriarty implements the same behavior. The links below are official source specifications or maintained implementation code. Use only the details relevant to the assigned lens; do not copy a protocol's rule into MIL/2 without checking its product constraints and finite-width/native cost.

- [Uniswap v2 pair implementation](https://github.com/Uniswap/v2-core/blob/master/contracts/UniswapV2Pair.sol), `swap`, `mint`, `burn`: the swap checks fee-adjusted post balances against pre reserves; mint has a separate zero-supply path that permanently locks a minimum share amount; burn calculates two pro-rata asset outputs. The fee-adjusted invariant involves variable products, so it is not the Φ₀ literal-multiplication fragment. The code also has a callback/flash path that MIL/2 expressly excludes.
- [ERC-4626 vault standard](https://eips.ethereum.org/EIPS/eip-4626): the four mutable share/asset operations have different preview and rounding directions. Its `convertTo*` views are fee-free and caller-independent, while the corresponding previews account for execution terms. The standard is for one underlying asset; a two-asset LP position needs a distinct pool contract, even if some share-accounting ideas transfer.
- [Balancer weighted pool math implementation](https://github.com/balancer/balancer-v2-monorepo/blob/master/pkg/pool-weighted/contracts/WeightedMath.sol): weighted pools impose bounded input/output ratios and explicit rounding choices around powers, invariant calculations, and joins/exits. This illustrates why a general weighted-pool family is a later arithmetic profile rather than a trivial Φ₀ library.
- [Uniswap v3 core whitepaper](https://app.uniswap.org/whitepaper-v3.pdf): concentrated liquidity has range/tick state and nonfungible position behavior. MIL/2 already places it out of the current version; use this source to scope the deferred extension, not to relabel it covered.
