The Anoma Protocol Adapter
The “protocol adapter” is a smart contract deployed to an EVM chain which enables Anoma
applications such as AnomaPay to be run on that chain. Even if the off-chain services go down, the funds on-chain are governed by the smart contract, which guarantees funds can only be moved with a valid proof. Any user can decide to run the off-chain infrastructure themselves and execute AnomaPay transactions powered by fully client-side proofs.
