The Canton Network ecosystem encompasses the organizations, applications, and infrastructure that make up the network. This page provides an overview of the ecosystem landscape.
​
Ecosystem Overview
​
Governance
​
Canton Foundation (CF)
The CF is an independent, non-profit body under the Linux Foundation that governs the Global Synchronizer.
Responsibility
Description
Network policies
Set parameters and rules
Upgrade coordination
Manage network upgrades
SV oversight
Oversee Super Validator participation
Ecosystem development
Foster network growth
Learn more:
canton.foundation

Infrastructure Participants
​
Super Validators
Super Validators operate the Global Synchronizer infrastructure and participate in governance.
Role
Function
Sequencer operation
Order transactions
Mediator operation
Aggregate confirmations
Governance
Vote on network parameters
Sponsorship
Onboard new validators
The current Super Validator set includes major financial institutions and technology providers.
​
Validators
Validators host parties and run participant nodes connected to the Global Synchronizer.
Type
Description
Enterprise validators
Run by organizations for their own parties
Service providers
Offer validator services to others
Application operators
Run validators for specific applications
