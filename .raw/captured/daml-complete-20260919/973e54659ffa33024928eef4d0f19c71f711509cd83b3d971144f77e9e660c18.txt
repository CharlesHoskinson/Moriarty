Splice nodes expose REST APIs that are separate from the
Ledger API
and the
Admin API
. These APIs are served by the Splice application layer running on top of Canton and provide access to Canton Network-specific functionality: querying network state, managing wallets, operating validators, and governing the network as a Super Validator (SV).

Authentication
All Splice APIs except the public Scan API require a JWT token passed as an
OAuth2 Bearer token
:
Authorization: Bearer <your-token>
The Scan API is publicly accessible and does not require authentication.
​
OpenAPI Specifications
The full set of OpenAPI specifications is published in the
Splice repository
:
scan.yaml
— Scan API
wallet-external.yaml
— Wallet API (external)
ans-external.yaml
— ANS API (external)
validator-internal.yaml
— Validator API (internal)
sv-internal.yaml
— SV API (internal)
scan-proxy.yaml
— Scan Proxy API
Endpoints in files named
*-external
carry backwards compatibility guarantees. Endpoints in
*-internal
files may change between releases without notice.
