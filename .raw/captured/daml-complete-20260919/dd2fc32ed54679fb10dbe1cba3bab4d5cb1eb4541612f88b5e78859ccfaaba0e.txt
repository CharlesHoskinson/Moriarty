Key Canton Console commands for health checks, party management, package management, and topology inspection
Copy page
Copy page
This reference covers the most commonly used Canton Console commands, organized by task. All examples assume you’re connected to a participant console unless otherwise noted.
When the Canton Console starts, it reads the configuration file and automatically binds a variable for each configured node. For example, if your configuration defines a participant node, the console makes it available as the
participant
variable (or whatever name you gave it in the config). You can use this variable directly to call commands like
participant.health.status
without any additional setup.
