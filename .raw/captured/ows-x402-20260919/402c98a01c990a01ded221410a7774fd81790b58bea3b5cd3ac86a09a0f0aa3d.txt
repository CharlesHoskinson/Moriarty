Integrations connect x402 payments and service discovery to platforms where you build and run
agents. Use one when your agent platform provides its own payment workflow instead of connecting an
agentic account directly.
Amazon Bedrock AgentCore
Give an AgentCore agent access to x402 services through an AWS Payment Manager and Coinbase CDP
connector.
Payment Acceptance API
x402-enable a merchant checkout built on Payment Acceptance so agents can authorize payment
sessions directly.
