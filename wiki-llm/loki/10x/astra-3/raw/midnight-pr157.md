Description
-----------

This PR integrates GPU acceleration for zero-knowledge proof generation using the ICICLE v4.0.0 CUDA backend, providing significant performance improvements for circuits with K≥14 (≥16,384 constraints).

### Key Changes

**GPU Backend Integration (`proofs/src/gpu/`)**

* Complete ICICLE v4.0.0 CUDA backend integration with automatic backend detection
* Smart MSM (Multi-Scalar Multiplication) dispatch: CPU (BLST) for small operations, GPU (ICICLE) for large operations
* Configurable GPU thresholds with automatic fallback to CPU
* Batch processing support for efficient GPU memory utilization
* Type-safe GPU operations with proper error handling

**Core Proof System Enhancements**

* Updated `plonk/prover.rs` with GPU-accelerated commitment generation
* Enhanced `poly/kzg/msm.rs` with hybrid CPU/GPU MSM strategy
* Extended `poly/kzg/params.rs` with GPU-aware parameter handling
* Modified `plonk/vanishing/prover.rs` and `plonk/lookup/prover.rs` for GPU support

**Testing & Benchmarks**

* `tests/e2e_proof_benchmark.rs` - End-to-end GPU vs CPU proof generation benchmarks
* `tests/gpu_integration.rs` - GPU backend integration tests
* `tests/msm_blst_detection.rs` - BLST CPU fallback verification
* `tests/batch_test.rs` - Batch processing tests
* `examples/gpu_benchmark.rs` - Standalone GPU benchmark
* `examples/plonk_msm_benchmark.rs` - MSM operation benchmarks
* `examples/proof_generation_benchmark.rs` - Comprehensive proof benchmarks
