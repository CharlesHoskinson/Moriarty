Impeller zkEVM evaluation circuits
==================================

This repository contains the Inker zkEVM circuits and aggregation workloads used to evaluate Impeller. It builds against the matching [Halo2 integration](https://github.com/SJTU-Liquid/halo2) and [Impeller compiler](https://github.com/SJTU-Liquid/Impeller).

Papers
------

* **Impeller: Scalable and Efficient Zero-Knowledge Proof Computation Framework via Graph Compilation.** Liukun Yu\*, Xinwei Qiang\*, Shixuan Sun, Chen Chen, Jingwen Leng, and Jin Dong. ASPLOS 2027. This repository supplies the paper's zkEVM and aggregation circuit workloads.
* **[FluxZK: Scalable and Efficient Zero-Knowledge Proof Computation via GPU Acceleration](https://sc26.conference-program.com/presentation/?id=pap593&sess=sess231).** Xinwei Qiang\*, Liukun Yu\*, Xiyu Wang, Zhengyi Li, Shixuan Sun, Jingwen Leng, Chen Chen, Jiaping Gui, Zhenzhe Zheng, Jin Dong, and Minyi Guo. SC 2026. The Impeller GPU implementation adapts kernels from the [FluxZK repository](https://github.com/SJTU-Liquid/FluxZK).

\* Equal contribution.

This release is based on `tie-pilot-qxw/zkevm-circuits` commit `51200300d1f4359c2ffc4b6acb1247f9d33c4745` (`artifect-evaluation`).

The [snark-verifier](https://github.com/SJTU-Liquid/snark-verifier) submodule pins commit `53678c63ebf040fed35b395a7b7522e02e492f84`, a snapshot of `tie-pilot-qxw/snark-verifier` commit `076aa8f11805145f2f0f3ca0aaba68c7df4f0c99`. It pins [halo2-lib](https://github.com/SJTU-Liquid/halo2-lib) commit `4cfcb29375017e93b547472b0d01a58355f19eb6`, a snapshot of `tie-pilot-qxw/halo2-lib` commit `2fbefca7c6aa7deea9e3b0627c1fe3af70fc7a5a`. These two forks adapt aggregation proof generation to Impeller's Halo2 interface.

Checkout and requirements
-------------------------

Clone Halo2 and this repository into the same parent directory. Cargo uses a sibling path to `halo2/halo2_proofs`; recursive cloning resolves the compiler, verifier, and `halo2-lib` submodules.

```
git clone --recurse-submodules https://github.com/SJTU-Liquid/halo2.git halo2
git clone --recurse-submodules https://github.com/SJTU-Liquid/zkevm-circuits.git zkevm-circuits
cd zkevm-circuits
export ZKPOLY_COMPILER_PROJECT_ROOT="$(pwd)/../halo2/zkpoly-compiler"
export AE_SCRATCH_DIR="$(pwd)/target/ae-scratch"
```

This release pins Rust nightly `2025-09-20`. The paper setup used CUDA 12.8, NVIDIA GPUs, and `xmake`. Full-size zkEVM benchmarks also require substantial host memory and GPU memory; use the small configuration first.

The main packages are `zkevm-circuits` (circuits and benchmarks), `aggregate-zkevm` (aggregation), `prover` (proof service), `eth-types`, `gadgets`, `keccak256`, `poseidon`, and `trace-parser`.

Unit tests
----------

Run a focused circuit test or the zkEVM package tests:

```
cargo test -p zkevm-circuits super_circuit::tests::test_super_circuit
cargo test -p zkevm-circuits
```

Tests that invoke the `evm` executable also need the `evm` feature. Install the executable from [go-ethereum](https://github.com/ethereum/go-ethereum) and make it available on `PATH`:

```
cargo test -p zkevm-circuits --features "default,evm"
```

Proof benchmarks
----------------

The default `fast_test` feature uses a small circuit (typically at least 16 GB of host memory). Generate parameters and then run the super circuit:

```
cargo test -p zkevm-circuits --profile bench --bench benchmark_list -- init_proof_params --nocapture
USEFILE=true cargo test -p zkevm-circuits --profile bench --bench benchmark_list -- super_circuit --nocapture
```

For the standard degree-19 configuration (typically at least 256 GB of host memory), disable `fast_test`:

```
cargo test -p zkevm-circuits --profile bench --no-default-features --bench benchmark_list -- init_proof_params --nocapture
USEFILE=true cargo test -p zkevm-circuits --profile bench --no-default-features --bench benchmark_list -- super_circuit --nocapture
```

Omit `USEFILE=true` to regenerate the parameters and keys on each run. Set `ROUND=10` to run ten rounds. `AE_SCRATCH_DIR` selects the disk spill directory; it defaults to `target/ae-scratch`. Other artifact paths can be set with `AE_DEBUG_DIR`, `AE_KERNEL_DIR`, `AE_ARTIFACT_DIR`, and `AE_PROCESSED_TYPE2_DIR`.

The optional scripts under [`scripts/`](/SJTU-Liquid/zkevm-circuits/blob/main/scripts) collect benchmark and system metrics. They use `sysstat`; Grafana reporting additionally needs Python, MySQL, and Grafana. These reporting services are not required for the proof benchmarks above.
