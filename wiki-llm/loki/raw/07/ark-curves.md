Curve implementations
=====================

This repository contains implementations of some popular elliptic curves. The curve API implemented here matches the curve traits defined in [ark-ec](https://github.com/arkworks-rs/algebra/blob/master/ec/src/lib.rs).

### BLS12-381 and embedded curves

* [`ark-bls12-381`](/arkworks-rs/algebra/blob/master/curves/bls12_381): Implements the BLS12-381 pairing-friendly curve
* [`ark-ed-on-bls12-381`](/arkworks-rs/algebra/blob/master/curves/ed_on_bls12_381): Implements a Twisted Edwards curve atop the scalar field of BLS12-381
* [`ark-ed-on-bls12-381-bandersnatch`](/arkworks-rs/algebra/blob/master/curves/ed_on_bls12_381_bandersnatch): Implements Bandersnatch, another Twisted Edwards curve atop the scalar field of BLS12-381

### BLS12-377 and related curves

* [`ark-bls12-377`](/arkworks-rs/algebra/blob/master/curves/bls12_377): Implements the BLS12-377 pairing-friendly curve
* [`ark-ed-on-bls12-377`](/arkworks-rs/algebra/blob/master/curves/ed_on_bls12_377): Implements a Twisted Edwards curve atop the scalar field of BLS12-377
* [`ark-bw6-761`](/arkworks-rs/algebra/blob/master/curves/bw6_761): Implements the BW6-761 pairing-friendly curve, which is a curve whose scalar field equals the base field of BLS12-377
* [`ark-ed-on-bw6-761`](/arkworks-rs/algebra/blob/master/curves/ed_on_bw6_761): Implements a Twisted Edwards curve atop the scalar field of BW6-761
* [`ark-cp6-782`](/arkworks-rs/algebra/blob/master/curves/cp6_782): Implements the CP6-782 pairing-friendly curve, which is a curve whose scalar field equals the base field of BLS12-377
* [`ark-ed-on-cp6-782`](/arkworks-rs/algebra/blob/master/curves/ed_on_cp6_782): Implements a Twisted Edwards curve atop the scalar field of CP6-782. This is the same curve as in `ark-ed-on-bw6-761`

### BN254 and related curves

* [`ark-bn254`](/arkworks-rs/algebra/blob/master/curves/bn254): Implements the BN254 pairing-friendly curve
* [`ark-ed-on-bn254`](/arkworks-rs/algebra/blob/master/curves/ed_on_bn254): Implements a Twisted Edwards curve atop the scalar field of BN254
* [`ark-grumpkin`](/arkworks-rs/algebra/blob/master/curves/grumpkin): Implements the Grumpkin curve. A curve that forms a cycle with bn254.

### MNT-298 cycle of curves and related curves

* [`ark-mnt4-298`](/arkworks-rs/algebra/blob/master/curves/mnt4_298): Implements the MNT4-298 pairing-friendly curve. This curve forms a pairing-friendly cycle with MNT6-298
* [`ark-mnt6-298`](/arkworks-rs/algebra/blob/master/curves/mnt6_298): Implements the MNT6-298 pairing-friendly curve. This curve forms a pairing-friendly cycle with MNT4-298
* [`ark-ed-on-mnt4-298`](/arkworks-rs/algebra/blob/master/curves/ed_on_mnt4_298): Implements a Twisted Edwards curve atop the scalar field of MNT4-298

### MNT-753 cycle of curves and related curves

* [`ark-mnt4-753`](/arkworks-rs/algebra/blob/master/curves/mnt4_753): Implements the MNT4-753 pairing-friendly curve. This curve forms a pairing-friendly cycle with MNT6-753
* [`ark-mnt6-753`](/arkworks-rs/algebra/blob/master/curves/mnt6_753): Implements the MNT6-753 pairing-friendly curve. This curve forms a pairing-friendly cycle with MNT4-753
* [`ark-ed-on-mnt4-753`](/arkworks-rs/algebra/blob/master/curves/ed_on_mnt4_753): Implements a Twisted Edwards curve atop the scalar field of MNT4-753

### [Pasta](https://electriccoin.co/blog/the-pasta-curves-for-halo-2-and-beyond/) cycle of curves

* [`ark-pallas`](/arkworks-rs/algebra/blob/master/curves/pallas): Implements Pallas, a prime-order curve that forms an amicable pair with Vesta
* [`ark-vesta`](/arkworks-rs/algebra/blob/master/curves/vesta): Implements Vesta, a prime-order curve that forms an amicable pair with Pallas
