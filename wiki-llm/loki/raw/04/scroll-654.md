### Describe the feature you would like

Current CI only includes mock proving of circuit, but sometimes even mock proving can pass, real proving & verification can fail. (problems like fixed column not really fixed... etc). So real proving is useful. If real proving needs more than 15 or 20 minutes, we may not need to run it each CI, but nightly, or using github action bot (comment "\b run real-prove") in PR comment
