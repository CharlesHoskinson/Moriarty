# Note service desk

Original local S0 servicing example for one term note. Run `mori check servicing.mori`, `mori test .`, or `mori simulate servicing.mori --action service_installment --scenario scenarios/installment.json`.

Scenario files are untrusted local stipulations. PreparedUnqualified does not sign, authenticate, prove, or commit a ledger transaction. `originate`, `roll`, and `liquidate` are SpecifiedOnly and do not execute.
