# Moriarty wiki-llm

This directory holds reviewable architecture notes produced from model-assisted research. A note must link its primary sources, raw model proposals, exact model identities, disagreements, and empirical limits. It does not define the adopted Moriarty language, replace `wiki/` provenance records, or establish compiler, proof, or ledger acceptance.
