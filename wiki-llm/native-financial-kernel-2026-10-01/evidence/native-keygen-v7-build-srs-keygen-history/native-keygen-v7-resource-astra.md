CPU/RSS are sampled nominally every 0.1 s, disks every 5 s. Filesystem traversal and scheduling add monitor latency; overshoot is possible. Aggregate CPU uses live process-group accounting plus waited-child CPU fields; per-process AS/CPU/FSIZE are hard supplemental limits, not hard aggregate quotas. Rayon 2 limits its pool, not all native threads. Global nonloopback RX includes unrelated host traffic and is measured at start/end. Parent hashing and other parent work lie outside the child budgets, so 1,020/960 are the phase allocations, not a hard end-to-end supervisor timing guarantee. Catchable cleanup owns/kills the process group; uncatchable supervisor SIGKILL/power loss cannot execute cleanup. The fsynced exclusive reservation blocks automatic reuse after such interruption.
