# Compact mapping experiment evidence

Experiment observation: six runtime suites passed using the generic source-Core mapper and pinned Compact 0.31.1 / language 0.23.0 / runtime 0.16.0. The independent source evaluator and generated Compact kernels agree on every numeric state field and source-order typed effect operand for loan accrual/settlement and swap/closure. All per-node multiplication/division hints were corrupted in negative controls and rejected. Dynamic overflow before a later fitting division, bad minimum output, actor IDs, state order, expiry, reset and closure reserve also reject.

`commands.json` retains version checks, materialization, the exact four `compact compile --skip-zk` commands, runtime test output and strict TypeScript output. `receipt.json` pins mapper/test/helper/example sources and every retained compiler artifact. `compiled/` contains the four resulting compiler/JS artifacts and both snapshot harnesses' exported ZKIR. No keys or proofs were generated. Generated source and companion metadata are in `experiments/moriarty-language/compact/generated/`.

The initial test failed with `ERR_MODULE_NOT_FOUND` before `src/lower-compact.ts` existed. The implementation subsequently compiled both kernels on its first compiler attempt. One strict TypeScript closure-narrowing error was corrected by retaining the already checked metadata reference; no runtime behavior changed.

The mapping is intentionally restricted. Persistent/observed Text and And/Or reject. Every Text argument requires an exact unconditional equality guard against static source Text, and all accepted Text values use collision-free sorted-table IDs. The typed Core's unit vectors, policies, source references and program hash remain in companion records; UInt128 alone does not prove the nominal unit or source-input binding to an external caller.

The generated snapshot wrappers store kernel results only to exercise compiler ZKIR and runtime state atomicity. They do not transfer financial assets or stand in for settlement. Obligation-ledger state/tombstones, settlement quantum conversion, authority/refinement, authenticated observations/genesis, PCD claims, durable nonce/state consumption and actual asset movement are outside this kernel relation. The full evaluator remains the candidate semantic reference. No MC01 closure, ACTUS/DeFi conformance, native proof, PCD, real settlement or full compiler/ledger correspondence is claimed. Independent audits and subsequent protocol integration remain required.
