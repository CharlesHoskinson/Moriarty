# Cardano catalogue inventory graph

[Open the interactive graph](graph/graph.html) to explore 143 versioned catalogue rows, 89 distinct property identifiers and all 20 UTXO pattern families. The graph has 590 nodes and 1,494 edges. Its nodes describe claims made in the captured draft catalogue; they do not certify those claims.

A fresh Gemini review compared all projected row metadata, the 20 pattern inventory entries, four identity-layer declarations and 48 display-label corrections with the source documents. Root also checked all 3,736 citation excerpts against the exact pinned sources. That mechanical check distinguishes complete JSON values, one-member fragments and key prefixes; a key prefix establishes the field's presence, not its whole value.

The label correction preserves graph IDs and source assertions. Luna reported that Graphify's default build had merged repeated labels; the corrected graph retained all IDs on its reported roundtrip. The original graph is preserved for comparison. The observed author tool version was graphifyy 0.9.91, with no latest-version claim or independent root rerun of the roundtrip.

The review covers the bounded inventory projection and label repair. Full graph semantics, predicate approval, cryptographic correctness and ledger truth remain unqualified. All 20 pattern families remain open. The missing original 42-property Cardano catalogue and 52-property Midnight source material remain provenance gaps. This graph adds no recovered rows, test results, native authority or Preprod transaction.
