# 8174 Rust source reconciliation map

This prototype is a navigation aid for the pinned source reconciliation. Start at the public head, then follow the frozen Core membership count to the sole changed `lib.rs` member and the eight ordinary module files absent from the frozen set. The links distinguish that source-membership result from any compile outcome.

The map keeps four paths separate: source-projection metadata and its limits; the upstream main CLI consumer; the delivered K2/R1CS consumer; and the test-gated draft language. It also records the unchanged financial/admission byte set, the bounded root/Muse source review, and the questions reserved for Opus.

`EXTRACTED` means a claim or relationship is stated in a cited source artifact. `INFERRED` marks the one navigational link synthesizing public module declarations with the independently cited missing-membership list. `OPEN` is a node status for questions/obligations the source materials leave unresolved. None of these labels establishes semantic equivalence, compiler behavior, security, native proof, Cardano correspondence, or product readiness.

The model contains 34 nodes and 29 edges, below the 40-node/60-edge limit. Graphify 0.9.91 builds and renders this exact model with the pinned installed Python interpreter. Rerun `./render.py` only to regenerate the graph artifacts from these exact source pins. No project tests, compiler, SDK, model, K/Quint, VM, ledger, native, proof, wallet, or browser operation is included.
