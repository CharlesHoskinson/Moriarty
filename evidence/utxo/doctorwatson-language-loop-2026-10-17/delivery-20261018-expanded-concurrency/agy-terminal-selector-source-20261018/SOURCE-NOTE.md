# Pure AGY terminal selector proposal

The function and eight ordinary format tests are frozen in SOURCE-FREEZE.json. The test source and expectations were frozen first, while the implementation file did not yet exist. Neither implementation nor tests was imported/executed in this authoring lane. Root owns source review and any test/integration run; this is not a RED/GREEN observation.

The new public protocol-shape receipt establishes the exact path: top-level event="result", child result dictionary, then result.structured_output dictionary. The earlier probe only searched direct root children, which explains that probe's missing export; this does not relabel the provider call as failed. The public shape receipt supplies field types, not the first probe's status literal. The separate root-specified allowed literals success/completed are prospective exact matches, not observed status claims.

`select_terminal_review` accepts parsed event values and explicit external schema/token/process-exit/input-pin observations. It returns an EXPORT with a copy of the full selected object only if all conditions hold. It never recursively searches response, progress, tool arguments or strings. Two result events are rejected even when identical. A result followed by another parsed event is not terminal and is rejected. Unknown/missing/non-string statuses, wrong nested shapes, token/schema failure, malformed-line observations and absent/nonzero exit or non-True pin observations produce NO_EXPORT with no review. Unknown nonterminal dictionaries are ignored rather than searched.

`decode_terminal_json_lines` consumes caller-supplied text lines once. It opens no files, launches no producer and has no old-capture/export mode. Blank lines are ignored; malformed/non-text lines mark parse failure so even an otherwise complete terminal object cannot export. Its generator forwards parsed objects directly to the selector; it does not retain or export raw progress text. Root's future integration must supply only new stdout in memory and independently establish terminal exit and input pins.

The externally supplied schema controls validation; the provider envelope's json_schema is never used as authority. Known declared schema drafts use jsonschema's validator_for; absence of a dialect uses Draft202012Validator, and unknown dialects give NO_EXPORT. The existing installed jsonschema API is used with a new empty referencing Registry, whose default retrieval callback raises NoSuchResource. Local schema references may resolve; missing external references give NO_EXPORT. No external registry resource is fetched by this selector. This is a stated ordinary dependency API boundary, not a security/resource certification of imported libraries or future callers.

The public init.model value is retained only as cliInitModelLabels, and actualBackendIdentityAttested is always false. Selection proves no actual backend identity, file-tool use, substantive source-review accuracy, source acceptance or security conclusion. Whole selected output can still contain an incorrect review; root must assess its claims independently.

Eight test methods cover the actual nested path and whole-object copy, false progress/tool candidates, response text/object fallback, duplicate terminals, partial/unknown/missing statuses, missing/wrong wire shapes, external schema/token/exit/pin gates, and malformed JSON lines. These author-derived format expectations are not independent financial/source-content oracles. Tests are not hostile/security tests or a security certification.

For root's separate ordinary test step, from this packet directory the proposed invocation is `python3 -m unittest -v test_agy_terminal_selector.py`. It was not run here. No provider request, old/private stream/log/session/auth/config read, SDK/native execution, global cache/lock/helper/worktree/Git mutation, scheduler change or prior-failure/vote relabeling occurred.
