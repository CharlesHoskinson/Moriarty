All shorter paths below are relative to `source-main/experiments/moriarty-eutxo/src/`.

1. **Generated compiler:** `cli.mjs:299–331` calls `compileCustody` with source, seed, cases, release/refund expectations, residual, manifest and output directory. `compile-custody.mjs:202–321` admits Source/5, derives evaluator fixtures/capacity, lowers and binds oracle cases. `322–350` writes `custody.ak`, checks/builds in an isolated project, copies `plutus.json` and applies parameters. `369–410` returns source hashes, instance, applied report and paths. 2. **Generated spender:** `lower-custody.mjs:1297–1330` renders `financial_head(seed,cash,lender,borrower,genesis).spend(datum,redeemer,own_ref,transaction)`. 3. **Existing state/action ABI:** `lower-custody.mjs:258–272` declares HeadDatum and Release/Refund/Cancel. The 13 positional head fields are program/bounds/source/schema/seed hashes; network/deployment; instance; transport revision/remaining; ordinary locked/revision; lifecycle. Lifecycle includes balances, allowances, obligations, used IDs and work. `native-financial.mjs:190–309` serializes those fields and five action fields (actor, recipient, transfer ID, lower, upper). `loadSourceTerminals:368–426` obtains terminal envelopes from the existing designer fixture source evaluator. This is concrete fixture forwarding, not arbitrary generated-source admission.
5. **Separate current consuming branch:** `runNativeCaller:2935–2943` selects `assembleConsumedFinancial` on `financialBody` plus `stages.inputs.twelveInputFrameSatisfied`. The helper at `2408–2697` reads `request.detailedData` (constructor 0, 13 fields), `request.spendScriptPath`, public key data, source terminals and slot/time inputs. It uses `UNIT_CASH_POLICY` and `UNIT_HEAD_POLICY`; request reference script is used for output-minimum measurement, separately from `spendScriptPath`. At `2599–2610`, it derives identity from the supplied head datum and takes the open-body transaction/output reference for spends. No equality/authentication conclusion is made about those inputs.
6. **Production guard:** at `2891–2906`, a production sibling replaces source path/blueprint/hashes and supplies calibrated terminal bounds. Preserve this guard. Owner authoring must supply its named concrete bindings rather than remove it or forward a filename alone.
7. **Final encoding boundary:** `native-body.mjs:545–559,598–660` reads the V3 script envelope, redeemer string and continuing inline datum, then passes files into `cardano-cli conway transaction build-raw`. This can spawn native tools and was not called.
