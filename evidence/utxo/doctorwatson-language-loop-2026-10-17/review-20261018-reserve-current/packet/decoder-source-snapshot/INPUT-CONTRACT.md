# Observation ITF input contract

This decoder targets the installed Quint0.32.0 TypeScript test trace produced by the pinned serializer and the reserve lifecycle model in checkout K, root-reported HEAD `f15214ab7a885a4dc3194002cbacbb56841fdcbf`. `SOURCE-PINS.json` stores exact source bytes/hashes; no Git command was used by this lane.

Input is the CLI ITF object with exactly top-level `#meta`, `vars` and `states`. Descriptive top metadata remains outside semantic comparison; it must identify format=ITF and status=passed. The caller supplies the **exact** variable spelling through `--variable`; there is no fuzzy namespace search or default alias. This model should have only that variable, so `vars` must equal that one-element list. Every captured state must contain only its ordered `#meta.index` and that variable. Exactly five states are required in original order; the decoder never truncates, fills, skips or synthesizes a state.

Every field of Observation is retained: c, last, attemptedTotal. Every PendingState field is retained: specimen, balances, programState, dutyPresent, dutyAmount, site, captures, committed. Every Invocation field is retained: status, attempted, advanced, hasSegment, newContinuation, effects, sourceSteps, errorSteps. Record key sets are exact, maps retain their full key sets and list order remains meaningful. It does not normalize numbers by floating-point conversion or treat booleans as integers.

Quint mathematical integers arrive as `{"#bigint":"decimal"}`. The current common codec/Rust adapter is explicitly limited to normal nonnegative0..142 integers; it is not a general mathematical-int/UInt128/field codec. `str -> int` maps arrive as `{"#map":[[key,value],...]}` and become JSON objects, with duplicate keys reported rather than overwritten. Ordered lists remain arrays. Unit Specimen and status constructors arrive as `{"tag":name,"value":{"#tup":[]}}`; both tag and empty payload are inspected. The parser's actual `unitValue` and serializer branches establish that representation. This reserve decoder accepts Reserve only; it recognizes the model's declared status tags without assuming that every variant occurs in the selected trajectory.

Resume effects keep original order and all represented payload fields: StateValue→tag/name/before/after; TransferAmount→tag/amount; DutyValue→tag/before/after; FeeAmount→tag/amount; EmitQuote→tag/quote. Asset/party/duty/capture identities are fixed external specimen context checked on the Rust source adapter side; they are not invented extra model fields. Prefix NormalEffect values are not decoded here because no initial/prefix FinancialFrame is a captured lifecycle variable.

Expected input is a separately frozen common wrapper containing initial, prefix and observations (or observations alone), or the explicit five-observation array. Only observations is selected; pure initial/prefix values are deliberately outside this comparison. The full decoded list is compared with exact record/map keys, array order, scalar types and values. The comparator reports the first JSON pointer difference. No financial expected numbers or transitions are hard-coded into the decoder.

CLI flags are `--input CAPTURE --variable EXACT_NAME --expected FROZEN_REFERENCE --output NEW_DECODED_FILE`. It writes a new file containing only `{"observations":[...]}` decoded from the supplied input. It also emits a receipt with captured input/reference/output hashes and a scoped match/mismatch result. A mismatch retains the decoded input for diagnosis and exits1; a match exits0; a format/read/write error exits2. Existing output paths are not reused. It does not create parent directories, run any tool, or read an evaluator to repair its input. The caller must bind actual source/tool/capture provenance separately; a synthetic specimen also has a well-typed format and is not thereby a real model execution.

The output does not include initial/prefix frames, Runtime Rust Step.statement/ExprIds/per-step snapshots, source admissions, hashes/cap wire fields, authentication, consumption, native SDK constraints, proof or target claims. Complete c remains an abstract post-state and is not an emitted Rust continuation. This is a finite selected-trace representation adapter, not whole model/source correspondence.
