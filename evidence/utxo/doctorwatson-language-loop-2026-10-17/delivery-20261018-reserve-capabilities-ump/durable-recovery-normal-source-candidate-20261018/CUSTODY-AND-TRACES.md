# Complete example custody and normal traces

## What these files are

Both example directories contain **complete authored documentary files**, assembled from literal proposed DTO definitions and the entire L04 financial data. They are not actual parser/evaluator/CLI output or independent runtime goldens. No product code or source-language runtime was executed. Source/IR/plan/trace rules are exposed to this author, and every new example must be independently rederived after adoption before use as a scored expected result.

The supplied identity markers remain unresolved. Program/Plan/Step fields are ordinary design data, not an assertion that the current Rust executable accepts them. No fixture can be called runnable/admitted until designated-owner identity/admission/error rules and the independent freeze exist. A valid JSON parse in a metadata script establishes only JSON syntax.
