# Normal Core/1 execution reports

This contract defines the adopted public report design for accepted finite Rust `language "moriarty/1"` / `moriarty-core/1` actions using `Let`, `Requires`, `Next`, `Ensures` and `Emit`, including an otherwise valid empty action. It defines their observations without changing source typing or arithmetic. Other financial statements retain their existing semantics and reports. Core/2 staged reports and target compilation have separate contracts.

Design adoption on 2026-10-18 establishes these requirements. Runtime behavior, source-to-IR correspondence and exact public bytes require separate conformance evidence; this document records no such result. The clauses refine existing [UNI-018/020/021/024](../openspec/changes/consolidated-language-kernel/specs/consolidated-language-kernel/spec.md#requirement-uni-018-profile-and-consumer-admission), with child labels NR-01–06.

## Public envelope and execution identity

For a successfully printed ordinary `mori simulate` result, the public envelope SHALL contain exactly `status: "accepted"`, `qualification: "local-reference-execution"` and `execution`. Execution SHALL contain exactly `semantics`, `action`, `pre`, `post`, `steps` and `effects`. Its semantics SHALL be `moriarty-core/1`, and its action SHALL be the selected action's name.

For an action with N statements, `steps` SHALL contain N entries in source order. Each Step SHALL contain all five members: `index`, `statement`, `value`, `snapshot` and `effects`. Entry i SHALL carry numeric zero-based `index: i` and the exact serialized statement i from the admitted public IR. Each ExprId in that statement SHALL be a numeric zero-based reference to the same Program's `expressions` array. An ExprId identifies an expression, rather than its evaluated value, source offset or Step. Numbering belongs to the exact source/IR candidate; it is not promised to survive source edits. These are NR-01 identity requirements.

Under NR-02, every accepted statement of the five scoped kinds SHALL have a present typed outer `Step.value`. UInt uses a canonical decimal string, for example `{"type":"UInt","value":"7"}`. Bool uses a JSON boolean, for example `{"type":"Bool","value":true}`. The outer Option encodes Some as that typed object and None as JSON null; null or an omitted outer `value` is not the selected representation for these completed statement kinds. This reporting rule does not change input decoding elsewhere.

`statement.value`, where present, is an ExprId number. The outer `Step.value` is the typed evaluation result. For example, `Let { name: "total", value: 2 }` can report outer `value: {"type":"UInt","value":"7"}`. The reference 2 and result 7 have different meanings.

## Sequential values and complete snapshots

Let S[-1] be `execution.pre` and S[i] the complete snapshot after statement i. A Snapshot SHALL contain exactly `state`, `balances` and `liabilities`. It SHALL retain affected and preserved rows, with declared state names mapped to typed values, balances ordered by exact `(asset, account)` and liabilities ordered by name. Asset comparison uses `(network, issuer, reference, scale)`. Inputs and local let captures are not Snapshot state fields.

NR-03 requires `pre` to be the complete normalized starting snapshot, including declared initial values selected by an empty supplied state map. Each `steps[i].snapshot` SHALL equal S[i]. For N>0, `post` SHALL equal the final Step snapshot. A let capture remains available to later statements while retaining its captured value; `Next` updates state immediately for subsequent expressions.

Define Eval(e,i) as the typed semantic value of expression e immediately before statement i, using the then-current state, action inputs and earlier captures. This notation specifies evaluation; it is not a call to an implementation.

| Statement | Required outer Step.value | Complete snapshot after statement | New Step.effects |
| --- | --- | --- | --- |
| `Let { name, value: e }` | Eval(e,i), captured under name | S[i-1] | `[]` |
| `Requires { predicate: e }` | typed Bool true | S[i-1] | `[]` |
| `Next { state: x, value: e }` | after = Eval(e,i), evaluated before assigning x | S[i-1] with only x replaced by after | exactly `[State { name: x, before: S[i-1].state[x], after }]` |
| `Ensures { predicate: e }` | typed Bool true, at its written position | S[i-1] | `[]` |
| `Emit { name, value: e }` | v = Eval(e,i) | S[i-1] | exactly `[Emit { name, value: v }]` |

The typed Let capture is observable even though its snapshot and effects do not change. `Ensures` reads the state at its own source position. Emit records an event while preserving the snapshot.

NR-04 defines `Step.effects` as the ordered effects newly produced by that statement. Define P[-1]=[] and P[i] as P[i-1] followed by `steps[i].effects`. `execution.effects` SHALL equal the ordered concatenation of all Step deltas, preserving repeated effects and array order. P is a derived prefix, not another wire field. Final state alone cannot supply this effect history, and unchanged snapshots can accompany Emit effects.

For N=0, `steps` SHALL be `[]`, `post` SHALL equal the complete normalized `pre`, and `effects` SHALL be `[]`, the empty concatenation P[-1]. Semantics and selected action identity remain present. No synthetic Step, statement index, ExprId or Step.value is created; per-Step rules have no instance for an empty action.

## ADDED Requirements

### Requirement: UNI-001 Permissionless public pipeline
When a developer presents a supported program and valid required evidence, the public pipeline SHALL decide validity without project, registry, council, Foreman or hosted-service membership.

#### Scenario: Positive witness
- **WHEN** A clean developer authors and submits a novel supported program without project records.
- **THEN** Objective checks accept it under owner and ledger rules.

#### Scenario: Hostile witness
- **WHEN** Only a reviewer receipt is removed from an otherwise identical valid candidate.
- **THEN** Validity is unchanged; a receipt cannot substitute for a missing proof.

### Requirement: UNI-002 One semantic relation
When an accepted stage changes state, the implementation SHALL bind program, profile, signed intention, current authority, history, observations, complete effects, costs and residual duties through one versioned relation.

#### Scenario: Positive witness
- **WHEN** Two source constructs elaborate into the supported Core with checked representations.
- **THEN** Their target behaviors satisfy the same scoped relation.

#### Scenario: Hostile witness
- **WHEN** A legacy lowering path drops authority or a mandatory predicate.
- **THEN** The path cannot claim certified acceptance.

### Requirement: UNI-003 Native target and correspondence
When a program claims certified execution, the toolchain SHALL establish valid-execution completeness and adversarial-witness soundness for its pinned ZKIRv3 or explicitly qualified successor target and actual ledger interface.

#### Scenario: Positive witness
- **WHEN** A source-valid execution has a witness under the bound target relation.
- **THEN** Native verification and actual effects agree with its specified outcome.

#### Scenario: Hostile witness
- **WHEN** An adversarial witness omits a range or assertion constraint.
- **THEN** It is rejected or the missing soundness obligation prevents certification.

### Requirement: UNI-004 Intent and solver completion
When a solver completes or combines intentions, acceptance SHALL preserve every applicable signed constraint, including allowed choices, gross caps, fees, net outcomes, liabilities, disclosures and recovery.

#### Scenario: Positive witness
- **WHEN** Two independent solvers choose distinct permitted routes.
- **THEN** Both receive the same objective acceptance treatment.

#### Scenario: Hostile witness
- **WHEN** A plan changes recipient, fee asset or obligation consent while preserving net balance.
- **THEN** Acceptance rejects the unauthorized effect.

### Requirement: UNI-005 Complete financial state
When a stage commits effects, acceptance SHALL account separately for assets and authorized supply, gross debits and fees, authority consumption, liabilities and residual duties over the authenticated complete state domain.

#### Scenario: Positive witness
- **WHEN** A partial fill consumes a proportional authorized amount and retains its remainder.
- **THEN** Accounting and cumulative limits remain correct.

#### Scenario: Hostile witness
- **WHEN** Netting hides a fee or an omitted liability/reservation.
- **THEN** Acceptance rejects the incomplete or unauthorized accounting.

### Requirement: UNI-006 Phases and partiality
When a target permits retained effects after failure, the compiler SHALL enforce the signed phase-specific effects, fees, authority consumption and remaining duties without representing them as global rollback or workflow completion.

#### Scenario: Positive witness
- **WHEN** The fallible phase fails while an authorized guaranteed fee remains.
- **THEN** The result records that fee and unresolved duties.

#### Scenario: Hostile witness
- **WHEN** An uncommitted incomplete candidate is presented as a completed workflow.
- **THEN** No ledger completion or unconsented duty is inferred.

### Requirement: UNI-007 Conditional settlement
When delivery is conditional, acceptance SHALL require the authorized evidence combination and distinguish request recording, funding, eligibility, in-flight effects and actual delivery.

#### Scenario: Positive witness
- **WHEN** Recipient consent and the bound document predicate become valid for funded escrow.
- **THEN** The permitted release can execute and be recorded after actual delivery evidence.

#### Scenario: Hostile witness
- **WHEN** A document digest, funding receipt or mere timeout is substituted for delivery conditions.
- **THEN** Release or completion is rejected and unresolved duties remain.

### Requirement: UNI-008 Recovery and state limits
When a workflow reaches expiry, work or state limits, supported recovery or successor transitions SHALL preserve applicable consent, cumulative budgets, replay state and duties under their own authority and resource rules.

#### Scenario: Positive witness
- **WHEN** Ordinary work is exhausted but an authorized funded recovery path remains.
- **THEN** Only that path may consume the reserved closure work.

#### Scenario: Hostile witness
- **WHEN** Rollover resets a spent budget or expiry erases debt.
- **THEN** Acceptance rejects the reset or erasure.

### Requirement: UNI-009 Full history scope
When compliant history is claimed, evidence SHALL establish authenticated origin, compatible well-founded predecessors and unique resource use under the stated mode; ledger induction SHALL NOT count as native recursive or private split/join evidence.

#### Scenario: Positive witness
- **WHEN** Two native financial steps and a bounded private join verify under the released compatible interface.
- **THEN** Their recursive and composition claims have retained independent verification.

#### Scenario: Hostile witness
- **WHEN** A fabricated base, arbitrary verifier, repeated parent resource or finalization omission is supplied.
- **THEN** Verification rejects the invalid history.

### Requirement: UNI-010 Privacy and completeness
Where private continuation is claimed, acceptance SHALL bind the authenticated completeness domain and permitted observations, while the implementation supplies the stated witness-handoff and availability mechanism.

#### Scenario: Positive witness
- **WHEN** A separately isolated successor gets authorized private inputs.
- **THEN** It continues under the declared privacy and history relation.

impl<'de> Deserialize<'de> for UInt {
    fn deserialize<D: serde::Deserializer<'de>>(deserializer: D) -> Result<Self, D::Error> {
        let s = String::deserialize(deserializer)?;
        if s.is_empty()
            || !s.bytes().all(|b| b.is_ascii_digit())
            || (s.len() > 1 && s.starts_with('0'))
        {
            return Err(serde::de::Error::custom(
                "expected canonical unsigned decimal string",
            ));
        }
        s.parse().map(UInt).map_err(serde::de::Error::custom)
    }
}

pub(crate) fn identifier(name: &str) -> bool {
    let mut bytes = name.bytes();
    matches!(bytes.next(), Some(b'A'..=b'Z' | b'a'..=b'z'))
        && name.len() <= 64
        && bytes.all(|b| b.is_ascii_alphanumeric() || b == b'_')
        && !matches!(
            name,
            "language"
                | "agreement"
                | "state"
                | "asset"
                | "action"
                | "input"
                | "let"
                | "next"
                | "requires"
                | "ensures"
                | "emit"
                | "transfer"
                | "fee"
                | "liability"
                | "discharge"
                | "true"
                | "false"
                | "and"
                | "or"
                | "not"
                | "UInt"
                | "Bool"
        )
}
fn names<'a>(values: impl Iterator<Item = &'a str>, kind: &str) -> Result<(), Error> {
    let mut seen = BTreeSet::new();
    for name in values {
        if !identifier(name) || !seen.insert(name) {
            return Err(failure(
                "duplicate",
                format!("Invalid or duplicate {kind} name {name:?}."),
            ));
        }
    }
    Ok(())
}

    program: &Program,
    id: ExprId,
    env: &BTreeMap<String, Type>,
    depth: usize,

fn type_cached(
    program: &Program,
    id: ExprId,
    env: &BTreeMap<String, Type>,
    depth: usize,
    cache: &mut [Option<Type>],
) -> Result<Type, Error> {
    if depth > 64 {
        return Err(failure("bound", "Expression depth exceeds 64."));
    }
    let index = usize::from(id);
    let node = program
        .expressions
        .get(index)
        .ok_or_else(|| failure("expression", "Expression index out of bounds."))?;
    if let Some(ty) = cache[index] {
        return Ok(ty);
    }
    let result = match node {
        Expr::LiabilityPresent { .. } => Ok(Type::Bool),
        Expr::LiabilityAmount { .. } => Ok(Type::UInt),
        Expr::Literal { value } => Ok(value.ty()),
        Expr::Name { name } => env
            .get(name)
            .copied()
            .ok_or_else(|| failure("name", format!("Unknown or forward name {name:?}."))),
        Expr::Not { value } => {
            if type_cached(program, *value, env, depth + 1, cache)? != Type::Bool {
                return Err(failure("type", "not requires Bool."));
            }
            Ok(Type::Bool)
        }
        Expr::Binary { op, lhs, rhs } => {
            let a = type_cached(program, *lhs, env, depth + 1, cache)?;
            let b = type_cached(program, *rhs, env, depth + 1, cache)?;
            let expected = match op {
                BinaryOp::And | BinaryOp::Or => Type::Bool,
                _ => Type::UInt,
            };
            if a != b || (!matches!(op, BinaryOp::Eq | BinaryOp::Ne) && a != expected) {
                return Err(failure("type", "Binary operands have incompatible types."));
            }
            Ok(
                if matches!(op, BinaryOp::Add | BinaryOp::Sub | BinaryOp::Mul) {
                    Type::UInt
                } else {
                    Type::Bool
                },
            )
        }
    }?;
    cache[index] = Some(result);
    Ok(result)
}
/// Validates even manually constructed/deserialized IR before interpretation.
pub fn validate(program: &Program) -> Result<(), Error> {
    if program.language != LANGUAGE || program.semantics != SEMANTICS {
        return Err(failure(
            "profile",
            "Unsupported language or semantics identity.",
        ));
    }
    if !identifier(&program.name) {
        return Err(failure(
            "name",
            "Agreement name must be a non-reserved ASCII identifier of at most 64 bytes.",
        ));
    }
    if program.actions.is_empty() {
        return Err(failure("program", "Program needs at least one action."));
    }
    if program.states.len() + program.assets.len() + program.actions.len() > MAX_DECLARATIONS
        || program.expressions.len() > MAX_EXPRESSIONS
    {
        return Err(failure(
            "bound",
            "Program exceeds finite declaration/expression bounds.",
        ));
    }
    names(
        program
            .states
            .iter()
            .map(|s| s.name.as_str())
            .chain(program.assets.iter().map(|a| a.name.as_str())),
        "declaration",
    )?;
    names(program.actions.iter().map(|a| a.name.as_str()), "action")?;
    let mut identities = BTreeSet::new();
    for asset in &program.assets {
        let id = &asset.identity;
        if id.network.is_empty()
            || id.issuer.is_empty()
            || id.reference.is_empty()
            || id.network.len() > 1024
            || id.issuer.len() > 1024
            || id.reference.len() > 1024
            || id.scale > 38
            || !identities.insert(id)
        {
            return Err(failure(
                "asset",
                "Asset identities must be complete, unique and use scale 0..38.",
            ));
        }
        if program.assets.iter().any(|other| {
            other.identity.network == id.network
                && other.identity.issuer == id.issuer
                && other.identity.reference == id.reference
                && other.identity.scale != id.scale
        }) {
            return Err(failure(
                "asset",
                "Same asset identity cannot have conflicting scales.",
            ));
        }
    }
    let mut depths = Vec::with_capacity(program.expressions.len());
    for (i, e) in program.expressions.iter().enumerate() {
        let refs = match e {
            Expr::Binary { lhs, rhs, .. } => vec![*lhs, *rhs],
            Expr::Not { value } => vec![*value],
            _ => vec![],
        };
        let mut depth = 0;
        for r in refs {
            if usize::from(r) >= i {
                return Err(failure(
                    "expression",
                    "Expression references must point to earlier nodes; cycles are forbidden.",
                ));
            }
            depth = depth.max(depths[usize::from(r)] + 1);
        }
        if depth > 64 {
            return Err(failure("bound", "Expression depth exceeds 64."));
        }
        depths.push(depth);
    }
    let state_types: BTreeMap<_, _> = program
        .states
        .iter()
        .map(|s| (s.name.clone(), s.ty))
        .collect();
    for state in &program.states {
        if state.initial.ty() != state.ty {
            return Err(failure(
                "type",
                format!("Initial state {:?} has wrong type.", state.name),
            ));
        }
    }
    for action in &program.actions {
        if action.inputs.len() > MAX_DECLARATIONS || action.statements.len() > MAX_STATEMENTS {
            return Err(failure(
                "bound",
                "Action exceeds input or statement bounds.",
            ));
        }
        names(action.inputs.iter().map(|i| i.name.as_str()), "input")?;
        let mut env = state_types.clone();
        for input in &action.inputs {
            if env.insert(input.name.clone(), input.ty).is_some()
                || program.assets.iter().any(|a| a.name == input.name)
            {
                return Err(failure("duplicate", "Input cannot shadow a declaration."));
            }
        }
        for statement in &action.statements {
            match statement {
                // Same identity as `stage::require_core1`; only an in-memory
                // program can carry Await here, since `/1` JSON cannot.
                Statement::Await { .. } => {
                    return Err(failure("profile", "Await requires moriarty-core/2."));
                }
                Statement::Let { name, value } => {
                    let ty = expr_type(program, *value, &env, 0)?;
                    if !identifier(name)
                        || env.insert(name.clone(), ty).is_some()
                        || program.assets.iter().any(|a| a.name == *name)
                    {
                        return Err(failure("duplicate", "let cannot shadow an existing name."));
                    }
                }
                Statement::Requires { predicate } | Statement::Ensures { predicate } => {
                    if expr_type(program, *predicate, &env, 0)? != Type::Bool {
                        return Err(failure("type", "Predicate must have type Bool."));
                    }
                }
                Statement::Next { state, value } => {
                    let expected = state_types
                        .get(state)
                        .ok_or_else(|| failure("name", format!("Unknown state {state:?}.")))?;
                    if expr_type(program, *value, &env, 0)? != *expected {
                        return Err(failure("type", "State update has wrong type."));
                    }
                }
                Statement::Emit { name, value } => {
                    if name.is_empty() || name.len() > 1024 {
                        return Err(failure("name", "Event name must contain 1..1024 bytes."));
                    }
                    expr_type(program, *value, &env, 0)?;
                }
                Statement::Transfer {
                    asset,
                    from,
                    to,
                    amount,
                }
                | Statement::Fee {
                    asset,
                    from,
                    to,
                    amount,
                } => {
                    validate_asset(program, asset)?;
                    if from.is_empty() || to.is_empty() || from.len() > 1024 || to.len() > 1024 {
                        return Err(failure("account", "Account identities cannot be empty."));
                    }
                    require_uint(program, *amount, &env)?;
                }
                Statement::Liability {
                    name,
                    asset,
                    debtor,
                    creditor,
                    amount,
                } => {
                    validate_asset(program, asset)?;
                    if name.is_empty()
                        || debtor.is_empty()
                        || creditor.is_empty()
                        || name.len() > 1024
                        || debtor.len() > 1024
                        || creditor.len() > 1024
                    {
                        return Err(failure(
                            "liability",
                            "Liability identities cannot be empty.",
                        ));
                    }
                    require_uint(program, *amount, &env)?;
                }
                Statement::Discharge { name, amount } => {
                    if name.is_empty() || name.len() > 1024 {
                        return Err(failure(
                            "liability",
                            "Liability name must contain 1..1024 bytes.",
                        ));
                    }
                    require_uint(program, *amount, &env)?;
                }
            }
        }
    }
    validate_liability_reads(program)?;
    Ok(())
}
// New reads require a source-fixed identity. Legacy Core external duties and
// discharge-only programs keep their existing validation rules.
pub(crate) fn validate_liability_reads(p: &Program) -> Result<(), Error> {
    let mut reads = BTreeMap::new();
    for expr in &p.expressions {
        if let Expr::LiabilityPresent { name } | Expr::LiabilityAmount { name } = expr {
            if name.is_empty() || name.len() > 1024 {
                return Err(failure(
                    "liability",
                    "Liability read name must contain 1..1024 bytes.",
                ));
            }
            reads.insert(name.as_str(), None);
        }
    }
    for stmt in p.actions.iter().flat_map(|a| &a.statements) {
        if let Statement::Liability {
            name,
            asset,
            debtor,
            creditor,
            ..
        } = stmt
            && let Some(found) = reads.get_mut(name.as_str())
        {
            let identity = (
                validate_asset(p, asset)?,
                debtor.as_str(),
                creditor.as_str(),
            );
            if found.is_some_and(|previous| previous != identity) {
                return Err(failure(
                    "liability",
                    format!("Conflicting source liability identity for {name:?}."),
                ));
            }
            *found = Some(identity);
        }
    }
    for (name, identity) in reads {
        if identity.is_none() {
            return Err(failure(
                "liability",
                format!("Liability read {name:?} has no source-derived identity."),
            ));
        }
    }
    Ok(())
}

fn eval_cached(
    p: &Program,
    id: ExprId,
    env: &BTreeMap<String, Value>,
    snapshot: &Snapshot,
    cache: &mut [Option<Value>],
    meter: &mut Option<&mut Meter>,
) -> Result<Value, Error> {
    let i = usize::from(id);
    if let Some(value) = &cache[i] {
        return Ok(value.clone());
    }
    // Charge the attempted node before its children or operation. Cache hits
    // above remain free, and evaluate creates a new cache for each statement.
    charge_logical(meter)?;
    let result = match &p.expressions[i] {
        Expr::LiabilityPresent { name } | Expr::LiabilityAmount { name } => {
            let row = snapshot
                .liabilities
                .binary_search_by(|l| l.name.as_str().cmp(name.as_str()))
                .ok()
                .map(|index| &snapshot.liabilities[index]);
            if matches!(&p.expressions[i], Expr::LiabilityPresent { .. }) {
                Value::Bool(row.is_some())
            } else {
                Value::UInt(row.map_or(UInt(0), |l| l.amount))
            }
        }
        Expr::Literal { value } => value.clone(),
        Expr::Name { name } => env
            .get(name)
            .cloned()
            .ok_or_else(|| failure("name", format!("Unknown name {name:?}.")))?,
        Expr::Not { value } => match eval_cached(p, *value, env, snapshot, cache, meter)? {
            Value::Bool(b) => Value::Bool(!b),
            _ => return Err(failure("type", "not expects Bool.")),
        },
        Expr::Binary { op, lhs, rhs } => {
            let a = eval_cached(p, *lhs, env, snapshot, cache, meter)?;
            let b = eval_cached(p, *rhs, env, snapshot, cache, meter)?;
            match (op, a, b) {
                (BinaryOp::Add, Value::UInt(UInt(a)), Value::UInt(UInt(b))) => {
                    Value::UInt(UInt(a.checked_add(b).ok_or_else(|| {
                        failure("overflow", "UInt addition exceeds u128.")
                    })?))
                }
                (BinaryOp::Sub, Value::UInt(UInt(a)), Value::UInt(UInt(b))) => {
                    Value::UInt(UInt(a.checked_sub(b).ok_or_else(|| {
                        failure("underflow", "UInt subtraction is negative.")
                    })?))
                }
                (BinaryOp::Mul, Value::UInt(UInt(a)), Value::UInt(UInt(b))) => {
                    Value::UInt(UInt(a.checked_mul(b).ok_or_else(|| {
                        failure("overflow", "UInt multiplication exceeds u128.")
                    })?))
                }
                (BinaryOp::Eq, a, b) => Value::Bool(a == b),
                (BinaryOp::Ne, a, b) => Value::Bool(a != b),
                (BinaryOp::Lt, Value::UInt(a), Value::UInt(b)) => Value::Bool(a < b),
                (BinaryOp::Le, Value::UInt(a), Value::UInt(b)) => Value::Bool(a <= b),
                (BinaryOp::Gt, Value::UInt(a), Value::UInt(b)) => Value::Bool(a > b),
                (BinaryOp::Ge, Value::UInt(a), Value::UInt(b)) => Value::Bool(a >= b),
                (BinaryOp::And, Value::Bool(a), Value::Bool(b)) => Value::Bool(a && b),
                (BinaryOp::Or, Value::Bool(a), Value::Bool(b)) => Value::Bool(a || b),
                _ => return Err(failure("type", "Invalid operand types.")),
            }
        }
    };
    cache[i] = Some(result.clone());
    Ok(result)
}

// Core also supports incoming duties without a source declaration. Only names
// declared by Liability statements have a source-fixed identity; do not impose
// the backend's closed, sixteen-entry compiler profile on general Core input.
fn liability_identities(p: &Program) -> Result<BTreeMap<&str, (&AssetId, &str, &str)>, Error> {
    let mut identities = BTreeMap::new();
    for stmt in p.actions.iter().flat_map(|action| &action.statements) {
        if let Statement::Liability {
            name,
            asset,
            debtor,
            creditor,
            ..
        } = stmt
        {
            let identity = (
                validate_asset(p, asset)?,
                debtor.as_str(),
                creditor.as_str(),
            );
            if let Some(existing) = identities.insert(name.as_str(), identity)

                    format!("Conflicting source liability identity for {name:?}."),
                ));
            }
        }
    }
    Ok(identities)
}
pub(crate) fn scenario_snapshot(p: &Program, a: &Action, s: &Scenario) -> Result<Snapshot, Error> {
    if s.balances.len() > 4096 || s.liabilities.len() > 1024 {
        return Err(failure(
            "bound",
            "Scenario exceeds 4,096 balances or 1,024 liabilities.",
        ));
    }
    let added_liabilities = a
        .statements
        .iter()
        .filter(|stmt| matches!(stmt, Statement::Liability { .. }))
        .count();
    let trace_records =
        p.states.len() + s.balances.len() + s.liabilities.len() + added_liabilities + 1;
    if trace_records.saturating_mul(a.statements.len() + 2) > MAX_TRACE_CELLS {
        return Err(failure(
            "bound",
            "Scenario and action exceed 65,536 trace snapshot records.",
        ));
    }
    if !s.state.is_empty() && s.state.len() != p.states.len() {
        return Err(failure(
            "state",
            "Provide either initial state {} or every declared state value.",
        ));
    }
    let mut state = BTreeMap::new();
    for d in &p.states {
        let value = if s.state.is_empty() {
            d.initial.clone()
        } else {
            s.state
                .get(&d.name)
                .ok_or_else(|| failure("state", format!("Missing state {:?}.", d.name)))?
                .clone()
        };
        if value.ty() != d.ty {
            return Err(failure(
                "state",
                format!("Wrong type for state {:?}.", d.name),
            ));
        }
        state.insert(d.name.clone(), value);
    }
    if s.inputs.len() != a.inputs.len() {
        return Err(failure(
            "input",
            "Scenario must provide exactly the selected action's inputs.",
        ));
    }
    for input in &a.inputs {
        if s.inputs.get(&input.name).map(Value::ty) != Some(input.ty) {
            return Err(failure(
                "input",
                format!("Missing or wrong type for input {:?}.", input.name),
            ));
        }
    }
    let ids: BTreeSet<_> = p.assets.iter().map(|a| a.identity.clone()).collect();
    let mut keys = BTreeSet::new();
    let mut balances = s.balances.clone();
    for b in &balances {
        if !ids.contains(&b.asset) {
            return Err(failure(
                "asset",
                format!(
                    "Undeclared exact asset identity for account {:?}.",
                    b.account
                ),
            ));
        }
        if b.account.is_empty()
            || b.account.len() > 1024
            || !keys.insert((b.asset.clone(), b.account.clone()))
        {
            return Err(failure(
                "balance",
                "Duplicate or invalid balance account/asset.",
            ));
        }
    }
    for stmt in &a.statements {
        if let Statement::Transfer {
            asset, from, to, ..
        }
        | Statement::Fee {
            asset, from, to, ..
        } = stmt
        {
            let id = validate_asset(p, asset)?;
            for account in [from, to] {
                if !keys.contains(&(id.clone(), account.clone())) {
                    return Err(failure(
                        "balance",
                        format!("Missing explicit balance for {account:?} and asset {asset:?}."),
                    ));
                }
            }
        }
    }
    balances.sort_by(|a, b| (&a.asset, &a.account).cmp(&(&b.asset, &b.account)));
    let identities = liability_identities(p)?;
    let mut liabilities = s.liabilities.clone();
    let mut names = BTreeSet::new();
    for l in &liabilities {
        if !ids.contains(&l.asset) {
            return Err(failure(
                "asset",
                "Liability uses undeclared exact asset identity.",
            ));
        }
        if l.name.is_empty()
            || l.name.len() > 1024
            || l.debtor.is_empty()
            || l.creditor.is_empty()
            || l.debtor.len() > 1024
            || l.creditor.len() > 1024
            || !names.insert(l.name.clone())
        {
            return Err(failure(
                "liability",
                "Invalid or duplicate liability identity.",
            ));
        }
        if let Some(identity) = identities.get(l.name.as_str())
            && *identity != (&l.asset, l.debtor.as_str(), l.creditor.as_str())
        {
            return Err(failure(
                "liability",
                format!("Existing liability identity differs for {:?}.", l.name),
            ));
        }
    }
    liabilities.sort_by(|a, b| a.name.cmp(&b.name));
    Ok(Snapshot {
        state,
        balances,
        liabilities,
    })
}
fn move_funds(
    snapshot: &mut Snapshot,
    id: &AssetId,
    from: &str,
    to: &str,
    amount: UInt,
) -> Result<(), Error> {
    let f = snapshot
        .balances
        .iter()
        .position(|b| b.asset == *id && b.account == from)
        .ok_or_else(|| failure("balance", "Missing source balance."))?;
    let t = snapshot
        .balances
        .iter()
        .position(|b| b.asset == *id && b.account == to)
        .ok_or_else(|| failure("balance", "Missing recipient balance."))?;
    let debit = snapshot.balances[f]
        .amount
        .0
        .checked_sub(amount.0)
        .ok_or_else(|| failure("balance", format!("Insufficient balance for {from:?}.")))?;
    if f != t {
        let credit = snapshot.balances[t]
            .amount
            .0
            .checked_add(amount.0)
            .ok_or_else(|| failure("overflow", "Recipient balance exceeds u128."))?;
        snapshot.balances[f].amount = UInt(debit);
        snapshot.balances[t].amount = UInt(credit);
    }
    Ok(())
}
/// Shared scalar statement execution for legacy actions and admitted segments.
fn execute_statement(
    program: &Program,
    stmt: &Statement,
    env: &mut BTreeMap<String, Value>,
    current: &mut Snapshot,
    meter: &mut Option<&mut Meter>,
    effects: &mut Vec<Effect>,
) -> Result<Option<Value>, Error> {
    charge_logical(meter)?;
    match stmt {
        Statement::Await { guard, .. } => {
            let v = evaluate(program, *guard, env, current, meter)?;
            Ok(Some(v))
        }
        Statement::Let { name, value } => {
            let v = evaluate(program, *value, env, current, meter)?;
            env.insert(name.clone(), v.clone());
            Ok(Some(v))
        }
        Statement::Requires { predicate } | Statement::Ensures { predicate } => {
            let v = evaluate(program, *predicate, env, current, meter)?;
            if v != Value::Bool(true) {
                return Err(failure(
                    if matches!(stmt, Statement::Requires { .. }) {
                        "requires"
                    } else {
                        "ensures"
                    },
                    "Action predicate evaluated to false.",
                ));
            }
            Ok(Some(v))
        }
        Statement::Next { state, value } => {
            let after = evaluate(program, *value, env, current, meter)?;
            let before = current.state[state].clone();
            current.state.insert(state.clone(), after.clone());
            env.insert(state.clone(), after.clone());
            effects.push(Effect::State {
                name: state.clone(),
                before,
                after: after.clone(),
            });
            Ok(Some(after))
        }
        Statement::Emit { name, value } => {
            let v = evaluate(program, *value, env, current, meter)?;
            effects.push(Effect::Emit {
                name: name.clone(),
                value: v.clone(),
            });
            Ok(Some(v))
        }
        Statement::Transfer {
            asset,
            from,
            to,
            amount: expr,
        }
        | Statement::Fee {
            asset,
            from,
            to,
            amount: expr,
        } => {
            let amount = amount(program, *expr, env, current, meter)?;
            let id = validate_asset(program, asset)?.clone();
            move_funds(current, &id, from, to, amount)?;
            effects.push(if matches!(stmt, Statement::Fee { .. }) {
                Effect::Fee {
                    asset: id,
                    from: from.clone(),
                    to: to.clone(),
                    amount,
                }
            } else {
                Effect::Transfer {
                    asset: id,
                    from: from.clone(),
                    to: to.clone(),
                    amount,
                }
            });
            Ok(Some(Value::UInt(amount)))
        }
        Statement::Liability {
            name,
            asset,
            debtor,
            creditor,
            amount: expr,
        } => {
            let amount = amount(program, *expr, env, current, meter)?;
            let id = validate_asset(program, asset)?.clone();
            let found = current.liabilities.iter().position(|l| l.name == *name);
            let before = if let Some(index) = found {
                let l = &current.liabilities[index];
                if l.asset != id || l.debtor != *debtor || l.creditor != *creditor {
                    return Err(failure("liability", "Existing liability identity differs."));
                }
                l.amount
            } else {
                UInt(0)
            };
            let after = UInt(
                before
                    .0
                    .checked_add(amount.0)
                    .ok_or_else(|| failure("overflow", "Liability exceeds u128."))?,
            );
            if let Some(index) = found {
                current.liabilities[index].amount = after;
            } else {
                current.liabilities.push(Liability {
                    name: name.clone(),
                    asset: id.clone(),
                    debtor: debtor.clone(),
                    creditor: creditor.clone(),
                    amount: after,
                });
                current.liabilities.sort_by(|a, b| a.name.cmp(&b.name));
            }
            effects.push(Effect::Liability {
                name: name.clone(),
                asset: id,
                debtor: debtor.clone(),
                creditor: creditor.clone(),
                before,
                after,
            });
            Ok(Some(Value::UInt(amount)))
        }
        Statement::Discharge { name, amount: expr } => {
            let amount = amount(program, *expr, env, current, meter)?;
            let l = current
                .liabilities
                .iter_mut()
                .find(|l| l.name == *name)
                .ok_or_else(|| {
                    failure("liability", format!("Unknown residual liability {name:?}."))
                })?;
            let before = l.amount;
            let after =
                UInt(before.0.checked_sub(amount.0).ok_or_else(|| {
                    failure("liability", "Discharge exceeds residual liability.")
                })?);
            l.amount = after;
            effects.push(Effect::Liability {
                name: name.clone(),
                asset: l.asset.clone(),
                debtor: l.debtor.clone(),
                creditor: l.creditor.clone(),
                before,
                after,
            });
            Ok(Some(Value::UInt(amount)))
        }
    }
}

/// Executes one finite action on a clone. A refusal exposes no committed effects.
pub fn simulate(program: &Program, action: &str, scenario: &Scenario) -> Result<Execution, Error> {
    simulate_with_meter(program, action, scenario, None)
}
pub(crate) fn simulate_with_meter(
    program: &Program,
    action: &str,
    scenario: &Scenario,
    mut meter: Option<&mut Meter>,
) -> Result<Execution, Error> {
    validate(program)?;
    let selected = program
        .actions
        .iter()
        .find(|a| a.name == action)
        .ok_or_else(|| failure("action", format!("Unknown action {action:?}.")))?;
    let pre = scenario_snapshot(program, selected, scenario)?;
    let mut current = pre.clone();
    let mut env = current.state.clone();
    env.extend(scenario.inputs.clone());
    let mut steps = vec![];
    let mut all_effects = vec![];
    for (i, stmt) in selected.statements.iter().enumerate() {
        let mut effects = vec![];
        let result = execute_statement(
            program,
            stmt,
            &mut env,
            &mut current,
            &mut meter,
            &mut effects,
        );
        let value = result.map_err(|mut e| {
            e.step = Some(i as u16);
            e
        })?;
        all_effects.extend(effects.clone());
        steps.push(Step {
            index: i as u16,
            statement: stmt.clone(),
            value,
            snapshot: current.clone(),
            effects,
        });
    }
    Ok(Execution {
        semantics: SEMANTICS.into(),
        action: action.into(),
        pre,
        post: current,
        steps,
        effects: all_effects,
    })
}
/// Environment seed supplied only by stage admission.
pub enum SegmentEntry<'a> {
    Start {
        inputs: &'a [crate::stage::NamedValue],
    },
    Resume {
        site: u16,
        captures: &'a [crate::stage::NamedValue],
        event: &'a [crate::stage::NamedValue],
    },
}

pub enum SegmentRun {
    NotAdvanced,
    Ran {
        execution: Box<Execution>,
        exit_site: u16,
        captures_out: Vec<crate::stage::NamedValue>,
    },
}

/// Runs an already-admitted finite source segment with the same scalar executor
/// as legacy simulation. The caller owns admission, publication and work policy.
pub(crate) fn run_segment(
    sp: &crate::stage::StagedProgram,
    action: usize,
    entry: SegmentEntry<'_>,
    boundary: Snapshot,
    meter: &mut Meter,
) -> Result<SegmentRun, Error> {
    let program = sp.program();
    let selected = &program.actions[action];
    let plan = &sp.plan().actions[action];
    let pre = boundary;
    let mut current = pre.clone();
    let mut env = pre.state.clone();
    let mut meter = Some(meter);
    let mut steps = Vec::new();
    let mut all_effects = Vec::new();
    let begin = match entry {
        SegmentEntry::Start { inputs } => {
            env.extend(inputs.iter().map(|v| (v.name.clone(), v.value.clone())));
            0
        }
        SegmentEntry::Resume {
            site,
            captures,
            event,
        } => {
            env.extend(
                captures
                    .iter()
                    .chain(event)
                    .map(|v| (v.name.clone(), v.value.clone())),
            );
            let ordinal = usize::from(plan.sites[usize::from(site) - 1].ordinal);
            let statement = &selected.statements[ordinal];
            let mut effects = Vec::new();
            // execute_statement charges dispatch once, then visits the guard.
            let value = execute_statement(
                program,
                statement,
                &mut env,
                &mut current,
                &mut meter,
                &mut effects,
            )
            .map_err(|mut error| {
                error.step = Some(ordinal as u16);
                error
            })?;
            if value != Some(Value::Bool(true)) {
                return Ok(SegmentRun::NotAdvanced);
            }
            steps.push(Step {
                index: ordinal as u16,
                statement: statement.clone(),
                value,
                snapshot: pre.clone(),
                effects,
            });
            ordinal + 1
        }
    };
    let mut exit_site = 0;
    let mut captures_out = Vec::new();
    for (ordinal, statement) in selected.statements.iter().enumerate().skip(begin) {
        if matches!(statement, Statement::Await { .. }) {
            // Entry charge is attempted now; guard and its Step belong to resume.
            charge_logical(&mut meter).map_err(|mut error| {
                error.step = Some(ordinal as u16);
                error
            })?;
            let site = plan
                .sites
                .iter()
                .find(|s| usize::from(s.ordinal) == ordinal)
                .ok_or_else(|| failure("stage_site", "Await site is absent from stage plan."))?;
            exit_site = site.site;
            for slot in &site.captures {
                let value = env
                    .get(&slot.name)
                    .cloned()
                    .ok_or_else(|| failure("name", format!("Unknown name {:?}.", slot.name)))?;
                captures_out.push(crate::stage::NamedValue {
                    name: slot.name.clone(),
                    value,
                });
            }
            break;
        }
        let mut effects = Vec::new();
        let value = execute_statement(
            program,
            statement,
            &mut env,
            &mut current,
            &mut meter,
            &mut effects,
        )
        .map_err(|mut error| {
            error.step = Some(ordinal as u16);
            error
        })?;
        all_effects.extend(effects.clone());
        steps.push(Step {
            index: ordinal as u16,
            statement: statement.clone(),
            value,
            snapshot: current.clone(),
            effects,
        });
    }
    Ok(SegmentRun::Ran {
        execution: Box::new(Execution {
            semantics: program.semantics.clone(),
            action: selected.name.clone(),
            pre,
            post: current,
            steps,
            effects: all_effects,
        }),
        exit_site,
        captures_out,
    })
}

/// Recomputes all steps and rejects at the first deterministic divergence.
pub fn replay(
    program: &Program,
    action: &str,
    scenario: &Scenario,
    expected: &Execution,
) -> Result<(), Error> {
    let actual = simulate(program, action, scenario)?;
    if actual.semantics != expected.semantics
        || actual.action != expected.action
        || actual.pre != expected.pre
    {
        return Err(failure(
            "replay",
            "Execution identity or predecessor differs.",
        ));
    }
    for i in 0..actual.steps.len().max(expected.steps.len()) {
        if actual.steps.get(i) != expected.steps.get(i) {
            let mut e = failure("replay", format!("First divergence at step {i}."));
            e.step = Some(i as u16);
            return Err(e);
        }
    }
    if actual.effects != expected.effects || actual.post != expected.post {
        return Err(failure(
            "replay",
            "Complete effect sequence or poststate differs.",
        ));
    }
    Ok(())
}
