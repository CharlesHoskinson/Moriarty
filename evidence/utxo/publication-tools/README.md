# Historical publication tools

These frozen helpers implement the historical publication process. Each archive generation records the exact helper bytes it actually used. The complete reviewed candidate and actual regression logs are identified by the publication manifests. Source and native approval remain false.

The current reviewed regression sources live beside their helper modules. `test_publication.py` is a narrowly classified exact public unittest source containing synthetic provider poison fixtures; its direct-publication receipt is retained. The historical-review-427 directory preserves older public review text and test source with their exact Opus classification. It does not claim that older tests ran against these newer helpers.

Use the archive reconstruction instructions to download historical objects. Reproducing the publication build requires the pinned original capture/provenance inputs; the public archive does not contain excluded keys or raw private provider captures.
