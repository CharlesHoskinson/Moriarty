MarloweScan
Explorers are useful tools to visually represent transactions on a blockchain. Because Marlowe contracts are encoded in binary format on the chain, it can be hard to see what is happening within a Marlowe contract by using a normal Cardano explorer. There are also many transactions that are unrelated to Marlowe and it can be hard to filter them. For these reasons, Marlowe has a specialized open-source explorer called
MarloweScan
used to view Marlowe contracts.
