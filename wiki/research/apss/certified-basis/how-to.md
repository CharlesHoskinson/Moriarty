# Review a candidate jet

Use this procedure to review a proposed optimized primitive.

1. Freeze the reference judgment and complete observation relation.
2. State input types, ranges, failure conditions and logical work.
3. Identify the exact host implementation and target constraint fragment.
4. Prove host equivalence on the declared domain.
5. Check target constraints against adversarial witnesses, not just generated witnesses.
6. Discharge source-side producer checks and witness-side premises separately.
7. Prove all caller preconditions, codec assumptions and frame obligations.
8. Pin emitted ZKIRv3 version, instructions, compiler route and verifier identity.
9. Retain numeric-boundary, altered-witness and work-exhaustion negative controls.
10. Report theorem, finite-test and deployment evidence as separate statuses.

An unproved boundary remains an explicit obligation. No project reviewer receipt belongs in an end-user program's deployment inputs. See [reference](reference.md) for the required evidence distinctions.
