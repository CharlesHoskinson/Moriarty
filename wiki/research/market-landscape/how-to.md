# Compare intention guarantees fairly

Define the same signed financial contract for each system. Compare language behavior, deployed implementation and proof scope separately. Record which guarantees are runtime checks, offline formal verification, execution proofs or whole-history invariants.

Run conditional DvP, concurrent solver budgets, partial-fill recovery, gross-to-net preservation, semantic migration and hostile-witness cases. Include a useful positive trace and the exact rejected trace. Compare added application code, assumptions and actual effects. Do not treat Moriarty's planned capabilities as delivered advantages or a different target chain as proof of novelty.
