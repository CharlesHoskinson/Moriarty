# One semantic contract for the whole language

Preserve exact arithmetic, explicit effects, gross debit limits, persistent liabilities, controlled state writes and native Midnight proving. The review recommends connecting them through one supported typed Core and stage acceptance relation before expanding application-specific profiles.

The current source/5 route prepares local lifecycle results. The inspected Compact mapper uses a separate legacy frontend and excludes full authority/proof/settlement acceptance. Several scoped Core representations must not be presented as an already integrated general compiler.

The local lifecycle reserves closure work but exposes no reserve-consuming recovery action. A reproduced origination consumes its final ordinary work units while retaining debt and reserve; repayment then rejects for insufficient work. This agrees with its narrow specification. The missing product behavior is a separately authorized recovery path or a viable-admission rule, not silently allowing ordinary work to consume the reserve.

Append-only ID categories are capped at128 in this local profile. Public services need either explicit finite episodes with usable termination/recovery or authenticated rollover preserving replay evidence, budgets, authority and duties. Proof compression alone does not shrink mutable state arrays.

Further specification should reconcile ledger-induced versus recursively certified history, ordinary-expiry versus late-recovery authority, composable financial libraries, private-state completeness and phase-specific effects. Native proof-stack reuse is settled; no Lean dependency is introduced. The detailed review proposes decisions without silently changing existing semantics.
