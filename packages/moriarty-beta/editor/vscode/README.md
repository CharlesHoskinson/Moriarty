# Moriarty Beta for VS Code

Lexical highlighting, snippets and brackets for `.mori`, plus a stdio language
client for the bundled bounded authoring server. The server supplies Full
synchronization, UTF-16 diagnostics, completion, hover, definition, document
symbols and formatting for checked source.

Install this VSIX explicitly. Node >=24 must be available as `node`; use the
`moriarty.nodePath` setting to select its executable. Open a `.mori` file to start
the client. No global provider or MCP configuration is installed.

Transfer and repay support unqualified local preparation in the separate CLI.
Other families provide specified authoring support; financial relations remain
open. No editor result signs, proves, sends or accepts a ledger transaction.

VSIX packaging and real stdio/Neovim tests do not establish VS Code activation.
Activation in a real VS Code instance remains unperformed for this candidate.
