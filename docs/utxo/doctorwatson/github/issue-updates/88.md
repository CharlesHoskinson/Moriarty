**Tier 2 — test cleanup.**

## Problem
- `crates/mori-backend/src/task4_native_driver.rs` (about 1.1k lines) is a measurement harness named after a past task:
  - `proving.rs` mounts it with `#[path]`.
  - It keeps a global `static BUDGET: Mutex`.
  - It puts `#[cfg(test)] task4_native_driver::charge(..)` hooks inside library proving and parameter-loading code (`proving.rs`, `parameters.rs`, `signed_relation.rs::task4_reconstruct_before_caps`).
  - It reads local runtime captures under `.moriarty-dev/runtime/`.
- `mori-backend/tests/support/task4-native-driver.py` runs `cargo test` and `git` through `subprocess`.
- Tests change their behavior or write files based on environment variables: `MORIARTY_TASK4_*`, `MORIARTY_TEST_PARAMS(_DIR)`, `MORIARTY_STAGE_V1_BASELINE`, `MORIARTY_SIGNED_MEASUREMENT_DIR`, `MORIARTY_LIABILITY_MEASUREMENT_DIR`, `MORI_IO_CAPTURE_DIR`, `MORI_STATIC_IO_CAPTURE_DIR`, `MORI_STATIC_CAPTURE_DIR`, `MORI_FEE_POOL_CAPTURE_DIR`, `MORI_INIT_CAPTURE_DIR`, `MORI_LEDGER_PUBLIC_CAPTURE`, `MORI_PROVENANCE_BASELINE_BINARY` and `MORI_METERED_INTENT_EVIDENCE`.

## Suggested fix
1. Move the task4 harness out of `src/` into `experiments/` or a separate example or bench target, and remove the `charge` hooks from library code. If tests need call counts, use a counting implementation of the provider traits instead of global hooks.
2. Remove the Python driver from the crate. If a measurement run is still needed, make it an explicit script under `scripts/` that isn't part of `cargo test`.
3. Replace the capture variables with explicit tools (an `examples/` binary or a script that writes the captures), so `cargo test` never writes outside its temporary directories. Expensive native tests stay `#[ignore]`d and document their inputs.

## Needs input
Which of these captures and measurements the review and evidence workflow (`docs/audits/`) still needs, so the replacement keeps producing the same artifacts.

## Done when
No test hooks remain in library code, and `cargo test` behaves the same whatever the environment variables are.
