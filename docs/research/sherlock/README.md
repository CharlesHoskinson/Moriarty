# Sherlock design research

The first ten source studies motivated the candidate reference machine and
its required Lean/Clean stage. Five separate Opus brainstorms supply their
own draft security requirements and dissent. They are research inputs, not
architecture or product approval.

The [registered proposal](../../../openspec/changes/sherlock-universal-interpreter-design/proposal.md)
contains the EARS clauses, actual model coverage and remaining decisions.
The [ten optimization studies](optimization/README.md) compare implementation
ideas against the recorded Candidate A snapshot. The original Quint model
and its annotation-only repair are retained in `frozen-quint/`; the current
checked source and repair lineage are in [model observations](../../../models/sherlock/observations.json).

Proposals and source receipts preserve their original filenames and citations.
Raw public captures remain separately retained. A paper's reported experiment
does not measure Sherlock. Public source metadata does not establish compiler,
circuit or native correspondence. Private Fenrir implementation inventories
and extension source are excluded from this public package.
