# Lane 09 — bounded Quint companion design

**Status: recommendation; design only; no Quint/K execution.** Falsifiable objective: a later concrete model must exhibit recursive call/return and ADT traversal traces with a frozen committed snapshot across waiting and unsuccessful termination. This addresses the research contract's lifecycle/recursion requirements, without changing existing language profiles or acceptance exits.

**Source facts.** Quint excludes recursive operators, mutually recursive operators and recursive type definitions [S1, “No recursion”](https://quint.sh/docs/language-basics#no-recursion). Its records, finite maps, lists and sum types can instead represent an explicit abstract machine [S2, “Records” and “Sum Types”](https://quint.sh/docs/lang#records). The CLI distinguishes sampled simulation from verification and supports the TypeScript backend for simulations/tests [S3, “Command run” and “Command test”](https://quint.sh/docs/quint). The installed modeling skill likewise requires witnesses alongside invariants; its single-actor rule selects one cohesive record and plain Quint.

**Alternatives and recommendation.** Prefer a finite node arena plus explicit continuation frames. It exposes sharing, references, allocation bounds and stack behavior while representing object-language recursion through repeated transitions. A flat instruction/value vector simplifies serialization but obscures ADT structure and sharing. A lifecycle-only macro model is cheapest, but cannot witness that recursion actually traverses frames. Keep the macro model as a later projection, not the initial demonstrator.

**Proposed state.** One interpreter is the sole actor; an external response is a nondeterministic input action, not another process. There is no network or Choreo. Use `var machine: Machine` containing lifecycle `Running | Waiting | Halted | Rejected | Exhausted`, immutable program identifier, PC, bounded environment, accumulator, `List[Frame]` call stack, node map, remaining fuel, pending request, working store/effects, committed snapshot and boundary counter. Frames carry return PC, saved environment, destination and continuation tag. Node payloads are nonrecursive sums such as `Nil`, `Cons({head, tailRef})`, `Leaf(value)`, and `Branch({leftRef,rightRef})`; all child edges are integer references. Guard every map/list access before evaluation. Absence is a dedicated variant, not reference zero.

**Finite initial instance.** One program of at most 32 instructions; 8 node slots; at most 6 frames; at most 4 local bindings; scalar values 0–7; fuel 128; at most 2 committed boundaries and 2 external replies. Domain overflow becomes an explicit bounded-model refusal reason, never integer wrapping or a hidden assumption. Instantiate every constant and test its bounds. These limits specify a demonstrator, not a universal interpreter capacity claim.

**Transitions.** Separate pure guards/results from thin actions for instruction execution, allocation, call, return, pattern case, wait, resume, commit and termination. Every executed instruction consumes one fuel unit; entering `Exhausted` at zero performs no instruction. Waiting freezes interpreter state until resume; it makes no eventual-response promise. Commit alone replaces the committed snapshot and increments its boundary. Rejection/exhaustion preserve the last snapshot and retain diagnostic working state. Halt does not silently commit. Terminal states permit only explicit stuttering; all ordinary actions require the appropriate lifecycle.

**Properties and nonvacuity.** High-priority invariants cover reference definedness, legal return PCs, stack/node bounds, nonnegative fuel, committed-snapshot preservation outside commit, and terminal absorption. Store a previous-step summary or express two-state checks in tests for transition properties. Pair each with concrete witnesses: factorial(3)=6 with depth at least three; sum([1,2,3])=6 with three distinct tail visits; traversal of a depth-two tree; wait/resume followed by commit; and fuel exhaustion after genuine progress. Also witness a normal wrong-constructor refusal. Initialize only Running; witnesses require visited states and observed effects, not merely terminal flags.

**K correspondence gap.** Propose a projection from K control/stack/environment/store/fuel/status/committed-boundary cells to these fields. Document which administrative K rewrites stutter and which instruction group consumes one Quint step. Compare named traces on the common finite subset; do not claim refinement from matching terminal states. Evaluation order, arithmetic domains, aliasing, allocation, effects and wait/commit atomicity need explicit adapters. New circuit work is undetermined; this is model/spec and later host trace-adapter work. After design freeze, plan incremental `typecheck`, TypeScript `test`, and TypeScript sampled `run` (e.g. 1,000 samples, 160 steps, recorded seeds); no `verify`/Apalache. Counterargument: explicit frames can duplicate K detail; retain only fields supporting these named properties.
