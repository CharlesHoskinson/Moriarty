# Lane 05 — effects, work and suspended financial computation

Status: source-inspected proposal. Falsifiable target: a named semantic suspension followed by resumption preserves the caller stack and produces the same ordered financial event fold as uninterrupted execution, modulo explicitly recorded commit boundaries. No execution occurred. Existing `/2` semantics remain a reference, without a universal correspondence claim.

**Source facts.** Plutus’s versioned `ExBudget` source separates CPU and memory, charges machine reductions and input-sensitive builtins, and counts allocation rather than garbage-collector behavior [P, “Budgeting”]. This motivates an explicit work schedule, without importing its units. RISC Zero splits a session trace into independently handled segments; sessions stop at halt or pause [R, “Continuations”, “Segment”, “Session”]. That is evidence for execution segmentation, not evidence that a segment settles money. Marlowe steps return state, remaining contract and effects; `Pay` can produce a partial payment and warning, and `Close` refunds accounts over several steps in one transaction [M, “About a Marlowe contract”, “Pay”, “Close”]. Its partial-payment policy is an alternative, not Moriarty’s default.

**Candidate K state.** Separate `<control>`, `<env>`, `<store>`, `<callStack>`, `<status>` and `<waitSet>` from `<financialCommitted>`, `<financialWorking>`, `<segmentEvents>`, `<committedEvents>`, `<duties>`, `<observations>`, `<work>` and `<resourceProfile>`. A call frame carries return control, caller environment and destination; a wait record carries continuation identity, outstanding request identity, expected result shape and timeout branch. Recursive data may be immutable constructor trees initially, with an indexed immutable arena as a later representation alternative. Trees simplify rules; arenas express sharing but add lookups. The frozen machine state must include all frames and reachable values, including waiting callers.

**Commit policy recommendation.** Evaluate a semantic segment against working financial state while accumulating an ordered event sequence. A successful explicit `yield` commits that delta and persists the suspended machine. A normal terminal return commits its final delta. A local segment failure discards its tentative financial delta but retains already committed history, measured work and persistent duties. Proof-trace chunking alone changes neither balances nor duties. The ledger adapter must separately represent guaranteed/fallible phase outcomes, including retained fees; local atomic failure cannot stand for ledger rollback.

Define `foldEvents(initial, orderedEvents)` over typed transfers, fees, reserve changes and liability create/accrue/discharge operations. Record payer, recipient, asset and stage, plus opening/closing state. Preserve gross debit independently of refunds, net receipts after fees, and liability balance separately from token balance. Residual duties remain present until an explicit discharge event. Keep logical reductions, allocation and maximum stack depth separate from circuit rows, prover time, DUST and service charges. Profile identifiers name schedules; research supplies no calibration.

**Bounded Quint abstraction.** Use two actors, stack depth two, one asset, two pending calls and a short event list. State includes lifecycle `Running | Waiting | Returned | Failed`, committed and tentative balances, outstanding calls, abstract frame IDs, residual duties, committed prefix and cumulative work. Actions: `Call`, `Emit`, `SuspendCommit`, `Receive`, `Resume`, `ReturnCommit`, `FailSegment`. A projection maps K frames to bounded frame IDs and concrete reductions to abstract steps; it omits expression evaluation and recursive data contents. This is a proposed lifecycle simulation obligation, not established correspondence.

**Independent ordinary examples.** Start with 100 reserve units and liability 40. First segment pays 30, charges fee 2 and discharges 30: closing reserve 68, gross debit 32, recipient net 30, liability 10. Suspend inside the callee while its caller remains outstanding. Resume and pay 10 with fee 1: reserve 57, cumulative gross debit 43, recipient receipts 40, liability zero. If segment two fails before commit, reserve stays 68 and liability stays 10; its work remains consumed. Freeze these outcomes independently before any execution.

Proposed EARS: WHEN suspension commits, the interpreter SHALL persist the complete continuation and ordered committed effects. WHEN a local segment fails, it SHALL retain prior commits, consumed work and residual duties. Counterargument: per-segment commits complicate reasoning; offer an atomic no-yield subset first, while keeping suspension explicit in the universal state design. Host/codegen work includes continuation encoding and event serialization; native constraints require later mapping of machine transitions and commit boundaries, with no foreign prover port presumed.
