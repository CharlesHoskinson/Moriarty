# Sherlock: academic and open-source concept research

Ten independent online studies searched primary papers and project sources
after Candidate A and its optimization proposals were written. Each proposal
links its evidence; each source inventory records acquisition coverage, pins,
failures and limitations. Raw papers, downloaded code and private integration
content are not republished. Hashes are in [manifest.json](manifest.json).

The user explicitly selected concepts we can independently rebuild. Licensing
and backend differences inform actual copying or integration; they do not
exclude a useful algorithm from the conceptual comparison. No external
implementation or proof-system port is selected by this research.

| [02](02/proposal.md) | Lurk lineage, tagged recursive data, environments and witness slots |

[Concept adoption](../CONCEPT-ADOPTION.md) and the
[implementation plan](../../../SHERLOCK-IMPLEMENTATION-PLAN.md) integrate
selected ideas into the next design candidate. Source recommendations and
reported paper results are not Sherlock measurements. Existing model checks
do not validate that later candidate automatically.

Source limitations remain explicit: historical papers can differ from current
code; guessed URLs, access failures, draft documentation and license-classifier
differences are retained. Lane09 exceeded the default fifteen-document
acquisition ceiling while following fallback URLs and stopped further intake;
its reported facts remain bounded by the captured sources. No further
acquisition or research-project execution is authorized by this publication.

Public transport removes local checkout paths and corrects lane04's earlier unverified public-pin classification. Original research bytes remain retained; `manifest.json` records original and published hashes for each transformation.
