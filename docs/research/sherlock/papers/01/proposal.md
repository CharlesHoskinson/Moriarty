**Source facts — four freshly acquired source families.** Danvy–Nielsen’s November 2004 report replaces consecutive plugging and decomposition with a context-preserving refocus function under stated decomposition conditions. Fusing its driver produces a machine separating context-navigation and reduction transitions. The report’s motivating overhead concerns reduction implementations that reconstruct intermediate terms; it is not a result about an existing CEK interpreter. See §1.3–1.4 and Figure 1, PDF page index 7. [Refocusing in Reduction Semantics](https://www.brics.dk/RS/04/26/BRICS-RS-04-26.pdf).

Buszka–Biernacki’s 2021 tool **semt** implements ANF → control-flow analysis → selective CPS → renewed analysis → selective defunctionalization → let inlining. Sections 3.3–3.4 permit atomic and non-defunctionalized annotations; mixed requirements at one potential application cause transformation failure. Figure 11 illustrates explicit continuation records.
