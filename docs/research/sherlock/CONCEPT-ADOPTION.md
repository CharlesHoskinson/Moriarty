## Comparison contract

`sherlock-k-a/1` retains A's K charge/publication schedule and error4 classification. `sherlock-quint-a/1` retains the companion's terminal tick. `sherlock-helper-microstep/1` is a new proposed profile charging legacy machine transitions and explicit helper transitions separately under its named mapping. A physical optimization claims preservation only inside one declared profile and admitted envelope. No same-fuel K/Quint/helper-profile equivalence is inferred.

Compare complete ordered reference prefixes: control, full saved environments/frames, structural values and occurrence IDs, status/reason, consumed/remaining work, logical depth, capacities, effects, committed prefixes and residual duties where the financial adapter exists. Additional data/code/frame/environment/serialization/helper caps are admission changes, with supported, rejected, exhausted and unsupported outcomes distinguished. Current closed-body/unique-function admission is work to implement, not a checked fact. The direct uncached implementation and an independent normal oracle precede caches, grouping and specialization.

Measurements retain reference work, helper visits, physical steps, frame/environment/node bytes, preparation, active/padded rows, degree, key/proof bytes, time/memory, DUST and financial/service fees separately. A winner requires the declared complete-path metric to improve under equal observations and bounds. No measurement exists here. Opus 5.5 owns all security analysis, requirements, hostile tests, theorems and acceptance judgments; this matrix supplies no proxy security criteria.
