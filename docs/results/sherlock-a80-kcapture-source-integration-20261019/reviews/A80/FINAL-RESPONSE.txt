## Preserved S1–S3 and sequencing (re-checked, unchanged bytes)

- `Seal([u8;32])` has a private tuple field.

- The commit binds role, qualification and transcript; the `(record, identity)` digest; the length-prefixed statement; the claim digest, including the A80 carrier; the instance lanes; the VK; the proof; and the record digest.

**Shapes and admission.**
- `offsets()` uses checked arithmetic and enforces `charge+1 == n`. Every public caller checks before indexing.

**Manifest intrinsic validation.**

- The per-child chain covers name, filenames, qualification, format, binding, carrier presence, `decode_digest` of 7 or 8 digests, `instance_lanes`, `proof_bytes` in 1..=262144, k in 1..=19, envelope and the exact sealed obligation list.

**Two-child scope.** Two-child obligations and provenance remain honestly scoped: the provenance is producer-asserted and unauthenticated, and the disclosures still match the code.

## Owner premises resolved by the supplied bodies

- **`decode_digest` → `unhex(text, 32)`.** It requires exactly 64 bytes, each `0-9` or `a-f`. Uppercase, 62- or 66-character, `zz` and empty inputs all refuse. **Resolved.**
- **`mori_core::json::parse`.**
  - It enforces a 1 MiB cap, depth 32 and 65,536 nodes.
  - A duplicate decoded key gives a custom error; trailing data fails `decoder.end()`; truncated or empty input gives EOF. All of these map to the backend `json` code.
  - `visit_u64` keeps `usize::MAX` on 64-bit hosts.
  - The synthetic manifest is roughly 10 KB with fewer than 200 nodes and depth ≤ 4.
  - **Resolved.**
- **R1 missing-versus-null.** Resolved as above, subject to the serde_derive idiom premise.

## Non-mandatory notes (no action required for this cut)

1. **T-a.** `serde_json::to_value(manifest())["children"][0]["carrier_source_sha256"].is_null()` does not distinguish null from absent, because serde_json's `Index` returns `Null` for a missing key (serde_json not supplied). Explicit null is already pinned by the `text.contains` check and the missing-key refusal, so this is redundant, not wrong.
2. **T-b.** The three overflow cases assert only `j.is_err()`. From reading `json.rs`, these values reach `validate` on 64-bit hosts, so code and message could be asserted. That would be a portability trade-off.
3. **T-c.** The explicit-null `wire` case re-sets a value that is already `null`, so it is equivalent to the honest round-trip.
4. **T-d.** The synthetic manifest is built from the same constants and obligation lists that `validate` uses. It is owner unit coverage, not an independent oracle. A shared constant or order error would not be caught.
5. **API-a.** `MidnightVK::read` computes `k - 1` on a `u8` taken from the input bytes. That panics in debug and wraps in release when k is 0. Here it only re-reads bytes the module wrote itself. Any future child-file loader must pre-check before passing untrusted VK bytes.
6. **API-b.** `setup_vk` sizes by `params.max_k()` and uses `expect` on keygen. The `vk.k()` check and the `OfflineParameters` degree check line up. This is native and unobserved.
7. **API-c (retained, not this cut).** `validate` does not bound `instance_lanes ≤ 2^14`, and the public `Deserialize` derive means a direct `serde_json::from_str::<LinkManifest>` skips both `validate` and the strict parser.

## Retained gaps (not waived; this is not whole-system acceptance)

**Host-only authority.**
- `LinkedRequests` and the seal are host-only, in-memory authority.
- Source and claim metadata and all digests are unauthenticated.
- A caller-supplied shape's contexts are trusted in `check_link_lanes`.

**Circuit and ledger scope.**
- Init is not constrained in circuit, and genesis is a locator with no Poseidon root.
- The following remain open: projectA, F3, F4, F5, StepInv/O1–O4, OBL.G4, full39 (the other 38 rows), 0.8.3/0.8.2 cross-version compatibility, SRS, k, rows, resources, parent and terminal, anchor, target and financial work.

**H1 physical limits.** The Clone, Eq and Drop recursion limits on `Program`, `Value`, `Tree` and `Environment` remain. Admission does not bound `Drop` of a deep caller-built `Arc<Program>`, or the derived `PartialEq` over `&Program`.

**Export durability.**
- The directory is not fsynced.
- A failed export is not cleaned up.
- `link.json` is not a durable commit marker.
- There is no child-file reader profile or loader.
- `instance.json` grows past 1 MiB above roughly 15.6k lanes.

**Separately owned work.**
- The Fenrir /2 reader still needs reconciliation for required `null` and the upper k bound.
- The F5 loader is a separate candidate.
- This cut makes no claim to compose with the unborn corrected reader, and no native eligibility claim.
