The missing relation was executable Lt/ReturnRight completion. The retained K model has Add but no Lt expression or source-bearing primitive completion/error control. This candidate adds a separate module rather than editing the existing model or the queued constructor-completion cut. Three existing K sources are byte-identical; three new K files declare and implement Lt and import the unchanged complete observer.

ngLt evaluates both source operands in order, preserving source occurrence and saved current environment in LtLeft/LtRight frames. Canonical UInt128 values compare as mathematical integers and produce a Bool primitive result. Completion pops only the Lt frame; every caller/field/scope frame remains. A separate primitive value step returns Bool so existing typed FunctionReturn/ConstructorFields and scope rules consume it normally. It does not equate a K step with B Scalar helper, ReturnRight, primitive or cost counters.

Canonical wrong-kind values produce source error11 rather than overflow10. The next primitive error step reaches a stable error-control boundary with enclosing frames intact. This is not P1 Rejected publication and does not unwind FunctionReturn or invent a caller restoration on error. Raw scalar UInt outside the admitted range produces OutsideModel and retains the pending Lt frame. Canonical admitted nominal values remain an external premise; this module does not add generic validation/admission or security guard policies.

The success, sort-error and scalar-malformed conditions are disjoint: either an UInt tag has an out-of-range integer; or both are in-range UInt; or both scalar representations are in-domain and at least one kind is not UInt. Nominal declaration/field canonicality is a premise. No fixed case IDs or operand values occur in semantic rules.
