# Handwritten Scalar Add/Sub circuits and typed publication composition

This source cut contains actual ZKIRv3 instruction emitters for checked UInt128 Add and Sub, Scalar completion, operation-specific return-right, primitive value/error and typed five-stage publication composition. The parent registers the three Sub modules with named exports; Sub carriers remain distinct and the Sub return-right guard preserves operator 1.

The 13 files have scoped independent source opinions. These are source and wiring results. The 43 existing test bodies plus three Sub arithmetic test bodies remain UNRUN against the SDK; this cut has not been Rust-compiled, SDK-preprocessed, proved or submitted to Midnight. The new three-branch Sub-chain test source is a separate candidate and is not included here.

Caller assumptions retain whole-source namespace ownership, upstream dispatch and provenance, bounds, complete AB/StepInv, physical packing, field and proof obligations. Full39/B96, financial, formal and target acceptance remain open. Historical source identities and actual opinions are preserved in the accompanying map.
