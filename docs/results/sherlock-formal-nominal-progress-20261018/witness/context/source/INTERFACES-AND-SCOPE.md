# Saved-record reference projection (source only)

The new `helper_machine::reference_projection` consumes complete saved observations from the existing fixed owner. It retains the exact source AST, joins every observed expression/function/parameter/arm row to that source, resolves values and newest-first environment chains with the existing uncached witness plan, and translates all nine frame variants plus full control/outcome payloads. Visible reference environments are lexical maps; all shadowed B cells remain in the accompanying raw/decoded snapshots.

`ReferenceSource::new` associates source and observed program tables. `project_reference_boundary` returns a complete reference snapshot or a complete pending-helper observation. `ReferencePrefixProjection::push` consumes saved, continuous B records; it accumulates complete helper intervals until an actual mapped source event has completed at a helper/result/task-free boundary. A `ReferenceSpan` includes all actual raw micro-records, the source-event index and the complete translated before/after record. `finish` refuses a trailing incomplete interval. It does not evaluate either machine, import states or authorize a cut.

Raw B initial/remaining/consumed/helper counters, source occurrences, event IDs and allocation counters remain distinct and available; they are never relabeled as A steps. Unsupported nominal values/types, unmapped rules, broken association/continuity and physical resource divergence are typed tooling gaps. No guard, budget, admission or owner transition changes are proposed.
