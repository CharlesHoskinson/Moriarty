# Local pattern-frontier correspondence declarations

Profile sherlock-quint-pattern-frontier-correspondence/1 is a LOCAL reference-model bridge, not sherlock-helper-microstep/1 and not a B schedule. It preserves the accepted B09 result semantics while exposing one indexed pattern inspection or one indexed source-field pair at a time. Diagnostics count local transitions/reads/field pairs/bindings and maximum pending tasks only. They are not B consumedWork/helperWork/visits/fuel or native/circuit cost. No new B rule ID/tag/charge/error/capacity policy is assigned.

Input has sourceMatchId, ordered arms {sourceArmId,bodyExprId,patternRoot}, valueRoot, valueRows, valueFields, patternRows, patternFields, decodedValues, encodedPatterns, sourcePaths, binderOrigins, savedEnvironment, layouts and analysisBounds. ValueRow={token:Token,children:{start,len}}, using B09 Token; PatternRow={token:PatternToken,children:{start,len}}, using B09 PatternToken. Source tree patterns and graph field references are prepared as finite immutable rows. decodedValues and encodedPatterns are INPUT representation witnesses, checked outside local advance; they are never read to advance an operational cursor. Source row IDs are not source-occurrence IDs. The source identity is (sourceMatchId,sourceArmId,fieldPath).

Task=InspectTask{patternRow,valueRow,path}|FieldTask{parentPattern,parentValue,patterns:{start,len},values:{start,len},cursor,path}. FieldTask.cursor is the next not-yet-scheduled source field; a child InspectTask is placed before its incremented parent FieldTask. No field list is eagerly traversed/decoded by advance. Wildcard consumes a task with no binder and no value-header lookup. Bind stores {name,valueRow,path}, retaining a complete immutable value reference. Constructor checks the pattern/value nominal header identity/arity and pushes a FieldTask. FieldTask inspects one ordered child pair per local advance. A mismatch discards all tentative bindings and tasks before the next source arm. NoArm is a local matching result, not a production application Outcome/error. Selection retains the first successful zero-based arm index and projects binding references over the saved environment separately.

Cursor retains the entire immutable input, phase BeginArm|Walking|Selected|NoArm, zero-based armIndex, tasks top-first, partial bindings in source preorder, complete pattern-visit records, diagnostics and latest local event. Visits={armIndex,sourceArmId,path,patternRow,valueRow,token}; event is local diagnostic only. Every pending prefix may be paused and resumed from its exact cursor. Terminal local advance stutters exactly. No production serialization/checkpoint ABI is introduced.

Reference result projection decodes only after completion, outside advance. It is compared to the accepted B09 pure nestedPatternMatch across source arms in order. This is a model-to-model correspondence check, not fresh independent expectations. A source-path order property compares actual pattern visits with the immutable source preorder-path input; selected arms must consume their complete source preorder while missed arms retain only a prefix. Partial bindings must reference the value at their exact input source-field path. These checks target eager child traversal, skipped shared occurrences, reordering and failed-arm binding leakage. Same saved environments and every partial/pending field cursor remain observable.

No B09 old8/shared4/455machine-prefix tests are rerun. All new model/frontend checks remain UNRUN by author.
