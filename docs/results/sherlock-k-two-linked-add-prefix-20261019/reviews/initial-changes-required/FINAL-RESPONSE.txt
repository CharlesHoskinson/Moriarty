# Independent source and operation review: two linked uncharged Add windows

**Reviewer:** claude-opus-5-5. I cannot observe my own effort setting, so I can't confirm "HIGH". I used no tools, shell, subcalls, edits or execution. This was one read of inline bodies 1–26. I did not request, read or derive any protected oracle body.

## Headline

The plan as written is **CHANGES_REQUIRED** because of one blocking defect in phase 01. Phases 02–10 are sound under Root obligations, but none of them can run until 01 succeeds.

**Blocking defect: phase 01 will fail to import its own adapter.** It runs `/usr/bin/python3 -I -B -S …/adapter/render_input.py`.
- Python documents that in isolated mode (`-I`, which implies `-P`), `sys.path` does not contain the script's directory.
- `render_input.py` does `import nominal_trace_codec` and `from complete_k_wire import CompleteKWire`.
- So it will exit with `ModuleNotFoundError` before writing anything. This fails closed, but nothing downstream ever runs.
- Phases 05 and 08 avoid this because they call `sys.path.insert(0, ADAPTER)` first. Phase 09's linker imports only the standard library, so it is unaffected.

**Minimum fix:** no helper source change is needed. Replace phase 01's argv with a `-c` body in the same style as 05 and 08:
- `sys.path.insert(0, ADAPTER)`
- `sys.argv = ['render_input.py', '--input', …, '--api', …, '--syntax', …, '--output-dir', …]`
- `import render_input; render_input.main()`

That new argv needs re-review. Also add `initial.ng` and `query.term` to phase 01's products; the list is currently `[]`.

## 1. SOURCE — composition is correct; no missing callable

**K semantics** (rules identified only; I did not author a predicted trace):
- **Window 1:** `ngObserve(S0,1)` checks that `ngEval` is non-terminal. `ngStep` fires the `ngEvaluate(ngFoundExpr(ngAdd(…)))` rule. That pushes `ngAddLeft` with source IDs, occurrence and saved Map, and appends exactly one `ngAddStarted`. The budget is then 0, so the result is `ngTape(S0,[S1],S1)`.
- **Window 2:** from S1, the Literal rule for the left operand fires. It appends one `ngLiteralEvaluated` and leaves frames and Map unchanged.
- **Scope consequence:** with a whole-case budget of 2, the trace never reaches `ngAddRightRequested`, `ngAdded`, `ngFinished` or any terminal. The terminal-stutter contract is carried as metadata only; it is not exercised.
- **`--depth 1` is not the step counter.** Every rule has a `[function]` head, so kore-exec evaluates during simplification. The one-step windows come from the `ngObserve` Int bound, not from kore-exec depth.

**Parsing and decoding**
- The `configure` regex correctly registers every base and Lt constructor from the combined syntax. Comments are stripped, and the `\n\s*syntax` and `\nendmodule` lookaheads hold for both modules.
- The `CompleteKWire.__init__` arity checks pass against the public API. I checked ngLtCompared, ngLtSortFailed, ngLtPrimitiveReturned/Failed, ngLetBound, ngBranchSelected, ngAddStarted, ngAddLeft and ngEval, all with exact field counts.
- Unevaluated function residue fails closed. `ngObserve` is not registered, so the parser rejects it. `ngInitial` is registered as NGState but is rejected by the `_args(…, 'ngState')` check.
- The glue reads `parser.API` and `parser.REG` after `configure()`, so it gets fresh globals rather than stale imports. The keyword arguments to `bind_shared_wire` and the `resume_query(bytes, int) → (bytes, dict)` call match their definitions.

**Preservation**
- **Map:** decoded to a sorted list with all rows kept.
- **Frames:** kept top-first.
- **Events:** kept in cumulative append order, and the one-event continuity check is enforced.
- **Program:** the same object is checked in every state.
- **Source IDs and occurrences:** taken from the input table, with no remapping.

**Raw carry is genuine.** `resume_query` byte-slices the third argument of the raw `ngTape` from `result.kore` and only checks that it is a 5-ary `ngState`; it does not regenerate anything from JSON.
- The link is verified independently. Phase 09 checks that the whole typed decoded first final equals the decoded second initial.
- One premise is unverified: the label constants `OBSERVE`, `TAPE` and `STATE` have not been checked against this cohort's `definition.kore`. A mismatch would fail closed.

**Schema**
- Each window has the six root fields and five-field states.
- `observerCuts` is `list(range(2)) == [0,1]`, as `checked_window` requires. The joined wire is `[0,1,2]`.
- Integer vs Bool is preserved by the `type()`-strict `same` function and by `json_domain`.

**Missing callables**
- Not part of this plan's glue: none.
- Not supplied: the Root orchestration driver (directory creation, pins, fsync, stop logic, building `record`), and the F03 bodies `kast_command`, `exec_command` and `kprint_command`. I therefore can't confirm that the argv forms match F03's. I judged them on their own.

**Minor finding:** the linker's receipt says `observerCuts_derived_from_actual: True`, but `[0,1,2]` is a constant. It is only valid because each window is checked to have exactly 2 states.

**Shadowing hazard (phases 05, 08 and fixed 01).** `sys.path.insert(0, ADAPTER)` puts the adapter directory ahead of the standard library for later imports such as `dataclasses`, its dependencies, and `typing`. Also, `-B` only stops Python writing `.pyc` files; it still reads them. An existing `__pycache__` (especially an unchecked-hash `.pyc`) in the adapter directory or the raw-helper directory would be executed.

3. **Per-phase checks after each run.**
   - Process outcome: `returncode == 0`, `timed_out False`, `outcome 'exited'`, `remaining == []`, `containment_breach False`.

## 3. SCOPE

What a pass would establish:
- K function-semantics reductions for two one-step prefixes, joined at one byte-carried, whole-typed-equal boundary.
- Equality of the complete 3-position trace with a prefrozen independent expectation.

That is more than boundary-only identity, which is all that phase 09 alone checks. It is still only a two-step prefix of Add (Add start plus the left literal). It does not establish:
- the Add result, or behaviour at the terminal boundary;
- a charged A/B clock, Kwork or fuel;
- recursive-child, public-state, proof or circuit equivalence;
- production Rust endpoint correspondence (still pending its owner);
- any native, security or adoption grant.

The zero-based `observerCuts` value comes from the existing decoder and consumer (`list(range(len))`, a fixed `[0,1]` check, and constant `[0,1,2]`). It is representation only, not an adjustment to the expectation. If the oracle used a different base, phase 10 fails closed rather than passing falsely.
