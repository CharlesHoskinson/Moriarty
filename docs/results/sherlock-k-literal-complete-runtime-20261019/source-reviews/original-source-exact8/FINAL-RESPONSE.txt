## 2. New helper (`complete_images_runtime_data.py`)

### `frame`
- It accepts either a bare `LbllcRun…{}` with arity 5 or the exact `INJECTION` bytes.
- It builds `generatedTop(<k>(kseq(inj(run),dotk())), generatedCounter(\dv Int "0"))`.
- It proves the inverse back to the stripped bytes, byte-exact.
- Typing against the quoted declarations is correct: the cell arities and sorts of lines 10, 11, 211, 212 and 214, and LCRun at line 382.
- `<k> lcRun(..) => .. </k>` with no `...` matches a single-item `kseq` with a `dotk` tail. This is the shape `initGeneratedTopCell` would produce.
- No step is computed.

### `audit`
- It binds the complete context, capacities and Program at all four machine positions, and checks that Init equals `source.init` and final equals done.
- It checks `event1.before/after` = initial/middle and `event2.before/after` = middle/done.
- It checks the integer-typed envelopes (102,3,1) and (80,0,0), which distinguish charged A102 from free A80.
- It compares all 335 lanes against the concatenation of the actual images and events.
- It checks layout, authentication and provenance strings.
- It predicts nothing.
- Wording note, not a defect: `distinct_state_positions: 3` and "advancing" label positions only. Value distinctness is not checked.

### `compare`
- It reads the freeze, checks `expected_body_reads == 0` (int) and that `actual_observation == pin(--input)`.
- It re-pins the observation, the audit and every freeze product, then checks the audit status and the audit-to-observation binding.
- Only after that does it open the binding and then the expected body.
- Equality is whole-object and typed: dict key sets, list order and lengths, and the `int`/`bool`/`float` distinction.
- On FAIL it exits 1 after writing the receipt.

### Imports
- `-B -S` without `-I` puts `source/` first on `sys.path`. That is safe only under exact four-member directory membership, which is a stated condition.
- `-B` prevents a `__pycache__` from being created and breaking that membership.

## 4. Conditions for exact8 (non-source)

1. **Oracle contract precision, before issuance.** The comparator is whole-object, so representation must be fixed in advance. Declare the exact JSON shape of these fields:
   - `logical_layout.segments` as an object keyed by the seven names, each `{start,length}`, plus `statement_lanes` as an int.
   - `afters` as the ordered list [intermediate, done].
   - Machines as exactly `{context,capacities,program,state}`.

   Without this, a FAIL could be representational rather than semantic. Re-pin the contract and SAFE-READSET afterwards. Pin the PROMPT bytes and confirm that the PROMPT contains only the SAFE-READSET material.
2. **Exact pin rows.** `pinned()` requires each row to equal `pin(path)`, meaning exactly `{path,bytes,sha256}`. Any extra key fails. The freeze must contain:
   - `expected_body_reads: 0`
   - `actual_observation`, whose path string is identical to the phase-08 `--input`
   - `actual_audit`, the 07 product
   - a non-empty `products_streams_receipts` covering all 01–07 streams, products and Root receipts

   The binding must be exactly `{"expected_complete_observation":{path,bytes,sha256}}`. The code does not enforce the other identity content in the freeze; Root owns it.
3. **Root inventories each phase cwd**, as F03 `stage_problems` did, to catch unexpected files such as `hs_err_pid*.log`. `F03.launch` alone does not do this.
4. **Root rechecks the expected-body hash opaquely around every child.** State explicitly that `expected_body_reads` counts reads by phases and the source author, not Root's hash-only rechecks.
5. **Prior conditions stand:** private prefreeze and binding before phase 01, all dynamic pins, fresh 0700 roots, and the durable freeze before phase 08.

## 5. Runtime risks (all unobserved; each stops fail-closed with no guessed repair)

- **Phase 05 → 06 framing (highest risk; prior F5 still open).** The configuration is now a framed `generatedTop`. kprint may emit `<generatedTop>…<generatedCounter> 0…`, `lcResult(…) ~> .K`, or `#And`/`#Top` if kore-exec returns a conjunction. The unchanged decoder strips only a bare `<k>…</k>` and rejects `<` and `~`. A rejection must be recorded as a framing non-pass, not patched within this plan.
- **Phase 03.** If kast emits `inj{SortLCRun{}, SortKItem{}}` with a space after the comma, `frame` rejects it, because `INJECTION` has no space. A bare `LbllcRun` emission is expected.
- **Phase 04, unquoted declarations.** The `inj` and LCRun→KItem subsort declarations are not quoted, though `syntax KItem ::= LCRun` implies the subsort exists.
- **Phase 04, engine behaviour.**
  - Nonlinear function left-hand sides in `lcPrepend` and `lcFinish`, and `owise` rules.
  - Side-condition evaluation under `--smt none`.
  - Whether a cold definition load plus evaluation fits in 30 s.
  - If `lcRun` stays unreduced, phase 06 rejects it.
- **Phase 08 diagnostics.** A FAIL does not show which lanes differ, so it cannot separate an oracle arithmetic error from a K error. Adjudication would need Root-owned follow-up.
- **Host dependencies.** The Python 3.14 stdlib and the libc dependencies of the kompiled `scanner` are not pinned.
