The public interfaces now include:

- `c6_phys_data`: owned data-node, data-field reference, environment-cell and value-slot sections; explicit tags/payloads, Const/Data references and raw slices.
- `c6_phys_helper`: helper control, helper result and ordered task sections, preserving enum/phase/option fields and existing representation caps/error order.
- `c6_phys_state`: one framed image/data/helper section with checked directory lengths and an explicit capacity/context descriptor. `encode_state`/`decode_state` operate on `C6OwnedState`; `state_lanes_from_host` and `host_with_decoded_state` consume the existing owned observation. `compare_uncached_witness` compares the existing uncached plan/evaluation before and after decoding over caller-selected lifetimes.

These codecs admit nothing, construct no live `MachineImage`, and replace no owner transition. They preserve representation, including stored counters independently of vector lengths; they do not establish cross-field membership, StepInv or owner admission (Chunk4). The context is caller-supplied, not a cryptographically authenticated identity. `max_total_lanes` bounds the encoded section only; it does not bound unfolded witness work or quadratic environment copying. Equality of decoded host state plus deterministic existing witness code explains the preservation comparison; it is not independent A/B semantics or native refinement evidence.
