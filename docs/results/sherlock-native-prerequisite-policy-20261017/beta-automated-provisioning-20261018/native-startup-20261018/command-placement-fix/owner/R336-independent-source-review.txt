#### B. Pre-Handoff Outcomes: Success, EOF, Bad Message, Nonzero Flags, Ancillary Mismatch, Timeout, OS Errors & `SIGALRM` (`L665–693`)
1. **Timeout & Pipe Registration Before Handoff (`L665–667`)**:
   - `child.close()` closes the parent copy of the child socket immediately after `Popen` (`L665`), ensuring `parent.recvmsg(...)` returns immediate EOF (`message == b''`) if the child process exits or crashes before sending `'L'`.
   - `parent.settimeout(max(.001, v['wall_seconds'] - (time.monotonic() - start)))` bounds `recvmsg` to the remaining phase wall-clock budget (`L665`).
   - `proc.stdout` and `proc.stderr` are placed in non-blocking mode and registered on `sel` (`L666–667`) **before** `parent.recvmsg(...)` is called.
2. **All Pre-Handoff Failure Modes Caught by `except BaseException:` (`L668–677`)**:
   - **Success**: `message == b'L'`, `flags == 0`, single `SOL_SOCKET`/`SCM_RIGHTS` ancillary item unpacking to `len(received) == 1` sets `listener = received[0]` (`L670–676`).
   - **EOF (`b''`) or Wrong Payload (`!= b'L'`) or Nonzero `flags` (e.g., `MSG_CTRUNC`)**: Fails `need(message == b'L' and not flags, 'listener handoff failed')` (`L671`), raising `Refusal('listener handoff failed')`.
   - **Ancillary Level/Type Mismatch**: Fails `need(level == socket.SOL_SOCKET and kind == socket.SCM_RIGHTS, 'unexpected handoff')` (`L673`), raising `Refusal('unexpected handoff')`.
   - **Zero or Multiple `SCM_RIGHTS` FDs (`len(received) != 1`)**: Fails `need(len(received) == 1, 'exact one seccomp listener required')` (`L676`) **before** `listener = received[0]` is assigned, raising `Refusal('exact one seccomp listener required')`.
   - **Socket Timeout / OS Error / `SIGALRM`**: `socket.timeout` (`TimeoutError`), `OSError`, or `SIGALRM` (`stop_alarm` raising `Refusal('whole-job wall cap')`, `L275–276`) all inherit from `BaseException` and enter `except BaseException:` (`L677`).

#### C. Received `SCM_RIGHTS` FD Ownership & Closure Across Pre-Handoff Failure and Post-Handoff `finally` (`L668–680`, `L712`)
- `received = []` is initialized prior to `try:` (`L668`), and every unpacked `SCM_RIGHTS` integer FD is appended via `received.extend(values)` (`L675`).
- On any synchronous pre-handoff failure (including ancillary mismatch on a second cmsg header or `len(received) != 1` when >1 FDs were passed), `listener` remains `None`, and the `except BaseException:` block closes every unpacked FD in `received`:
  ```python
  for rfd in received:
      try:os.close(rfd)
      except OSError:pass
  ```
- On post-handoff execution (once `listener = received[0]` succeeds and the `try` block exits normally), `listener` owns the single FD and the inner `finally:` (`L712`) closes it via `if listener is not None: os.close(listener)`.
- *(Minor non-blocking observation)*: If an asynchronous `SIGALRM` were to fire on `L676` in the sub-microsecond window after `listener = received[0]` executes but before the `try:` block exits, `except BaseException:` would close `rfd` (`received[0]`) and inner `finally:` (`L712`) would call `os.close(listener)` on the already-closed FD number (single-threaded process, no concurrent FD allocator). Moving `listener = received[0]` to the `else:` clause of `try:` (or setting `listener = None` inside `except BaseException:`) would eliminate even that theoretical `SIGALRM` double-close, though it does not affect normal synchronous failure paths or single-threaded safety and does not block `APPROVE`.

#### D. `group.kill()`, Bounded Failure Drain, Stream Budgets & Non-Masking of Original Exception (`L681–693`)
1. **Immediate Cgroup Termination Before Drain (`L681`)**:
   - `group.kill()` writes `'1'` to `sdk-once-<phase>/cgroup.kill` (`L263–266`) **before** entering the drain loop (`L682`). This immediately terminates `bwrap` and any descendants inside the phase cgroup so that child pipe write-ends close promptly and the drain loop cannot stall on a live child.
2. **Selector Contents & Bounded Drain Loop (`L682–692`)**:
   - Because `sel.register(listener, ...)` (`L694`) occurs **after** the pre-handoff `try...except`, `sel.get_map()` inside `except BaseException:` contains exclusively `(name, log)` entries for `proc.stdout` and `proc.stderr` (never `('network', None)`).
   - The drain loop runs while `sel.get_map()` is non-empty, breaking immediately if:
     - `time.monotonic() - start > v['wall_seconds']` (`L683`, respecting the phase wall deadline without raising a `wall cap` `Refusal`), or
     - `not events and proc.poll() is not None` (`L685`, exiting once the killed child has terminated and no pipe events remain).
   - For each readable pipe, `take = min(len(chunk), max(0, v[name+'_bytes'] - counts[name]))` (`L689`) clamps writes to the remaining per-stream byte budget (`v['stdout_bytes']` / `v['stderr_bytes']`) and unregisters the stream if `take < len(chunk)` (`L691`) or EOF (`not chunk`, `L688`).
3. **No Exception Masking (`L682–693`)**:
   - Unlike the normal post-handoff loop (which calls `need(...)` on wall cap and log cap), the failure drain uses `break` on wall deadline and `min(..., max(0, ...))` clamping on stream byte caps, and `group.kill()` catches `(FileNotFoundError, ProcessLookupError)`. Thus, neither log-cap overflow nor deadline expiry during error drain can raise a secondary `Refusal` that masks the original pre-handoff exception re-raised by bare `raise` at `L693`.

#### E. Post-Handoff Loop, Listener Registration, `group.check()`, `group.close()` & All `finally` Paths (`L694–727`)
- **Post-Handoff Selector Loop (`L694–705`)**: Registers `listener` as `('network', None)` at `L694`; loops while `len(sel.get_map()) > 1 or proc.poll() is None`; enforces `v['wall_seconds']`, `group.check()` (`events.get('oom_kill', 0) == 0` and `events.get('oom', 0) == 0`), `not network_pending(listener)`, and `counts[name] <= v[name+'_bytes']`.
- **Post-Exit Checks (`L706–708`)**: Verifies `proc.wait() == 0`, `group.check()`, `not network_pending(listener)`, and `read_numbers(group.path/'cgroup.events').get('populated', 0) == 0` (no background descendants).
- **Inner Variant `finally:` (`L710–717`)**:
  - Disarms `ITIMER_REAL` if unwinding an exception (`L710`).
  - If `proc` is still running (`proc is not None and proc.poll() is None`), calls `group.kill(); proc.wait(timeout=5)` (`L711`).
  - Closes `listener` (if not `None`), `parent`, `child` (Python `socket.close()` is idempotent after `L665`), `fd`, `stage_fd`, `token_fd` (if `>= 0`), `sel`, and each file in `logs` (`L712–717`).
- **Outer Phase `finally:` (`L725–727`)**:
  - Disarms `ITIMER_REAL` on exception (`L726`) and calls `group.close()` (`L727`), which kills the phase cgroup, waits up to 5s for `populated == 0`, and `rmdir`s `sdk-once-<phase>` (`L267–274`).
