## 1. Mandatory source findings

### S1 (blocking): `compare` is guaranteed to raise `RecursionError` on any equal whole document

`root_data.compare` calls `base.same(actual, expected)`. `base.same` recurses through a generator expression at every container level:

```
same(dict) → genexpr → same(list) → genexpr → same(dict) …
```

That is 4 live Python frames per typed `ctLane` node.

Each `CTLanes` chain has 48 + 13 × frames lanes:

- I checked case 00 by hand: 17 frames, so 269 lanes.
- Case 01 and case 07, also checked, have 17 frames as well.
- The other cases appear to be rotations of the same 17 frames.

At 17 frames, the stack reaches the last lane of answer 0 at about 12 + 4 × 268 ≈ 1084 frames. That is beyond CPython's default recursion limit of 1000. `/usr/bin/python3` resolves to 3.14, where the Python-frame limit still applies.

The traversal only reaches that depth when every earlier field matches. So:

- an equal (correct) actual always raises a traceback;
- under the frozen classification rules, that traceback after dispatch is counted as **UNKNOWN**;
- PASS is therefore unreachable.

Running 06 as frozen would spend the single prospective comparison and read the expected body without any possible positive result.

**Required change (Opus source owner, since it replaces the comparator used in `compare`):** add an iterative comparator in `root_data.py` with exactly the semantics of `base.same`, and use it in `compare`. Leave `c6_data` untouched.

```python
def same_whole(a, b):
    stack = [(a, b)]
    while stack:
        x, y = stack.pop()
        if type(x) is not type(y): return False
        if type(x) is dict:
            if x.keys() != y.keys(): return False
            stack.extend((x[k], y[k]) for k in x)
        elif type(x) is list:
            if len(x) != len(y): return False
            stack.extend(zip(x, y))
        elif x != y: return False
    return True
```

Do not "fix" this with `sys.setrecursionlimit`. That only moves the failure from the Python limit to the C stack.

### S2 (mandatory with S1): `test_root_data.py` cannot detect S1

None of the 6 methods exercises `compare` or a lane-depth structure. Add normal positive/negative data tests that build two independent deep typed lane trees with loops. Use at least 600 nested `ctLane` nodes so the test exceeds the real depth with margin. The tests must show:

- equal trees give `True` under the default recursion limit;
- changing only the deepest scalar gives `False`;
- a deepest `Bool` `true` against an `Int` `1` gives `False`.

Use no expected body and no hostile parser input. Record the new test before the source change, as the existing first-test record did.

### S3 (recommended, cheap to include in the same revision): bind operands in source

- `INPUT_PIN` is only used by the tests. `render` and `decode` accept any self-consistent `source_input` pin from the manifest. Add `if m['source_input'] != INPUT_PIN: raise ValueError(...)` to both.
- `compare` could likewise require `m['expected']` to equal the public opaque pin (613495 B, `4ca15348…`). That is a hash-only constant, so it does not expose the expected body.

## 2. Mandatory Root and caller conditions (not source changes)

**R1.** Before 01 and before 05, Root must verify that each manifest's `source_input` is byte-identical to the 726918 B `6f029ff2…` pin. This stays mandatory even if S3 is adopted.

**R2.** Before 06, Root must verify the barrier itself, because `base.validate_barrier` is weaker than the frozen conditions. It only checks that `expected_body_reads` is the int 0 and that the actual pin is a member. Root must also check:

- the exact 3-key member pins;
- `expected_body_read_scope`;
- fsync of all files and directories.

Root must also verify that the 06 manifest `expected` equals the opaque pin exactly.

**R3.** Classify 06 only from a valid, complete stdout JSON plus empty stderr. A traceback exits with code 1, the same code as a genuine FAIL. Set the parse count to `None` before dispatch, as already frozen.

**R4.** The F03 `launch` callable only records the child process. The Opus-owned caller must supply everything else around it:

- fresh 0700 working directories;
- the exact allowed-file membership check for each stage;
- source, compiled-15, tool and helper pins before and after every child;
- hash-only checks of the expected and freeze files;
- stop-on-first-problem behaviour.

This is what makes the verdict CONDITIONAL rather than ELIGIBLE after S1 and S2 are closed.
