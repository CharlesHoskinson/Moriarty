# Public draft B execution source proposal

Capability predicate: an external caller supplies a dedicated draft source and
explicit config/target strings to `run_draft_host`; the bounded public pipeline
produces one actual admitted pair, projects that pair's unstepped preparation,
then the fixed B owner runs that same admitted/image pair and forwards its full
events once. The returned `CompletedRun` contains the actual final image and
summary; it is not a source result literal or an A-model evaluation.

This is an ordinary orchestration source proposal. Root requested no execution
and assigned independent runtime expectations to a different author. No tests,
fixtures, expected runtime values, execution receipts or acceptance are authored
by this lane. General H1 and owner allocation/cleanup premises remain explicit.
