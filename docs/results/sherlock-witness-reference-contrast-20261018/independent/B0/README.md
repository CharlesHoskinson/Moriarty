# Independent B0 normal work-prefix expectations

This is a specified-only schedule and numeric work oracle for the previously
independently frozen factorial3, list[2,5], tree4/(1,3) and factorial2 inputs.
No evaluator, owner/family implementation, projector, DAG/materializer or actual
trace was read or run. The standalone adopted materialized schema237a3f31,
R4 rowsa0dd03b1 and overlay79d27df9 are the normative basis. Proposal-era labels
remain historical: BASIS-MEMBERSHIP and QUALIFIED-SOURCE-DECISION bind their
qualified host use. H1 is retained; this data grants no invocation authority.

The normative positive helper rows suffice to derive a complete charged clock
and rule schedule for these uncut cases. There is no need to substitute A fuel
for B fuel. The derivation annotates every independently authored A record with
its preceding explicit B helper interval, then its separate legacy completion.
It does not evaluate a program or copy an actual B result. Full existing A
program/state/frame/environment data remain in their original pinned oracles.

The data materializer contains the positive interval tables and explanatory
source references. Scalar UInt literal validation has entry, occurrence, empty
and exit. Compound literals independently unfold each occurrence and ordered
field. Appending the one argument uses entry/empty/tail/exit. One-function
lookup uses entry/row/exit. One-parameter Bind uses entry/pair/empty/type/insert/
exit. EnvGet inspects the actual expected persistent lexical binding chain,
not a sorted visible map. Match inserts binders in source order over its saved
chain. Return/scope/caller restoration tracks those chains independently and
checks their visible meaning against every pre-existing A snapshot.

UInt Eq uses Equal.entry/different/exit for unequal scalars, and entry/pair/
empty/exit for equal scalars. Positive arithmetic uses Scalar.entry/tag/
arithmetic/exit. Bool/type tests use entry/tag/exit. Literal recursive values,
shallow match attempts, selected bindings and all traversal occurrences are
retained. A failed shallow arm still has its own charged interval before the
next A arm attempt. There is no implicit zero-cost helper closure or cached
skipping. Free final publication produces a record without increasing work.

Each file contains the complete ordered clockPrefixes table, including genesis
and every after-event prefix, plus every complete helper/legacy interval.
Numeric columns are consumed_work, helper_work, helper_visits, reference_cursor,
remaining_work and the explicit semantic A snapshot index. An interval helper
prefix erases to the pinned complete legacy pre-snapshot; legacy completion
advances to its complete post-snapshot. A's virtual fuel stays in that A oracle;
B remaining_work is separate. Every row satisfies W_B-H_B=reference_cursor by
the selected normative schedule. This is finite expected arithmetic, not a
general refinement proof or a claim about the implementation.

Helper visits are supplied independently as a diagnostic. They are not fuel,
copies, cache hits or memory. Host wall time and bytes are absent. Full raw B
physical row IDs, helper payload/cursor/task images, allocation history and
earliest capacity outcomes are not supplied by these clock files. Complete raw
MachineImage equality, actual current rule realization and the global B-to-A
theorem remain unproved. A consumer must compare actual clocks/rule sequences
to these independent values; it must not populate missing actual fields from
expected data or infer complete035 acceptance from a matching final total.

The exact source inputs use initial fuel4096/stack64 and the original explicit
DedicatedSorts/Absent host layout. Their source excerpt and program-oracle pins
are bound in the freeze. The contrasting factorial2 changes the source program
and immutable input identity; it is not a continuation or same-key warm hit.
Existing A39 oracles, source identity maps and all other fixtures are unchanged.

`verify_numeric_data.py` independently reads the resulting JSON and normative
rows, checks each declared helper interval/legacy record, every work/visit/cursor
sum and semantic-index association, exact source pins and available fuel. This
is data integrity, not subject execution or semantic approval. Root and a fresh
nonauthor reviewer receive populated values. Authors receive SAFE-BINDINGS only.
