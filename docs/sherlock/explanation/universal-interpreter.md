# About Sherlock's universal interpreter

Draft, 2026-10-17. The audit baseline is public source `628615a9`; the later ordinary stream receipt binds its exact source snapshot. The reconciled [final03 design](../design.md) governs planned increments. Subsequent [finite Quint validation](../../results/sherlock-quint-design-20261017/README.md) passed44 selected tests and five directed/sampled runs; its declared omissions remain open.

Sherlock is intended to give Moriarty one reusable machine for supported programs. Program tables, input and machine state vary; the interpreter's transition rules supply the execution meaning. This makes a newly authored program a test of the same language implementation, rather than a reason to handwrite another evaluator or manufacture a literal with its answer. The [product contract](../../MORIARTY-PRODUCT-CONTRACT.md) retains mandatory financial and proof obligations and permissionless public developer use.

“Universal” has a declared domain. It does not promise every source construct, unbounded execution or arbitrary native recursion. The current A host represents UInt128, Bool, lists and trees, named self/mutual calls, strict argument order and ordered shallow matching. Its explicit frames retain pending operations and caller environments. The later actual stream producer and 216-run diagnostic comparison exercise this host machine through visit_steps; they add no public source grammar or general native consumer. A recursive factorial call can therefore leave multiplication pending while its callee executes; returning restores the caller's scope before continuing. A tree fold similarly retains the branch that has not yet been visited. These calls advance through explicit machine states; a fuel-bounded run does not require a source function to decrease structurally on its input data. Their existence does not establish recursive native proof composition.

The general design extends that machinery through bounded helpers, declaration-driven recursive data and financial continuations. These are required v1 work, with different implementation dispositions. A public B scalar library consumer already calls the real owner engine. Generic ADT payload proposals and metadata composition do not establish production generic declaration admission. Existing Core/2 financial execution is reusable behavior to map into Sherlock; it is not evidence that this lowering already exists.

For `moriarty/1`, the current public `mori compile` route attaches scalar source-projection metadata to its ordinary Core artifact. The recursive source bridge is a test-only draft. Final03 and the additive OpenSpec define a planned first compiler increment: parameter-free Core/1 scalar actions reach real B preparation/admission with explicit HostOnly artifacts and separate optional observation. Its selected flags/schema are design contracts, not installed command support. Witness/constraint/native omissions remain explicit. This public route matters because a typed literal-only constructor cannot demonstrate that a new supported source program reaches the interpreter relation.
