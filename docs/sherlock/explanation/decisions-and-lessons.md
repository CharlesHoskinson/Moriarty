The proposed direction is to converge the existing A/B components through explicit adapters and real public consumers. Adding isolated leaves keeps useful progress local but can postpone the shared dispatcher and source-to-ledger path. Replacing the backend with another zkVM would introduce migration and correspondence work without supplying Midnight acceptance. Reusing current components keeps those missing consumers visible while preserving their actual tested scope.
