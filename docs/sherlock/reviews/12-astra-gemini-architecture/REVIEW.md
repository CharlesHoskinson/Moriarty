The report's exhaustion/error8 interpretation is also wrong: A Outcome::Exhausted is distinct; UIREQ-011 concerns pure completion. See G01-G/H, G03-F; D6.

2. **Do not ban pending-helper checkpoints.** Lane02's quiet-only rule excludes exactly the state UIREQ-029:215–216 names: a pending multiplication, caller environment and helper cursor. Interfaces.md:240 says “A technical cut retains all pending state and cumulative work.” A declared quiet-only prototype is narrower evidence, not v1 completion. Existing literal A102→A80 composition ends in a noncanonical Step image. Its exact in-memory adjacency does not discharge persistent import. Keep the original Step image, projected canonical result and explicit domain result. Any alternative is a separate existing-owner matter; this review changes no A4/guard policy. See G08-C/D; D4/D7.

4. **Keep first-match and missing-origin semantics.** Lane01's blanket unique-function rejection would change the legacy execution domain. UIREQ-027:202 retains source-order first-match until a separately admitted unique-function profile; draft_typecheck.rs:133–135 follows that rule. ## Useful additions and their actual consumers

**Compiler/admission (D1–D2; Integrator I plus profile/type/backend owners).** The selected public compile route should pass one explicit admitted-program product to its interpreter and witness consumers, with source occurrence, profile/layout/bounds and capability linkage. This is proposed interface work; there is no inspected generic admit_program method to invoke everywhere. Existing A diagnostic Machine/visit_steps remain diagnostic. B OwnerEngine preparation/admission is an actual reusable seam, but its HostOnly/uncut/DedicatedSorts qualification remains.

The public parser's inspected declaration branch and type function support the bounded Core grammar and UInt/Bool (parser.rs:146,217–222); recursive program/fn/entry drafts are cfg(test) in lib.rs:12–23. A two-stage declaration/body pass is a good way to support closed monomorphic mutual groups without unrolling calls. Reconcile the grammar and selected source subset before promotion. Do not introduce a new source module name as though it exists.

Freeze separate program/admission, operation, constraint, witness and capability/export artifacts with concrete producer/consumer fields. Current compile.rs publishes individual files and then artifact.json (48–79); this supports a completion-marker convention, not an all-files atomicity claim. Unsupported selected Sherlock lowering must stay explicit; ordinary Core's metadata report and the literal relation remain separate scopes. Preserve existing source/hash/key identity contracts. S1/S2 success does not supply this general compiler path.

**Constructor evaluation (D3; shared interface owner plus frame/call/ADT family owners).** This is the strongest new concrete gap. shared.rs:211–225 explicitly has nine core frame variants and refuses ConstructorFields. Proposed shared_adt.proposed.rs::ControlExtC::Materialize already takes evaluated fields; its twelve Build/Plan payload rows do not evaluate constructor expressions. The extension needs a frame retaining type/constructor, origin, saved environment, evaluated prefix, remaining fields/cursor and return context, with all introductions/returns/failures/serialization mapped. Do not invent widths, tags, guards or charges.

Preserve strict left-to-right construction and recursion inside fields. The nominal Schedule result4 versus independent sum9, mutually recursive declarations and a cut during a recursive field are concrete normal discriminators. Lane02's proposed nonlinear-pattern error8 is not current semantics: reference.rs:381–401 and structural.rs:187–199 make repeated dedicated Cons/Branch binders a match miss; draft_typecheck.rs:166–195 instead reports a source preparation error for its subset. Generic binder admissibility needs an explicit selected-domain contract, not a new guard authored here.

**Reusable realization (D5; dispatcher/infrastructure owner with disjoint leaf owners).** Current literal, return, error and exhaustion leaves do repeat image_ranges calls. Factorable infrastructure is worth designing, but the alleged39x/38x row savings and k17 failure are not measurements. Fetches must remain enabled by actual control/rule needs, and fuel updates must respect free publication. Keep separate A39, B and GenericNominal consumer inventories.

Operation metadata can connect separate witness and constraint plans. Actual B EffectPlan is a pre-image-derived proposal of writes/deltas; it is not already ConstraintPlan or a correspondence proof. Interfaces.md:275 prohibits generating both semantics and its independent oracle from metadata. The deterministic uncached witness DAG and private Clean stage remain required. Preallocated scratch is a deferred optimization: actual environment.rs Append copies the existing prefix into a fresh value-slot span, but physical instruction savings cannot silently alter B charges/caps/allocation history.

**Composition (D7; Owner H plus composition/backend owners).** Use a typed interface matrix for execution steps, persistent checkpoints, source financial boundaries, recursive statements and final ledger effects. This clarifies missing consumers without prematurely fixing digests or opcodes. Carry committed and tentative state completely. A82/A84 are pure publications and do not themselves roll back finance; Core/2 source policy controls financial continuation. Keep all five composition operators, complete effects/duties, private handoff and native acceptance in scope. Preparing the outer envelope later is scheduling, not an optional final acceptance condition.
