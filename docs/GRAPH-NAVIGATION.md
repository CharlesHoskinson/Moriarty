# Worktree graph navigation

Prepared 2026-10-19. Example node IDs below refer to that dated graph; verify freshness and exact current IDs before use.

Use one graph per worktree: `export GRAPHIFY_OUT="$PWD/graphify-out"`. Run `python3 scripts/graph-nav.py status` before lookup. The helper checks graph/manifest/semantic-coverage identity, recorded root, snapshot cardinality, HEAD, every included source hash and the current primary tracked/untracked file set. Missing, malformed or unreadable metadata yields JSON `STALE`. It does not execute product code or rebuild the graph.

```sh
python3 scripts/graph-nav.py query "script hash representation current evidence" --seed current_script_hash_representation_current_evidence_index
python3 scripts/graph-nav.py query "Core3 observed language progress" --seed current_core3_language_actual_progress_index
graphify explain EXACT_NODE_ID --graph "$GRAPHIFY_OUT/graph.json"
graphify path NODE_A NODE_B --graph "$GRAPHIFY_OUT/graph.json"
graphify affected FULL_SOURCE_PATH --graph "$GRAPHIFY_OUT/graph.json"
```

Native command details remain in `graphify --help` and subcommand help. Use exact IDs from the graph and follow the returned raw sources. Narrow the seed or use one-hop explain when needed.

The source manifest is complete only for its declared primary-source policy and explicit draft/evidence allowlists. Hidden directory components, the manifest’s excluded components/prefixes and private/binary suffix patterns are excluded. Generic public auth/config/private source directory names are not automatically excluded. Symlinks, nonregular files, non-UTF8 bodies and NUL-containing bodies are excluded. See the exact manifest policy and skip ledger; this is a declared source scope, not a claim to inventory all disk bytes.
