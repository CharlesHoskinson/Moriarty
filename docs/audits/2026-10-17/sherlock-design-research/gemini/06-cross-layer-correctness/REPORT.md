* **Exact Proposed Text & Tests**: Add `pub enum ContinuityFault { InitialMismatch(SnapshotField), Gap { index: usize, field: SnapshotField }, FinalMismatch(SnapshotField), ChargeFuelMismatch { index: usize }, NonPendingBefore { index: usize }, StepAfterTerminal { index: usize } }` and `pub fn check_continuity(view: TraceView<'_>, final_state: &Snapshot) -> Option<ContinuityFault>` in [`compare.rs`](file:///home/charl/Moriarty/.worktrees/sherlock-parallel-implementation-20261016/crates/mori-core/src/sherlock/compare.rs). ## 4. Mandatory vs. Optional & What to Reject/Defer

* **Mandatory before full v1 / slice acceptance**: Rank 1 (`check_continuity` + ban on self-oracle expectations in Quint), Rank 2 (non-vacuous Quint chunk/observer/eraseHelpers model + mutation-sensitivity + ITF replay), and Rank 3 (B pre/post step materialization for `N01`, explicit Lean rule emission, and Scalar Clean terminal control reconciliation).

* **Reject / Defer**:
  1. *Reject* using model transition functions (`computePublishedPost`) to generate expected test states (`T1`).
  2. *Reject* treating `StepEventC` deltas or `RunSummary` aggregates as complete before/after state comparisons.
  3. *Reject* copying private Fenrir Lean/Clean paths or pins into public Moriarty artifacts, or claiming finite Quint/ITF sampling as formal refinement or circuit constraint soundness.
