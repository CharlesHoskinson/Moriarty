## 2. Concrete Design Gaps & Counterexamples

1. **G1 — Zero-Budget vs. Terminal Priority Contradiction & Stranded Exact-Zero Publication (`[contradiction]`)**:
   - Candidate02 states: `"Observer budget0 returns Budget without advancing or callback even on an already terminal machine."`
   - In [`Machine::visit_steps`](file:///home/charl/Moriarty/.worktrees/sherlock-parallel-implementation-20261016/crates/mori-core/src/sherlock/reference_stream.rs#L38-L72), `max_events == 0` skips the loop and returns `VisitStop::Budget` even when `outcome != Outcome::Pending`. By contrast, [`advance_m`](file:///home/charl/Moriarty/.worktrees/sherlock-parallel-implementation-20261016/crates/mori-core/src/sherlock/reference_slice.rs#L63-L99) with `m == 0` checks `end.outcome`: on a terminal machine it returns `SliceStop::Outcome(end.outcome)` (`SliceBoundaryKind::Terminal`), and only on `Pending` returns `SliceStop::TechnicalCut`. Meanwhile, B's [`owner_run`](file:///home/charl/Moriarty/.worktrees/sherlock-parallel-implementation-20261016/crates/mori-core/src/sherlock/helper_machine/shared/owner_runtime.rs#L1075-L1086) has *no* observer budget (`max_events`) or `ControlFlow::Break` support at all.
   - *Counterexample*: Run `N02` (`initial_fuel = 7`) with `visit_steps(7, ...)`. Event 7 (`A21/1`) consumes the 7th fuel unit, leaving `outcome = Pending`, `control = Some(Return(5))`, `frames = []`, `remaining_fuel = 0`, and exits with `VisitStop::Budget`. A caller observing `(VisitStop::Budget, remaining_fuel == 0)` cannot tell without granting an 8th observation slot whether the next zero-charge administrative step will publish `Done(5)` (`A80`), `Rejected(c)` (`A82`), or `Exhausted` (`A84`).
2. **G2 — Asymmetric B Refusal Charging, 1-Step vs. 2-Step Termination, and `ordinal` Indexing (`[repository observation]`)**:
   - In [`owner_step`](file:///home/charl/Moriarty/.worktrees/sherlock-parallel-implementation-20261016/crates/mori-core/src/sherlock/helper_machine/shared/owner_runtime.rs#L1026-L1074): P1 (`KAdminPublishValue`/`Error`), P2 (`ExhaustReason::Fuel`), and P3 (`ExhaustReason::HelperWork`) charge `work_delta = 0` and terminate in 1 step. P4/P6 capacity refusals (`DataNodes`, `DataFields`, `EnvironmentCells`, `HelperTasks`) charge `work_delta = 1` (`StepDisposition::RefusedCapCharged`) and transition *directly* to `OutcomeC::Exhausted` in 1 step (no free publish event). Yet P7 `KMachinePushRefuse` (frame cap) charges `work_delta = 1` to set `ControlC::Error { code: 4 }` while staying `Running`, requiring a *second* step (P1 `KAdminPublishError`, `work_delta = 0`) to reach `Rejected { code: 4 }`.
   - *Counterexample*: `owner_apply_validated` (`L951`) and `publish_event` (`L1022`) compute `StepEventC.ordinal` from `consumed_work` rather than an event counter. This avoids collision *only* because all `work_delta == 0` events in `owner_step` immediately terminate the machine; any non-terminal zero-charge event collides on `ordinal`.
3. **G3 — Mid-Helper Arena Mutation & Staged `result` Invalidate Naive Prefix Erasure (`[contradiction]`)**:
   - Candidate02 states: `"A completed B helper interval erases to its corresponding A event only on the declared common domain; incomplete helper prefixes erase to the saved A origin."`
   - In `owner_runtime.rs` (`L487-501`, `L966-995`), B helpers execute `HelperEnter -> HelperVisit* -> HelperExit/HelperFail -> LegacyComplete`. During `HelperVisit` (`BHelperScalarConstruct`, `BHelperEnvPutInsert`, `BHelperBindInsert`, `BHelperAppendCopy`, `BHelperMatchBinding`), B mutates `img.data`, `img.data_fields`, `img.env`, `img.value_slots`, and monotone `img.alloc` counters *before* `LegacyComplete` advances `reference_cursor` and updates `control`.
   - *Counterexample*: Cut a B trace either mid-`HelperVisit` or right after `HelperExit` (`helper == None, result == Some(r)`). At `result.is_some()`, if `remaining_work == 0`, P1 (`L1032`) is blocked by `result.is_none()` and P2 fires `Exhausted(Fuel)`. Erasing to the "saved A origin" without rolling back `(active, alloc)` and clearing `result` leaves partially mutated arenas that disagree with the A pre-state under `project_a`.
4. **G4 — Dual Quint Clock Semantics & Legacy `helper_schedule.rs` Fusion Drift (`[repository observation]`)**:
   - `universalMachine.qnt` (`sherlock-quint-a/1`) charges 1 fuel on `returnOne`, whereas `kProfileMachine.qnt` (`sherlock-k-a/1`) uses zero-charge publication (`rules 80, 82, 84`) plus post-terminal stutter (`rule 0, charge 0`). Separately, `helper_schedule.rs` (`L190-200`) fuses `CompleteFind -> BindEntry`, contradicting `owner_runtime.rs`'s two-cycle `Find` then `Bind` protocol.

## 3. Ranked Design Improvements (`[recommendation]`)

1. **Rank 1 (Mandatory): Unify Pre-Step Terminal Priority & Bounded Observer Stepping Across A, Slicing, and B**
   - *Evidence*: Wasmtime `UpdateDeadline::Yield` ([capture-01](file:///home/charl/Moriarty/.moriarty-dev/runtime/sherlock-review-20261017/gemini-research/05-clocks-fuel-observers/capture-01-wasmtime-updatedeadline.md)); RISC Zero `ExitCode::SystemSplit` vs `Halted` ([capture-02](file:///home/charl/Moriarty/.moriarty-dev/runtime/sherlock-review-20261017/gemini-research/05-clocks-fuel-observers/capture-02-risc0-exitcode.md)); `reference_stream.rs` vs `reference_slice.rs` vs `owner_runtime.rs`.
   - *Applicability & Tradeoff*: Adds bounded/interruptible `owner_visit_steps` to B and aligns `max_events == 0` terminal reporting between `visit_steps` and `advance_m`. Tradeoff: updates one `budget_zero_on_terminal_machine_still_reports_budget` test in `reference_stream_tests.rs`.
   - *Proposed Contract Text*: `"Before checking max_events == 0, both A::visit_steps and B::owner_visit_steps check if the machine is already terminal; if so, return Stop::Terminal with 0 events. When remaining_fuel == 0 in a Pending/Running state, one zero-charge administrative step remains enabled; chunked observers MUST drain until Stop::Terminal rather than halting on remaining_fuel == 0."`
   - *Proposed Test*: Assert `visit_steps(0, ...).stop == VisitStop::Terminal` on terminal `N01` (matching `advance_m(m, 0)`); assert B `owner_visit_steps` chunked across widths `[1, 2, 4]` produces the exact trace of `owner_run`.
2. **Rank 2 (Mandatory): Enforce A-Aligned Cut Boundaries or Helper-Entry `(ActiveLengths, AllocCounters)` Rollback for `eraseHelpers`**
   - *Evidence*: RISC Zero `Segment` ([capture-03](file:///home/charl/Moriarty/.moriarty-dev/runtime/sherlock-review-20261017/gemini-research/05-clocks-fuel-observers/capture-03-risc0-segment.md)); `SegBase` in `host_implied_prefix.rs`; `owner_runtime.rs:966-995`.
   - *Applicability & Tradeoff*: Makes incomplete-helper erasure sound. Tradeoff: either restrict proof/projection cuts to A-aligned states (`helper.is_none() && result.is_none()`) or snapshot `(ActiveLengths, AllocCounters)` at `HelperEnter` (`7` scalars) to truncate arena appends on erasure.
   - *Proposed Contract Text*: `"A B state is A-aligned iff helper == None && result == None. Any incomplete B helper prefix (helper != None || result != None) erased to its saved A origin MUST restore active arena lengths and alloc counters to their HelperEnter snapshot and clear result."`
   - *Proposed Test*: Cut `N03` after `BHelperBindInsert` (`helper.is_some()`) and after `BHelperBindComplete` (`result.is_some()`); assert `eraseHelpers` equals the pre-helper A state `project_a` including `active` and `alloc`.
3. **Rank 3 (Mandatory): Decouple `StepEventC.ordinal` from `consumed_work` and Specify B Refusal Classes (P1/P2/P3 vs P6 vs P7)**
   - *Evidence*: Owens et al. (ESOP 2016) clock vs step index; `interfaces.md:16`; `owner_runtime.rs:951,1022,1052-1072`.
   - *Applicability & Tradeoff*: Guarantees unique monotone event ordinals regardless of `work_delta in {0, 1}` and codifies 1-step P6 charged exhaustion vs 2-step P7+P1 frame refusal. Tradeoff: adds a monotone `event_ordinal: u64` counter to B runtime state.
   - *Proposed Contract Text*: `"StepEventC.ordinal is the 0-based monotone emitted-event index (+1 per StepEventC regardless of work_delta), distinct from consumed_work. P6 arena/task capacity refusals charge 1 work and terminate in 1 event (Exhausted(cap)); P7 frame-cap refusal (KMachinePushRefuse) charges 1 work to enter ControlC::Error(4) and publishes Rejected(4) via P1 (0 work) on the next event."`
   - *Proposed Test*: On B traces ending in P1, P2, P3, P6, and P7+P1, assert `events[i].ordinal == i` and `sum(work_delta) == final.consumed_work`.
4. **Rank 4 (Optional): Filter Quint Terminal Stutters Strictly by `rule == 0`, Never `charge == 0`**
   - *Evidence*: `kProfileMachine.qnt:345-360` vs `universalMachine.qnt:194-234`; `SHERLOCK-CORRECTNESS-LOOP.md:150`.
   - *Applicability & Tradeoff*: Prevents Quint trace comparators from stripping valid zero-charge terminal publications (`rules 80, 82, 84`) when removing post-terminal stutters. Tradeoff: none (predicate refinement).
   - *Proposed Contract Text*: `"Quint trace projection for sherlock-k-a/1 drops only post-terminal stutters with rule == 0, retaining zero-charge publication records (rules 80, 82, 84)."`
   - *Proposed Test*: Project a `kProfileMachine.qnt` trace with stutters; assert the final record has `rule in {80, 82, 84}, charge == 0` and zero `rule == 0` records remain.

## 4. Verdict & What to Reject/Defer

- **Limited Design Verdict**: **Conditionally sound convergence architecture (Option 3), blocked on Ranks 1-3**. Candidate02 properly separates A semantic events from B helper microsteps and scopes `W_B = W_A + H_B` to completed common-domain intervals, but must fix the `budget = 0` terminal priority contradiction, add bounded observer stepping to B, and account for mid-helper arena/alloc mutations and staged `result` states during prefix erasure.
- **Reject / Defer**:
  - **Reject**: Returning `VisitStop::Budget` at `max_events == 0` on an already-terminal machine (contradicts `advance_m` and hides terminality).
  - **Reject**: Control-only `eraseHelpers` on incomplete B helper intervals (`helper.is_some() || result.is_some()`) without restoring `(active, alloc)` to the `HelperEnter` snapshot.
  - **Reject**: Treating `helper_schedule.rs`'s fused `CompleteFind -> BindEntry` transition as normative (superseded by `owner_runtime.rs`).
  - **Defer**: Multi-segment B canonical resume (`reg.segBase != 0`, `X-10`) until Stage 1 uncut B-core (`host_implied_prefix.rs`) and single-segment A/B adapter obligations close.
