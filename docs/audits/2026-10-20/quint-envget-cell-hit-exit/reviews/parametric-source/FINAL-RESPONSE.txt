### Source/API findings

No mandatory source or API fix is required for the stated parametric positive scope.

The Quint relation matches the production positive slice on the decisive points:

- **Cell hit:** Pending `EnvGet`, `cursor = Some(index)`, and `env[index].binder == helper.binder` produce `found = Some(env[index].value)` and `status = Positive`. Cursor, common record, binder, result, control, frames, tasks, tables, admission, ProgramView, layout, and all unrelated image fields are retained by spread.
- **Cell miss divergence is intentional domain narrowing, not a modeling error:** Rust advances `cursor` to `cell.previous` on binder mismatch, whereas Quint returns `Q41OutsidePositiveSlice`. The reviewed claim is only the hit row; the marker is not represented as a Core refusal, error, terminal state, or unchanged-host outcome.
- **Exit:** Positive `EnvGet` with `found = Some(value)` clears the helper and stages exactly `C6HResultEnvFound({ value })`, with no Ref decoding or `Const → Data` coercion. This matches Rust `env_get_exit`.
- **Selection:** Cell is `BHelperEnvGetCell / HelperVisit`, visits `1`; Exit is `BHelperEnvGetExit / HelperExit`, visits `0`. Site and helper kind are `Some(common.site)` and `Some("EnvGet")`, consistent with Rust under the reachable-state premise that helper `common.site` equals the owner-derived site.
- **Owner charges:** Each step applies `remaining_work - 1`, `consumed_work + 1`, and `helper_work + 1`. Only Cell adds `helper_visits + 1`. `reference_cursor` remains unchanged because neither row is `LegacyComplete`. This matches P4/P7 and Rust `visits_of` / `build_event`.
- **Linked window:** `q41ComputeWindow` feeds the actual computed `after_cell` host into the second `q41NormalStep`; it does not reconstruct or replace the intermediate host.
- **Events:** All 28 event fields are computed rather than hard-coded from a literal case. Ordinal is the relevant pre-step `consumed_work`; run identity is retained; source expression is `pre.control_origin`; occurrence owner/function/path are taken from the full pre-state ProgramView occurrence slice without reordering or `[1, 0]` normalization. Cell phase/cursor are `Pending → Positive` with cursor retained; Exit is `Positive → None` with cursor cleared in the event projection. Result tag is absent for Cell and `EnvFound` for Exit. Origin cursor uses `helper.common.origin_reference_cursor`, not the current reference/work clock.
- **Preservation:** In the combined property, `q41WholeWindowExact` pins the entire computed three-host/two-event window, so it catches unrelated mutations. One qualification: `q41PreservedOutsideWrites` by itself exempts helper and result on both steps, so it should not be quoted alone as proof that Cell preserved `result`; the combined whole-window equality is the operative preservation check. This is not a blocking defect in the delivered combined predicate.
