## Row-by-row findings

### EnvGet — dispatched by `plan_env_get`

- **`/helper_events/6` entry → `env_get_entry`.** Reads `pre.control()` (`ControlC::Eval { expr }`) and `pre.expr(expr)` (`ExpressionRowC::Var { binder }`), i.e. the map's `prog.expressions` read at `c.expr`. Installs `EnvGet { common, binder, cursor: pre.env_root(), found: None, status: Pending }` as `reg.helper`, exactly the row's single ordered effect including `cursor: pre.envRoot`. All other writes Keep/None, delta all zero, matching base tail `[0,0,0,0,0,0]` at positions 5–10. No table scan at entry.
- **`/helper_events/7` cell → `env_get_cell`.** Reads `pre.env_cell(&id)` with `id` from `cursor` (absent cursor → `WrongVariant`), i.e. `img.env[unwrap(h.cursor)]` bounded by `pre.active.env`. The conditional is the row effect, not selection: if `cell.binder == binder`, sets `found = Some(cell.value)` and `status = Positive`, leaving `cursor` on the matching cell; otherwise sets `cursor = cell.previous`. Because entry starts at `pre.env_root()` and each non-match steps to `previous`, traversal is newest-first and the first (newest) binding wins; an absent variable is reached only when the chain ends and the `.empty` row is selected by the owner. Delta all zero, matching the row.
- **`/helper_events/8` empty → `env_get_empty`.** Sets only `status = Negative`. No reads beyond the helper register, delta all zero. `found`/`cursor` are preserved (absent under the owner's selected state), as the row's single effect requires.
- **`/helper_events/9` exit → `env_get_exit`.** Extracts `found` (absent → `WrongVariant`), sets `result = EnvFound { value }` and `helper = None` (the row's `clearHelper`), in that content. Delta all zero.
- **`/helper_events/10` failure → `env_get_failure`.** Checks only the `EnvGet` variant, sets `result = EnvMissing` and clears the helper. This is the correct absent-environment result path. Delta all zero.

### Append — dispatched by `plan_append` (6 Enabled arms only)

- **`/helper_events/32` entry → `append_entry`.** Reads `ControlC::Return { value }` and top frame `FrameRowC::ArgsF { completed, .. }`, installs `Append { common, src: completed, value, src_cursor: 0, dest_start: pre.active().value_slots, staged: None, phase: Copy }`. Matches the row including `destStart: pre.active.valueSlots`. Delta all zero.
- **`/helper_events/33` cell → `append_cell`.** Computes the source address with checked arithmetic, `src.start.checked_add(*src_cursor)` (overflow → `ArithmeticUndefined`), then stages exactly one slot: `staged = Some(pre.value_slot(&pos)?)`. It does not write a value slot, does not advance the cursor, and does not clear anything. Delta all zero.
- **`/helper_events/34` empty → `append_empty`.** Sets only `phase = Tail`. Delta all zero.
- **`/helper_events/35` tail → `append_tail`.** Exactly one slot write, `alloc_value_slot = Some(*value)`, with `phase = Done` and `active_value_slots = 1`, other delta components zero — matching the row's `allocValueSlot(h.value)` then `phase: Done` and base position 10 = 1.
- **`/helper_events/36` copy → `append_copy`.** Takes the staged value out first, writes it exactly once (`alloc_value_slot = Some(staged)`), then increments `src_cursor` via `checked_add(1)` and clears `staged = None`, with `active_value_slots = 1` and the rest zero. This is the row's ordered triple — allocate staged value, `srcCursor + 1`, `staged: none` — and cannot double-write because the staged value is copied into the plan before the local staged field is cleared.
- **`/helper_events/37` exit → `append_exit`.** Allocates nothing (all alloc fields stay None, delta all zero). Computes `len = src.len.checked_add(1)` with overflow → `ArithmeticUndefined`, and returns `AppendDone { seq: SliceC::normalized(dest_start, len) }`. Since `len ≥ 1`, normalization returns `(dest_start, src.len + 1)` unchanged — the contiguous slice just written — and the helper is cleared. Matches the row and the seam's `SliceC::normalized` semantics for the `len == 0 → (0,0)` convention, which this row can never trigger.
- **Disabled `/helper_events/38` failure:** no `BHelperAppendFailure` arm exists; it falls to `foreign()`. Correct.
