### Lazy, guard-first evaluation, from the installed source (Body 7)

1. **Closures, not values.** `builder.js` at 398 runs `args = expr.args.map(arg => buildExpr(builder, arg))`. That builds evaluator closures and evaluates nothing.
2. **`actionAll` gets the closures.** If the opcode is in `lazyOps`, `op(ctx, args)` receives those closures. `lazyOps` includes `actionAll`, `and`, `or` and `ite`. The eager path is only the `else` branch, which handles builtins and user-defined operators.
3. **Early stop.** `actionAll` calls each closure in turn. On a false result it restores the next-state snapshot and returns false **before invoking any later closure**. On `Left` it returns the error immediately, so a fault is never turned into a disabled guard.
4. **User-defined arguments run only when reached.** The arguments of a user operator such as `beginInvocation(suppliedQueue.nth(…))`, `resumeFollows(…)` or `initInvocation(head(…))` are evaluated eagerly only when that member's own closure runs. That happens only after the earlier guards have passed.

So no `head` or `nth` call is evaluated before an earlier false `all` guard.

**The one link not shown: argument order.** Source-to-IR argument order depends on `popMany` (`ToIrListener.js` 883–887), and its body is not supplied. That link does not carry the weight within this bound:
- Laziness alone (points 1–3) rules out the eager failure. Under eager evaluation, `records.nth(-1)` would fault at state 0.
- Suppose the order were reversed. In states 0–4, `beginInvocation`'s own phase guard either fails first, in Ready states, or every index is in range, in Published states with `len` of 1 or 2. The result would be identical.
- The only state where order matters is Published with `len==|Q|`, which is state 5. If the simulator evaluated a step there, a reversed order would raise a loud `Left`, not a false pass.
- The same reasoning applies to F3 (`i == 0 or …`): a reversal would fault loudly in the state-0 invariant.

Under the expected left-to-right order, no out-of-bounds call occurs in any state.
