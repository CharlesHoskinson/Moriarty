## Findings

The product boundary is a permissionless general financial language. ACTUS, loans, swaps, vaults and other applications are conformance libraries/examples, not the product's limit ([product contract](/home/charl/Moriarty/.worktrees/mid-roadmap-20261014/docs/MORIARTY-PRODUCT-CONTRACT.md:15)). The mapped concrete financial library is PR49's FeePool: a fixed one-epoch profile with two operator seats, one DA seat, one watcher, fixed receipts, nine duties, explicit claims and a bounded weighted allocation. Its 162 independent local cases cover the specified finite profile and 23 actions; the case report says this does not establish authenticated import, native custody or full M11 ([coverage](/home/charl/Moriarty/.worktrees/mid-roadmap-20261014/examples/core/fee-pool/cases/COVERAGE.md:3)).

Arithmetic policy is stricter and broader than the examples: base-per-quote price orientation; ceil for obligations, floor for receipts; protocol reserve receives rounding remainder; and explicit dimensioned conversion is required when adapting quote-per-base sources. U0 numeric profile covers only arithmetic primitives actually implemented by the successor, while AMM/vault/ACTUS primitives remain U6 ([numeric decision](/home/charl/Moriarty/.worktrees/mid-roadmap-20261014/docs/decisions/u0-numeric-profile-decision.md:7)). FeePool independently constrains its numeric inputs/predecessor fields below 2^64 and uses checked u128 witness products; that finite profile is not a generic arithmetic certificate ([FeePool README](/home/charl/Moriarty/.worktrees/mid-roadmap-20261014/examples/core/fee-pool/README.md:29)).

There are real local precursors for scoped fee reservations, cost-plane metering, source sponsorship with a reserved recovery slice, role/quorum/call policy, source-static native-call compilation and duty frames. Their interfaces explicitly leave authentication with the caller or compile only public static inputs. The financial-duty static example is compilation-only and does not claim ledger effects ([static compile README](/home/charl/Moriarty/.worktrees/mid-roadmap-20261014/examples/core/static-compile/README.md:36)). Likewise local sponsor unknown-finality holds do not authenticate network observations ([source sponsor](/home/charl/Moriarty/.worktrees/mid-roadmap-20261014/crates/mori-core/src/source_sponsor.rs:294)).

U3 remains a specified lifecycle: two-asset escrow, conditional recipient/document delivery, partial fills, persistent duties and continuations, joins, recovery authority, reserved work and late-result/refund controls. U5 needs adapters, common evidence, actual policy and epoch migration, durable concurrent reservations, payment/result/delivery separation and independent solvers. U6 keeps full ACTUS/DeFi denominators and requires separate semantic/native/local/Preview evidence ([roadmap](/home/charl/Moriarty/.worktrees/mid-roadmap-20261014/ROADMAP.md:48)). The M11–M17 table is a target contract: FeePool plus Capacity Exchange; registry/per-block anchors; coordinator recovery lifecycle; same-domain atomic swap; batch/oracle/liquidation; separated cost planes; and authenticated epoch-bound roles. Local source policy objects are partial components, not those complete systems ([Fenrir design](/home/charl/Moriarty/.worktrees/mid-roadmap-20261014/docs/superpowers/specs/2026-10-10-fenrir-integration-design.md:86)).
