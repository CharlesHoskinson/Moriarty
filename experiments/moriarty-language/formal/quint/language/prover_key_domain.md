## State and limits

One grouped Operation holds a typed request, immutable count/identity fixture, phase, admitted public/PK/physical counts, observed accesses and publication state. There are no messages, concurrent actors, clock or fairness assumptions. False terminal actions introduce no stutter. Reader phases separate required public acquisition, PK declaration and marker agreement, opaque PK acquisition and snapshot acceptance. Export phases account for payload and both markers, with the public marker authoritative and last. Refused, Snapshot and Published are separate terminal states.

V1 preserves min(PK cap, public leaf cap) and shared aggregate accounting. V2 grants an independent finite PK cap only to the singleton selected PK of a trusted keyset operation. Generic packages and arbitrary PK-like filenames remain public. Every modeled non-PK leaf and applicable marker counts as public; physical is checked public+PK. Cold keyset snapshots ignore optional PK/proving-marker metadata, counts and files; proving snapshots add the proving marker and PK to their respective domains.

The transition domain uses WORD_MAX 31, public hard 8, PK hard 16, input hard 2, VK hard 1 and leaf cap 4. These independently reduced quotas preserve boundary relationships, not a uniform byte scale or a Rust machine-width theorem. The complete modeled payload is a list sum; production must establish that it supplied all source/action/deployment/predecessor/parameter leaves. Pure test predicates separately use real 16MiB public, 64MiB PK, 1MiB input JSON, 64KiB VK and 80MiB physical counts, caller PK 32MiB as an explicit hypothesis only, and exact u64::MAX addition boundaries without allocating buffers. TypeScript bigint evaluates those predicates; the Rust evaluator rejects u64::MAX outside its i64 literal range.

Profile and purpose are trusted enums. Hash and marker identity are equality tokens. The model does not parse JSON, validate factory provenance, prove hash collision resistance, reproduce OS behavior or mint a proving capability from host flags. Its cap predicates omit usize sentinel conversion and the existing Signed v1 input/leaf envelope details; source inspection and actual ordinary Rust controls cover those obligations separately.
