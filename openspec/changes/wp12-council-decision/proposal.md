# Change: WP12 terminal council decision

## Why

The sprint sequence must end with one funded direction. An ambiguous request to
continue exploring would bypass the stop tests and preserve unfunded scope.

## What Changes

- Freeze all prior evidence and unresolved dissent.
- Run blinded Grok, Sol, and exact Fable 5.1 critiques.
- Score language, audited-library, and stop alternatives.
- Record one terminal decision with scope, owners, and rollback triggers.

## Capabilities

### New Capabilities

- `terminal-decision`: Produce an evidence-bound decision of Moriarty language,
  audited Compact libraries, or stop.

### Modified Capabilities

None.

## Impact

This package controls funding and the next implementation scope. Council advice
is evidence, not the decision authority.
