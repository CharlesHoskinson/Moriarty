# EARS requirements: Sherlock VM consensus (2026-11-07)

Status: CONSENSUS v2.1 (council vote 6/6 ACCEPT at 2026-11-07 21:29Z; text unchanged from DRAFT v2.1; amended 2026-11-08 (3) by the owner decisions in `dissent.md` "Resolved 2026-11-08", "Resolved 2026-11-08 (2)" and "Resolved 2026-11-08 (3)" (speed re-plan: SRC-011 mandatory, SRC-015..018 added, SRC-013/014 edited)). Forms: U = Ubiquitous, E = Event-driven, S = State-driven, X = Unwanted behaviour, O = Optional. Each requirement has a stable ID, an acceptance check that is a recorded run or a read-only check (never a review), and the clauses it refines (`UIREQ`, `UISEC`, `ZR`, `MNR`, `RPP`, `SRPOC`) or adopts (council clauses `ASR` astra-1, `SND` astra-2, `SRC` fable-2 proposed text, astra-3 scope clauses, fable-3 workflow text). Full requirement + scenario text is in `specs/<capability>/spec.md`. Design sections are in `design.md`. None of these clauses claims the code satisfies it today.
