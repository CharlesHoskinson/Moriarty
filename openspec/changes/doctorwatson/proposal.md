# DoctorWatson local software factory

User-authorized developer workflow and QA increment, 2026-10-16.

Deliver an executable local corpus/readback/comparison check, meaningful
regressions, direct parallel source ownership and a requirement-linked delivery
plan. GitHub stores reviewed source and results; automatic hosted CI is disabled
for this workflow at the user's request. This is not a scheduler or another
milestone system.

The existing Sherlock semantics, clock, interfaces, independent expectations,
execution authority and acceptance requirements remain normative. The initial
checker consumes existing independent A-profile data; it does not run rules or
authenticate a claim made by a producer. Missing model/circuit adapters remain
explicit gaps.

See [EARS and scenarios](requirements.md), the
[delivery plan](../../../docs/DOCTORWATSON.md), and the
[required correctness loop](../../../docs/SHERLOCK-CORRECTNESS-LOOP.md).
