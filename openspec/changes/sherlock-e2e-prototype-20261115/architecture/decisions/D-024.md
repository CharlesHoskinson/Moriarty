# D-024: A mixed-hash R_SL program is an open gap with a temporary named refusal

- Status: accepted
- Authority: OWNER (2026-11-15, owner: "go with the recommended answers for the 21 decisions"; was LEAD PICK for T15)
- Legacy IDs: EKT-004; RSL-002; Astra-A review R-01

## Context and Problem Statement

SHA-256 needs 3 extra AIRs and keccak256 needs 3. Both in one program give 11 app AIRs, above the bucket.

## Decision Drivers

- D-017 (the bucket).
- `compile.rs:847` refuses the program.
- EKT-004.

## Considered Options

- Keep the named capacity refusal as a temporary state and carry the capability as incomplete.
- A third bucket size, or one shared hash group.
- Make the refusal a language rule.

## Decision Outcome

The first option. The refusal is an implementation limit, not a rule of the language. The capability is incomplete until a path proves both hashes under the universal key rule.

Authority: OWNER (2026-11-15, owner: "go with the recommended answers for the 21 decisions"; was LEAD PICK for T15). Earlier text: LEAD PICK for T15. LEAD PICK for T15 for the temporary refusal only. No authority exists for a permanent limit: that needs the owner (D-008). The owner has not seen this limit; it is presented at T15.

### Consequences

- Good: One leaf key today.
- Bad: A real contract can hit the refusal.

## Confirmation

- outcome: test `rsl_sha_and_keccak_in_one_program_refused` (the temporary refusal is named). Status: planned unless the cited requirement reads MEASURED.
- conformance: EKT-004; COVERAGE.md gap list. Status: planned unless the cited requirement reads MEASURED.

## Pros and Cons of the Options

### Keep the named capacity refusal as a temporary state and carry the capability as incomplete

- Good: The bucket and the one leaf key hold today; the gap is visible.
- Bad: A valid Compact contract with both hashes in one circuit has no R_SL proof.

### A third bucket size, or one shared hash group

- Good: Accepts both hashes.
- Bad: Not built; a second universal leaf shape must be shown to keep D-004.

### Make the refusal a language rule

- Good: Simple.
- Bad: Narrows the language; a lead decision cannot authorize an exception to a hard rule (D-008).

## More Information

### Reconsideration

A suite or user contract needs both hashes in one circuit; or T25 changes the leaf encoder.
