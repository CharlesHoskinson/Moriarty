# D-008: GP-1 to GP-4 are never narrowed

- Status: accepted
- Authority: OWNER
- Legacy IDs: hard rule; CPR-005; memory rule (GP definition); O10

## Context and Problem Statement

General purpose and universal means all of: universal VM, composition, foreign proofs, PCD.

## Decision Drivers

- GP-001 to GP-004 (`sherlock-vm-consensus-20261107`).
- CPR-005 (processor-final).

## Considered Options

- No constant, gate or requirement narrows a GP target; a capacity that fills has a spill path.
- Accept a bounded variant for the prototype.

## Decision Outcome

Authority: OWNER. Owner hard rule.

- Bad: Limits of the Compact frontend (D-024) must be shown not to narrow GP-1.
