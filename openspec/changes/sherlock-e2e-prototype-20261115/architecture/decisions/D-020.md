# D-020: rsl-call/1 is the call record between Mycroft and the R_SL executor

- Status: proposed
- Authority: LEAD PICK for T15
- Legacy IDs: ERS-001; `mycroft-call/1`

## Context and Problem Statement

The Mycroft compiler and the openvm R_SL executor are in two repositories. They exchange one JSON file per call.

## Decision Drivers

- ERS-001, ERS-002.
- `mycroft-emit` (`crates/sherlock-leaf/tools/mycroft-emit/src/main.rs:120-125`).

## Considered Options

- One file per call with program, ABI fields, tape and native reference.
- Link the Mycroft crate into the prover.

## Decision Outcome

`rsl-call/1` as built. A schema file and a `prog_d` field are gaps (ERS-001, ERS-006).

Authority: LEAD PICK for T15. LEAD PICK for T15 (built by the rekey-chips lane; no owner words).

### Consequences

- Good: Boxes replay calls from files with a sha256.
- Bad: Two formats exist (`rsl-call/1`, `mycroft-call/1`).

## Confirmation

- outcome: ERS-005, ERS-011 (cross-box `comm` and W). Status: planned unless the cited requirement reads MEASURED.
- conformance: ERS-001, ERS-013 (T-CALL-FORMAT round trip), ERS-014 (T-CALL-SCHEMA negative parser test). Status: planned unless the cited requirement reads MEASURED.

## Pros and Cons of the Options

### One file per call with program, ABI fields, tape and native reference

- Good: One artifact reproduces a call on any box.
- Bad: The file holds the tape, so it is private (ERS-002).

### Link the Mycroft crate into the prover

- Good: No file format.
- Bad: Couples two repositories and two toolchains.

## More Information

### Reconsideration

The product CLI joins compiler and prover in one binary.
