# D-014: Setup mode replaces F-3

- Status: accepted
- Authority: OWNER
- Legacy IDs: F-3; SPL-002; SPL-011; SETUP-SPEC ST, PF, SC

## Context and Problem Statement

An elastic prover must adapt to the hardware. F-3 put a schedule menu in `key_root`.

## Decision Drivers

- Owner 2026-11-14: "Sherlock should have a setup mode where it profiles the machine and optimizes for it".
- T16 three-box table (RESULTS-CDE.md).

## Considered Options

- Setup mode writes `sherlock-profile/1`; schedules come from the profile; one key set accepts every schedule.
- A schedule menu in `key_root`.

## Decision Outcome

Setup mode.

Authority: OWNER. Owner ruling 2026-11-14.

### Consequences

- Good: Byte-equal `claim_pub` on every box.
- Bad: The setup requirements live in a research file, not in OpenSpec (AUDIT.md).
