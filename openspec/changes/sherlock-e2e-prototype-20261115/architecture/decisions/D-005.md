# D-005: The ledger 9.1.0.1 verifier is unchanged

- Status: accepted
- Authority: OWNER
- Legacy IDs: hard rule; OD-24 option E; CPR-004; MID-001

## Context and Problem Statement

Midnight verifies a wrap with `VerifierKey::verify`. Ledger 9 refuses a G4 key (check M7-0, MEASURED).

## Decision Drivers

- CPR-004, MID-001 (processor-final).
- OD-24: the ledger-readable wrap path.

## Considered Options

- Option E: an Fr-native STARK layer `L_Fr` under one `ZkStdLib`-architecture wrap that the stock verifier reads.
- Options A and C: a G4 wrap.
- A ledger change.

## Decision Outcome

Option E.

Authority: OWNER. Owner decision OD-24, 2026-11-12; hard rule.

### Consequences

- Good: Deploys on Preview today.
- Bad: The wrap must keep the `ZkStdLib` key shape.

- conformance: slice C LVR requirements; MYC-ACC-001, MYC-CHIP-008. Status: planned unless the cited requirement reads MEASURED.
