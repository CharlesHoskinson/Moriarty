# D-022: The prototype settles Compact calls in run form through acceptRun

- Status: proposed
- Authority: LEAD PICK for T15
- Legacy IDs: T23; MYC-CHIP-004; MYC-SEAL; STL-001

## Context and Problem Statement

The Mycroft design seals a call as the native call vector `[bind, comm] ++ anchor ++ W ++ zeros`, so a Compact contract holds the universal wrap key. The built R_SL app exposes `comm` then W, and T23 settles through SherlockLedger `acceptRun(c_p, input_pub, outcome_pub)`.

## Decision Drivers

- LOOP.md row T23: every call is settled on Preview through SherlockLedger `acceptRun`.
- ERS-003, ERS-008, STL-001.

## Considered Options

- Run form: the call is a general run whose outcome is `Halted(vd([comm] ++ W))`; one SherlockLedger per program.
- Sealed form (MYC-SEAL): the contract entry holds the wrap key and the ledger applies W.

## Decision Outcome

Run form for the prototype; the sealed form stays the Mycroft target.

Authority: LEAD PICK for T15. LEAD PICK for T15. The row text is the lead's; the owner order names "all the contracts work on Preview".

### Consequences

- Good: T23 can run after T25 and T12.
- Bad: "Works on Preview" means an accepted claim with W equal to native, not a native state change.

## Confirmation

- outcome: ECS-010, EUF-010. Status: planned unless the cited requirement reads MEASURED.
- conformance: ERS-003, ERS-008; slice C SLC requirements. Status: planned unless the cited requirement reads MEASURED.

## Pros and Cons of the Options

### Run form: the call is a general run whose outcome is `Halted(vd([comm] ++ W))`; one SherlockLedger per program

- Good: Uses the contract and wrap that T17 proved on Preview.
- Bad: The Compact contract's own ledger state is not written; W is compared with native off chain.

### Sealed form (MYC-SEAL): the contract entry holds the wrap key and the ledger applies W

- Good: Native state parity on chain (MYC-ACC-007).
- Bad: Needs the seal statement in `L` and the wrap; not built.

## More Information

### Reconsideration

The owner asks for native state parity on chain, or the seal statement is built.
