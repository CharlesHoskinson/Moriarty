# D-013: The x_j lock form is canon

- Status: accepted
- Authority: OWNER
- Legacy IDs: ANC-002; ANC-017; T10B-LOCK; NT-2, NT-3

## Context and Problem Statement

The lock anchor of a chunked call must bind the run. The old form `P2(DOM_LOCK, ...)` did not bind `k`, `d_in`, `d_out`.

## Decision Drivers

- Owner 2026-11-14: x_j lock form is canon.
- openvm e3b407d `iface::lock_x`; NT-1 to NT-3 CONFIRMED and fixed.

## Considered Options

- `A_j = PoseidonFr_4(SHK_LOCK, x_j)`, `x_j = sponge(U_LOCK; c, pack(run_tag), k, d_in, d_out, pack(C_(j+1)), j)`.
- Keep `P2(DOM_LOCK)`.

## Decision Outcome

The x_j form.

Authority: OWNER. Owner ruling 2026-11-14; extension confirmed 2026-11-15 (wiki 09:04). Second extension: the FP-3 link `pack(C_(j+1))` before `j` comes from D-038 (OWNER 2026-11-15); the text follows the code (F-B-BR-2, LEAD PICK for T15). The form stays: one `U_LOCK` sponge over the run's bound operands with `j` last, `A_j = PoseidonFr_4(SHK_LOCK, x_j)`, `A_0 = A_k = C_P`.

### Consequences

- Good: Splice and truncation attacks are refused.
- Bad: L_Fr and the wrap VK change at the rekey.

## Confirmation

- outcome: ANC-016, ANC-017 (completion). Status: planned unless the cited requirement reads MEASURED.
- conformance: LPC-017; slice B CLB requirements. Status: planned unless the cited requirement reads MEASURED.

- Good: Binds the run and the chunk position.
