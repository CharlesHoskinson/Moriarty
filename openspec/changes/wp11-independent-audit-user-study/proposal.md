# Change: WP11 independent evaluation

## Why

Internal tests cannot establish security or user value. The project needs an
independent audit, a language-versus-library comparison, and real pilot demand.

## What Changes

- Commission a scoped audit outside the authorship chain.
- Compare Moriarty with audited Compact libraries using matched tasks.
- Collect two user-supplied non-toy pilot specifications.
- Preserve findings, measurements, dissent, and remediation evidence.

## Capabilities

### New Capabilities

- `independent-evaluation`: Test security, reviewability, usability, and demand
  without substituting model simulation for human evidence.

### Modified Capabilities

None.

## Impact

This package can block release or select the library-only fallback. Council
reviews do not satisfy the independent security-audit requirement.
