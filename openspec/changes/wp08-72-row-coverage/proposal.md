# Change: WP08 72-row protocol coverage

## Why

Moriarty needs an honest disposition for the entire DeFiFormal corpus. Family
demos alone cannot establish usefulness across 72 distinct deployed products.

## What Changes

- Map every protocol to a bounded instance or outside-kernel manifest.
- Review unsupported mechanisms and external assumptions.
- Retain thirteen legacy Marlowe-style regression patterns.
- Prevent family-level evidence from becoming protocol-completeness claims.

## Capabilities

### New Capabilities

- `protocol-coverage`: Give every DeFiFormal protocol a reviewed, evidence-bound
  Moriarty coverage disposition.

### Modified Capabilities

None.

## Impact

This package produces the adoption and expressiveness boundary used by the
terminal decision. It does not require every protocol to compile.
