# Change: WP07 seven canonical demonstrations

## Why

One atomic swap does not establish a useful financial language. Seven bounded
slices must exercise the recommended DeFi families and prediction markets.

## What Changes

- Implement one canonical application for F1 through F6 and Prediction.
- Produce source, Core, Compact, manifest, certificate, and client checks.
- State every outside-kernel assumption.
- Compare reusable language structure with special-case generators.

## Capabilities

### New Capabilities

- `family-demonstrations`: Demonstrate bounded applications across the complete
  human-facing taxonomy without claiming full protocol implementations.

### Modified Capabilities

None.

## Impact

This package expands feasibility evidence and feeds protocol coverage, SDK, and
pilot evaluation. It does not prove that all protocols fit Moriarty.
