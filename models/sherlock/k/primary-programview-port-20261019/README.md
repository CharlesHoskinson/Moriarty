# General public ProgramSnapshot port

The two Python files are unchanged from the fresh source-reviewed and Root-run
interface cut. The port retains all23 ProgramSnapshot fields and the complete
input document, emits a partial NGProgram plus source origins, and explicitly
refuses unsupported mapped forms. See the scoped three-case evidence at
`docs/results/sherlock-primary-programview-port-three-20261019/README.md`.

Primary admission/authenticity remains an external premise. The global ArmRow
and SCC-min group conventions are derived port labels, not canonical source
identities. This is a data adapter; it does not run an evaluator or model and
does not establish complete primary-to-K transition/work correspondence.
