The complete owner findings AF-1–AF-8 govern:

1. **AF-1, caller binding:** operand order is left = Right-frame value, right = returned value; type IDs must be bound to actual fetched nodes. P-1-values-only tests no Constant/Data address or fetch.
2. **AF-2, coverage:** A108 duplicates F-1 and does not establish rule dispatch. Identical expected terms in other cases do not imply identical requests.
3. **AF-3, tooling:** `arithmetic-fuel.k` and `normal-checks.k` are separate definitions. The normal definition has no `-SYNTAX` companion. Any future separately classified command must name appropriate main and syntax modules explicitly; no default is assumed verified.

5. **AF-5, result interpretation:** a future normal check succeeds only with exactly `afCheckedNormal(true)`. A request succeeds only when the entire `<k>` cell matches its complete expected term. False, absent, stuck, partial/unreduced results, extra content, timeout and crash are not success. Any exclusion of generated cells needs an explicit rule. 8. **AF-8, independence:** expectations and source share an author. Review hand derivations do not establish an independent implementation, proof or all-input runtime result.
