The complete P3 arena source proposal is conditionally adopted for UInt, Bool, List and Tree. This is a source design; it is not an executed model, a compiled circuit or interpreter acceptance.

Read [the unchanged design](P3-ARENA-DESIGN.md), [its JSON catalog](A-ARENA-OPERATIONS.json), and [the Root adoption record](ROOT-COMPLETE-P3-SOURCE-ADOPTION.json) together. The adoption incorporates the complete fresh Opus and Muse reviews, including their binding errata and conditions. The original manifest remains unchanged and records the source packet, not this publication directory. Runtime paths in historical receipts identify the original inputs; the publication contains the corresponding artifact bodies.

The proposal specifies append relations for all 39 CandidateA transitions and four auxiliary records: EnvGetScan, FindScan, BindPreflight and EqScratch. In particular, Q_eq+1 is a labelled lower bound for EqScratch.rows, not an adopted exact-need wire format. The aux/1 proposal is not a complete step-witness profile: arithmetic and fuel-borrow witness placement remain open.

The compressed author and review captures preserve exact original bytes. Opus supplied the designated-owner security and physical-design vote; Muse supplied the independent normal-conformance vote. Neither vote grants execution or resource admission.

G4, P4, P5, F4, MD2, StepInv/chaining, Constant typing, D-NAMES enforcement, O-ARITH, L04 binding and L05 numeric admission remain open.
